# Pata kitufe cha DeepSeek API

Deepsand inahitaji mtoa huduma wa modeli ili kuwasha mratibu. Usanidi chaguo-msingi hutumia DeepSeek. Ukurasa huu hupitia kuunda akaunti, kuongeza mkopo, kutengeneza kitufe cha API, na kuihifadhi katika Deepsand.

Ikiwa tayari una ufunguo wa API kutoka kwa mtoa huduma mwingine, ruka hadi [Tumia ufunguo ambao tayari unao](#use-a-key-you-already-have).

## Kabla ya kuanza

Utahitaji:

- Anwani ya barua pepe au akaunti inayotumika ya kuingia.
- Njia ya malipo ya mkopo wa API.
- Dakika chache kuunda ufunguo na kuubandika kwenye Deepsand.

DeepSeek API inatozwa kando na tovuti ya gumzo ya DeepSeek na programu ya simu. Kuongeza mkopo kwenye jukwaa la API ndiko kunakoruhusu msaidizi kufanya maombi.

## 1. Fungua akaunti ya DeepSeek

1. Fungua [Jukwaa la DeepSeek API](https://platform.deepseek.com/).
2. Chagua **Jisajili** au **Ingia**.
3. Fungua akaunti ukitumia anwani yako ya barua pepe, au utumie mojawapo ya chaguo zinazotumika za kuingia.
4. Thibitisha anwani yako ya barua pepe au nambari ya simu ikiwa jukwaa litakuuliza ufanye hivyo.

## 2. Ongeza mkopo

1. Ingia kwenye jukwaa la API.
2. Fungua sehemu ya bili au ya kujaza kwenye dashibodi.
3. Ongeza kiasi cha mkopo unachotaka kutumia.
4. Kamilisha malipo.

Matumizi ya API yamekatwa kwenye salio hili. Jukwaa linaonyesha usawa wa sasa, matumizi na bei. Anza na kiasi kidogo wakati unajaribu Deepsand; unaweza kuongeza zaidi baadaye.

## 3. Unda ufunguo wa API

1. Fungua sehemu ya **Vifunguo vya API** ya jukwaa.
2. Chagua **Unda ufunguo mpya wa API** au kitufe sawa.
3. Toa ufunguo jina utakalotambua, kama vile **Deepsand**.
4. Unda ufunguo na uinakili mara moja.

Ufunguo kawaida huonyeshwa mara moja tu. Lichukulie kama nenosiri: mtu yeyote aliye nalo anaweza kutumia mkopo kwenye akaunti yako.

## 4. Hifadhi ufunguo katika Deepsand

1. Fungua Deepsand.
2. Fungua **Mipangilio**.
3. Pata uga wa **Kitufe cha API** chini ya vitambulisho chaguo-msingi.
4. Bandika ufunguo.
5. Chagua **Hifadhi ufunguo**.

Deepsand huhifadhi ufunguo katika duka la vitufe vya mfumo wako wa uendeshaji, si katika faili ya mipangilio yake. Dirisha linaonyesha tu herufi nne za mwisho baada ya kuhifadhi, ili uweze kuthibitisha ufunguo upo bila kufichua tena.

Ufunguo mpana wa programu hutumika wakati usanidi wa seva pangishi DeepCode wala mradi hautoi ufunguo wake. Kitufe cha kiwango cha mradi bado kinatanguliwa.

## Tumia ufunguo ambao tayari unao

Ikiwa tayari una ufunguo wa API, huhitaji kuunda akaunti ya DeepSeek.

- Ili kuitumia kwa kila mradi, fungua **Mipangilio**, ingiza ufunguo kwenye uwanja wa **Kitufe cha API**, na uihifadhi.
- Ili kutumia ncha au muundo tofauti, pia weka URL msingi na muundo katika **Mipangilio** au katika vitambulisho vya mradi wenyewe.
- Ili kuweka ufunguo kwa mradi mmoja pekee, fungua mipangilio ya mradi huo na uiweke hapo badala yake.

Mtoa huduma lazima afichue API ambayo DeepCode CLI inaweza kupiga. Ikiwa unatumia mtoa huduma asiye wa DeepSeek, weka URL yake msingi na jina la modeli badala ya chaguomsingi za DeepSeek.

## Ikiwa kitu haifanyi kazi

- **Ufunguo umekataliwa:** unda kitufe kipya kwenye jukwaa na ubadilishe kilichohifadhiwa.
- **Salio ni tupu:** ongeza mkopo kwenye akaunti ya API. Usajili wa gumzo hauchangii kiotomati matumizi ya API.
- **Mratibu hawezi kufikia mtoa huduma:** angalia hali ya mtandao ya mradi na orodha ya ruhusa. Mwisho wa mfano lazima upatikane.
- **Unataka kuondoa ufunguo:** fungua **Mipangilio** na uchague **Ondoa ufunguo**.
