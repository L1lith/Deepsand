# Pakua Deepsand

Deepsand inapatikana kwa Windows, macOS na Linux. Ukurasa hutambua mfumo wako, lakini unaweza kuchagua jukwaa lingine ikiwa unapakua kwa mashine tofauti.

<DownloadPicker />

## Kabla ya kusakinisha

- Deepsand hutumia Docker kuendesha kila mradi katika sanduku lake la mchanga. Sakinisha Docker Desktop kwenye Windows au macOS, au Docker Engine kwenye Linux.
- Utahitaji ufunguo wa API wa mfano. [Pata kitufe cha DeepSeek API](./guide/deepseek-api), au tumia ufunguo uliopo wa mtoa huduma.
- Uzinduzi wa kwanza unaweza kuunda picha ya sandbox, ambayo inaweza kuchukua dakika chache.

## Baada ya kusakinisha

1. Anzisha Deepsand.
2. Fungua **Mipangilio** na uhifadhi ufunguo wako wa mtindo API.
3. Unda mradi na uchague saraka yake ya kufanya kazi.
4. Bonyeza **Kimbia** ili kuanza sandbox.

Soma [Kuanza](./guide/getting-started) kwa mapitio kamili ya awamu ya kwanza.
