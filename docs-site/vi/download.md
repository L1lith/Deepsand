# Tải xuống Deepsand

Deepsand có sẵn cho Windows, macOS và Linux. Trang này phát hiện hệ thống của bạn, nhưng bạn có thể chọn nền tảng khác nếu bạn đang tải xuống cho một máy khác.

<DownloadPicker />

## Trước khi bạn cài đặt

- Deepsand sử dụng Docker để chạy từng dự án trong hộp cát riêng của nó. Cài đặt Docker Desktop trên Windows hoặc macOS hoặc Docker Engine trên Linux.
- Bạn sẽ cần một khóa API kiểu mẫu. [Nhận khóa DeepSeek API](./guide/deepseek-api) hoặc sử dụng khóa nhà cung cấp hiện có.
- Lần khởi chạy đầu tiên có thể xây dựng hình ảnh hộp cát, quá trình này có thể mất vài phút.

## Sau khi bạn cài đặt

1. Bắt đầu Deepsand.
2. Mở **Cài đặt** và lưu khóa API mô hình của bạn.
3. Tạo một dự án và chọn thư mục làm việc của nó.
4. Nhấn **Chạy** để khởi động sandbox.

Đọc [Bắt đầu](./guide/getting-started) để biết hướng dẫn đầy đủ về lần chạy đầu tiên.
