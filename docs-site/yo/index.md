## Wa aaye ibẹrẹ ti o tọ

**Titun si ifaminsi tabi tuntun si awọn irinṣẹ AI?** Ka [Kini Deepsand?](./guide/what-is-deepsand). O ṣe alaye imọran ni ede ti o rọrun ati fihan nigbati o wulo.

**Ṣetan lati gbiyanju rẹ?** [Fi Deepsand sori ẹrọ ki o ṣẹda iṣẹ akanṣe akọkọ rẹ](./guide/getting-started).

**Itunu pẹlu Docker, awọn ebute, ati awọn awoṣe irokeke?** Lọ taara si [Labẹ awọn Hood](./guide/for-developers) fun faaji ati aala aabo.

**Nilo kan awọn ọna idahun?** Ṣayẹwo awọn [nigbagbogbo beere ibeere](./guide/faq).
