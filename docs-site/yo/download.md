# Ṣe igbasilẹ Deepsand

Deepsand wa fun Windows, macOS ati Linux. Oju-iwe naa ṣawari ẹrọ rẹ, ṣugbọn o le yan iru ẹrọ miiran ti o ba n ṣe igbasilẹ fun ẹrọ miiran.

<DownloadPicker />

## Ṣaaju ki o to fi sori ẹrọ

- Deepsand nlo Docker lati ṣiṣe iṣẹ akanṣe kọọkan ninu apoti iyanrin tirẹ. Fi Docker Desktop sori Windows tabi macOS, tabi Docker Engine lori Linux.
- Iwọ yoo nilo bọtini API awoṣe kan. [Gba DeepSeek API bọtini](./guide/deepseek-api), tabi lo bọtini olupese ti o wa tẹlẹ.
- Ifilọlẹ akọkọ le kọ aworan apoti iyanrin, eyiti o le gba iṣẹju diẹ.

## Lẹhin ti o fi sori ẹrọ

1. Bẹrẹ Deepsand.
2. Ṣii **Eto** ati fi bọtini API awoṣe rẹ pamọ.
3. Ṣẹda iṣẹ akanṣe kan ki o yan itọsọna iṣẹ rẹ.
4. Tẹ **Ṣiṣe** lati bẹrẹ apoti iyanrin.

Ka [Bibẹrẹ](./guide/getting-started) fun ni kikun Ririn-ṣiṣe akọkọ.
