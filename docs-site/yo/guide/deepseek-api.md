# Gba DeepSeek API bọtini

Deepsand nilo olupese awoṣe lati fi agbara fun oluranlọwọ. Iṣeto ni aiyipada nlo DeepSeek. Oju-iwe yii n rin nipasẹ ṣiṣẹda akọọlẹ kan, fifi kirẹditi kun, ṣiṣe bọtini API, ati fifipamọ rẹ ni Deepsand.

Ti o ba ti ni bọtini API tẹlẹ lati ọdọ olupese miiran, foo si [Lo bọtini ti o ti ni tẹlẹ](#use-a-key-you-already-have).

## Ṣaaju ki o to bẹrẹ

Iwọ yoo nilo:

- Adirẹsi imeeli tabi iroyin iwọle ti atilẹyin.
- Ọna isanwo fun kirẹditi API.
- Iṣẹju diẹ lati ṣẹda bọtini ati ki o lẹẹmọ sinu Deepsand.

DeepSeek API jẹ idiyele lọtọ lati oju opo wẹẹbu iwiregbe DeepSeek ati ohun elo alagbeka. Ṣafikun kirẹditi lori pẹpẹ API jẹ ohun ti ngbanilaaye oluranlọwọ lati ṣe awọn ibeere.

## 1. Ṣẹda DeepSeek iroyin

1. Ṣii [DeepSeek API Syeed](https://platform.deepseek.com/).
2. Yan **forukọsilẹ** tabi **Wo ile**.
3. Ṣẹda akọọlẹ kan pẹlu adirẹsi imeeli rẹ, tabi lo ọkan ninu awọn aṣayan iwọle atilẹyin.
4. Daju adirẹsi imeeli rẹ tabi nọmba foonu ti Syeed ba beere lọwọ rẹ.

## 2. Fi gbese

1. Wọle si iru ẹrọ API.
2. Ṣii ìdíyelé tabi apakan oke-soke ninu dasibodu naa.
3. Ṣafikun iye kirẹditi ti o fẹ lati lo.
4. Pari owo sisan.

Lilo API ti yọkuro lati iwọntunwọnsi yii. Syeed fihan iwọntunwọnsi lọwọlọwọ, lilo ati idiyele. Bẹrẹ pẹlu iye kekere nigba ti o n gbiyanju Deepsand; o le fi diẹ sii nigbamii.

## 3. Ṣẹda bọtini API

1. Ṣii apakan **API awọn bọtini** ti pẹpẹ.
2. Yan **Ṣẹda titun API bọtini** tabi bọtini deede.
3. Fun bọtini naa orukọ ti iwọ yoo da, gẹgẹbi **Deepsand**.
4. Ṣẹda bọtini naa ki o daakọ lẹsẹkẹsẹ.

Bọtini maa n han ni ẹẹkan. Ṣe itọju rẹ bi ọrọ igbaniwọle: ẹnikẹni ti o ni o le lo kirẹditi lori akọọlẹ rẹ.

## 4. Fipamọ bọtini ni Deepsand

1. Ṣii Deepsand.
2. Ṣii **Eto**.
3. Wa aaye **API bọtini** labẹ awọn iwe-ẹri aiyipada.
4. Lẹẹmọ bọtini naa.
5. Yan **Fi bọtini pamọ**.

Deepsand tọju bọtini naa sinu ibi-ipamọ ẹrọ ẹrọ ṣiṣe rẹ, kii ṣe ninu faili eto rẹ. Ferese nikan fihan awọn ohun kikọ mẹrin ti o kẹhin lẹhin fifipamọ, nitorinaa o le jẹrisi bọtini kan wa laisi ṣiṣafihan lẹẹkansi.

Bọtini jakejado app ni a lo nigbati ko ba jẹ atunto DeepCode agbalejo tabi iṣẹ akanṣe kan pese bọtini tirẹ. Bọtini ipele-iṣẹ kan ṣi gba iṣaaju.

## Lo bọtini ti o ti ni tẹlẹ

Ti o ba ti ni bọtini API tẹlẹ, iwọ ko nilo lati ṣẹda akọọlẹ DeepSeek kan.

- Lati lo fun gbogbo iṣẹ akanṣe, ṣii **Eto**, tẹ bọtini sii ni aaye **API bọtini**, ki o fipamọ.
- Lati lo aaye ipari tabi awoṣe ti o yatọ, tun ṣeto URL ipilẹ ati awoṣe ni **Eto** tabi ni awọn iwe-ẹri tirẹ.
- Lati tọju bọtini kan nikan fun iṣẹ akanṣe kan, ṣii awọn eto iṣẹ akanṣe naa ki o tẹ sii sibẹ dipo.

Olupese gbọdọ ṣafihan API kan ti DeepCode CLI le pe. Ti o ba nlo olupese ti kii ṣe DeepSeek, tẹ URL ipilẹ rẹ ati orukọ awoṣe dipo awọn aiyipada DeepSeek.

## Ti nkan ko ba ṣiṣẹ

- **Ti kọ bọtini naa:** ṣẹda bọtini tuntun lori pẹpẹ ki o rọpo ọkan ti o fipamọ.
- **Dọgbadọgba ti ṣofo:** ṣafikun kirẹditi si akọọlẹ API. Ṣiṣe alabapin iwiregbe kii ṣe inawo lilo API laifọwọyi.
- **Oluranlọwọ ko le de ọdọ olupese:** ṣayẹwo ipo nẹtiwọọki iṣẹ akanṣe ati atokọ iyọọda. Ojuami ipari awoṣe gbọdọ wa ni arọwọto.
- **O fẹ yọ bọtini naa kuro:** ṣii **Eto** ko si yan **Yọ bọtini kuro**.
