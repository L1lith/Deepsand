# Awọn ibeere ti a beere nigbagbogbo

## Ṣe DeepCode wo itọsọna ile mi?

Rara. Apoti iyanrin n wo itọsọna iṣẹ akanṣe ni `/workspace` ati awọn ilana ti o funni ni gbangba. Awọn iyokù ti awọn ogun filesystem ti wa ni ko agesin.

## Kini yoo ṣẹlẹ nigbati MO ba fọwọsi ibeere itọsọna kan?

Deepsand ṣe afikun ilana naa gẹgẹbi ẹbun, tun ṣe eiyan pẹlu oke tuntun ti a so, ati tun bẹrẹ igba DeepCode. Apoti iyanrin ti nṣiṣẹ ko le jèrè oke dipọ lai ṣe atunda.

## Nibo ni a ti fipamọ awọn ibaraẹnisọrọ mi?

Itan ibaraẹnisọrọ, awọn akoko, awọn asomọ ati awọn ọgbọn ti ipilẹṣẹ n gbe ni iwọn didun Docker-iṣẹ kan. Awọn folda ise agbese lori disk ni nikan koodu rẹ ati awọn faili.

Yiyọ iṣẹ akanṣe kuro lati Deepsand ko pa iwọn didun yẹn rẹ. Pipa data DeepCode ise agbese kan yọ iwọn didun kuro ṣugbọn fi folda iṣẹ akanṣe silẹ.

## Nibo ni awọn bọtini API ati awọn aṣiri ti wa ni ipamọ?

Awọn aṣiri jẹ fifi ẹnọ kọ nkan ni isinmi pẹlu bọtini kan ti o waye nipasẹ ibi-ipamọ ẹrọ ẹrọ, ati pe a fi itasi sinu apoti iyanrin bi awọn oniyipada ayika nikan nigbati o bẹrẹ. Ni wiwo fihan awọn orukọ ati gigun, kii ṣe awọn iye ti o fipamọ.

Awọn iwe-ẹri tun le jogun lati inu atunto DeepCode agbalejo rẹ. Wọn ko daakọ sinu folda ise agbese.

## Le kọọkan ise agbese lo kan yatọ si awoṣe?

Bẹẹni. Ise agbese kan le jogun iṣeto agbalejo tabi kọju awoṣe, URL ipilẹ ati awọn iwe-ẹri ninu awọn eto tirẹ. Aṣayan akọsori tun le yan awoṣe fun iṣẹ akanṣe; **Dari si atunto** tumo si ise agbese ko pin ọkan.

## Awoṣe wo ni MO yẹ ki n lo lati tọju awọn idiyele si isalẹ?

Lo awoṣe filasi fun ọpọlọpọ awọn iṣẹ-ṣiṣe. Deepsand aiyipada si `deepseek-v4-flash`, eyiti o jẹ yiyan ti o din owo fun ifaminsi lojoojumọ, awọn alaye ati awọn atunṣe. Ṣe ifipamọ `deepseek-v4-pro` fun iṣẹ nibiti filasi n tiraka kedere tabi o nilo agbara afikun rẹ, nitori pe awoṣe pro jẹ idiyele diẹ sii lati ṣiṣẹ.

Yipada awọn awoṣe lati akọsori iṣẹ akanṣe tabi pẹlu `/model` ni ebute DeepCode. Ti o ba n gbiyanju Deepsand fun igba akọkọ, bẹrẹ pẹlu filasi ati gbe lọ si pro nikan nigbati o ba ni iṣẹ-ṣiṣe ti o nilo rẹ.

## Kini esun ero n ṣe?

Awọn ero esun ni tókàn si awọn awoṣe selector ni ise agbese akọsori. O ṣakoso iye ero ti awoṣe ṣe ṣaaju ki o to dahun.

| Duro | Ohun ti o tumo |
| --- | --- |
| **Paa** | Maṣe ronu ṣaaju idahun. Yara ju, ṣugbọn o kere julọ ṣọra. |
| **Iyara** | Ironu diẹ, fun awọn atunṣe ti o ni pato daradara. |
| **Iwontunwonsi** | Irotunwọnsi. Idaduro aarin ati aiyipada oye fun iṣẹ gidi. |
| **Jin** | Ronu bi lile bi awoṣe ṣe le. O lọra ati gbowolori julọ. |
| **Aiyipada** | Dari si alejo `settings.json`; ti ko ba sọ nkankan, ṣubu DeepCode pada si Iwontunws.funfun. |

Jeki esun lori **Iwontunwonsi** fun ọpọlọpọ awọn iṣẹ-ṣiṣe. O jẹ eto aarin, ati pe o funni ni awọn abajade to dara laisi isanwo fun idi ti o lọra, gbowolori julọ lori gbogbo ibeere. Lọ si **Jin** nikan fun awọn iṣoro ti o nira nitootọ, ati lo **Paa** tabi **Iyara** fun kekere, awọn atunṣe asọtẹlẹ.

## Ṣe Deepsand ṣiṣẹ pẹlu DeepSeek nikan?

Rara DeepSeek jẹ aiyipada nitori pe o jẹ awoṣe ati opin opin Deepsand ọkọ pẹlu, ṣugbọn Deepsand tunto DeepCode CLI pẹlu orukọ awoṣe, URL ipilẹ ati bọtini API. O le tọka si olupese miiran ti o ṣafihan API kan ti CLI le pe, ni igbagbogbo aaye ipari ibaramu OpenAI.

Ṣeto URL ipilẹ ti olupese ati awoṣe ni **Eto**, tabi ni awọn iwe-ẹri iṣẹ akanṣe tirẹ, ki o tọju bọtini API olupese yẹn ni aaye kanna. Ilana nẹtiwọọki apoti iyanrin gbọdọ tun gba aaye ipari olupese laaye.

## Kini ti Docker Desktop ko ba ṣiṣẹ tabi ti dẹkun idahun?

Deepsand ko le bẹrẹ apoti iyanrin laisi ẹrọ Docker. Ti Docker Desktop ko ba ṣiṣẹ, bẹrẹ ki o duro de ẹrọ lati pari ibẹrẹ. Deepsand tun ṣayẹwo nigbati window ba tun ni idojukọ, ati pe rinhoho ipo nfunni ni atunwo.

Nigba miiran Docker Desktop tun nṣiṣẹ ṣugbọn ẹrọ rẹ ti dẹkun idahun. Tun bẹrẹ Deepsand ko ṣe atunṣe pe; Docker Desktop funrararẹ nilo lati tun bẹrẹ.

- **Lo iṣakoso inu-app nigbati o han.** Ti Deepsand ba ṣawari Docker Desktop, o fihan **Tun Docker Desktop bẹrẹ…** ni ipo ipo tabi ikilọ ebute. Iṣakoso yẹn tun bẹrẹ ẹrọ Docker, pẹlu ilana WSL ti o nlo lori Windows, ati duro titi ti eiyan le tun bẹrẹ.
- **Windows:** tẹ-ọtun Docker whale ni agbegbe iwifunni ki o yan **Tun bẹrẹ**. Ti aṣayan yẹn ba sonu, ṣii Docker Desktop, yan **Laasigbotitusita**, lẹhinna **Tun Docker Desktop bẹrẹ**.
- **macOS:** tẹ ẹja Docker ninu ọpa akojọ aṣayan ki o yan **Tun bẹrẹ**.
- **Linux:** ṣii akojọ aṣayan Docker Desktop, yan **Laasigbotitusita**, lẹhinna **Tun Docker Desktop bẹrẹ**. Ti o ba lo Docker Engine dipo Docker Desktop, tun bẹrẹ iṣẹ rẹ, fun apẹẹrẹ `sudo systemctl restart docker`.

Tun bẹrẹ Docker Desktop pari gbogbo eiyan lori ẹrọ, pẹlu awọn apoti ti ko ni ibatan si Deepsand. Deepsand nfunni ni atunbẹrẹ ṣugbọn ko ṣe laifọwọyi. Wo [Docker iwe laasigbotitusita](https://docs.docker.com/desktop/troubleshoot-and-support/troubleshoot/) fun akojọ-ipilẹ kan pato.

## Ṣe MO le lo Deepsand laisi iraye si intanẹẹti?

Awoṣe naa nilo aaye ipari rẹ. Pẹlu ipo nẹtiwọọki `none`, aaye ipari nikan ni o le de ọdọ nipasẹ aṣoju Deepsand. Awọn fifi sori ẹrọ idii ati iraye si nẹtiwọọki miiran yoo kuna ayafi ti o ba gba awọn ogun laaye ti wọn nilo.

## Bawo ni MO ṣe ṣe imudojuiwọn Deepsand?

Ṣii **Eto**, lẹhinna **Awọn imudojuiwọn**, ki o ṣayẹwo fun ẹya tuntun. Itusilẹ ṣe igbasilẹ awọn imudojuiwọn fowo si ati tun bẹrẹ app lẹhin fifi ọkan sii. Fifi imudojuiwọn imudojuiwọn duro ṣiṣiṣẹ awọn apoti iyanrin.

## Njẹ wiwo laini aṣẹ kan wa?

Bẹẹni. `deepsandctl` n pese awọn aṣẹ laini ori gẹgẹbi `doctor`, `plan`, `run`, `watch`, `requests` ati `network`. Ohun elo tabili tabili ati CLI pin koodu eto imulo kanna ni `deepsand-core`.

## Bawo ni MO ṣe jabo ọrọ aabo kan?

Maṣe ṣii ọrọ ti gbogbo eniyan fun iṣoro aabo kan. Kan si awọn olutọju ni ikọkọ nipasẹ ikanni ijabọ aabo ibi ipamọ ati pẹlu awọn alaye ti o to lati ṣe ẹda iṣoro naa.
