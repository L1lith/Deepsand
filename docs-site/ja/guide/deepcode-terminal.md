# DeepCode 端末の使用

Deepsand はサンドボックス内で [DeepCode CLI](https://github.com/lessweb/deepcode-cli) を実行します。 [**ターミナル**] タブはライブ DeepCode セッションです。通常の言語でリクエストを入力するか、DeepCode のスラッシュ コマンドの 1 つを使用してセッションを制御します。

DeepCode を自分のマシンにインストールする必要はありません。 Deepsand は、プロジェクトのコンテナ内で CLI を起動します。ここで、`/workspace` と共有したディレクトリが表示されます。

詳細については、[DeepCode プロジェクトのホームページ](https://deepcode.vegamo.cn/) または [DeepCode リポジトリ](https://github.com/lessweb/deepcode-cli) をご覧ください。

## セッションを開始する

1. サイドバーでプロジェクトを選択します。
2. **走る**を押します。
3. サンドボックスが開始されるまで待ちます。イメージが見つからない場合は、Deepsand が最初にイメージをビルドし、**活動** にビルド出力を表示します。
4. CLI の準備が完了すると、DeepCode 端子が表示されます。

サンドボックスを停止するとコンテナも終了します。プロジェクトを再度開始すると、以前の DeepCode 会話が存在する場合、その会話が再開されます。

## DeepCode に何かを依頼する

通常のリクエストを入力し、**入力** を押します。例えば：

```text
Find the failing test in this project and explain what is wrong.
```

DeepCode は、ワークスペース内のファイルの読み取りと編集、コマンドの実行、プロジェクト用に選択されたツールの使用を行うことができます。常に制御できます。ワークスペースの外で何かが必要になると、Deepsand はサンドボックスを一時停止し、最初に質問します。

## メインのスラッシュコマンド

スラッシュコマンドは `/` で始まります。 「`/`」と単独で入力すると、コマンド メニューが開きます。

|コマンド |何をするのか |
| --- | --- |
| `/new` |新たな会話を始めましょう |
| `/resume` |続行するには前の会話を選択してください |
| `/fork` |現在の会話をフォークする |
| `/continue` |アクティブな会話を続行するか、再開する会話を選択してください |
| `/model` |モデル、思考モード、推論努力を切り替える |
| `/raw` |表示モードを切り替えます: Normal、Lite、または Raw スクロールバック |
| `/init` |プロジェクト手順を含む `AGENTS.md` ファイルを作成する |
| `/skills` | DeepCode が利用できるスキルをリストします |
| `/mcp` | MCP サーバーのステータスと利用可能なツールを表示 |
| `/undo` |コード、会話、またはその両方を以前の時点に復元します。
| `/exit` | DeepCodeをやめる |

プロジェクトにはすでに `AGENTS.md` がある可能性があります。すでに存在する命令を置き換えないように、`/init` を使用する前に確認してください。

## キーボードショートカット

|キー |アクション |
| --- | --- |
| `Enter` |プロンプトを送信 |
| `Shift+Enter` |改行を挿入 |
| `Ctrl+J` |改行を挿入 |
| `Esc` |現在のモデルターンを中断 |
| `Ctrl+V` |選択したモデルが画像をサポートしている場合に画像を貼り付けます |
| `Ctrl+D` 2 回 | DeepCodeをやめる |

`Esc` でターンを中断した後、別のリクエストを入力できます。サンドボックスは再起動されません。

## ターミナルにファイルをドロップする

ファイルをターミナルにドラッグすると、そのパスが入力されます。

- プロジェクト フォルダー内のファイル、またはプロジェクトと共有したディレクトリ内のファイルは、サンドボックスがすでに認識している場所 (`/workspace/...` または `/grants/...`) を参照します。何もコピーされません。
- 他の場所からのファイルはサンドボックス内の `/tmp/deepsand-incoming` にコピーされ、Deepsand が最初に問い合わせます。このフォルダーはリポジトリの一部ではないため、ドロップされたファイルはコミットに含めることができず、サンドボックスが再作成されるとファイルは消えます。ダイアログには **二度と警告しないでください** スイッチがあり、これは **設定 → 動作 → プロジェクト外からファイルをドロップする前に警告する** と同じ設定です。

## 最新情報を維持する

DeepCode CLI はサンドボックス イメージ内にインストールされており、サンドボックス自体を更新できません。各開始前に、Deepsand は npm に最新のリリースが何かを尋ね、イメージに古いリリースがある場合は、最初にイメージのその部分を再構築します。そのため、すでに更新を要求しているバージョンでターミナルが開かれることはありません。答えは 15 分の間記憶されるため、これは実行ごとに 1 つではなく 1 つのリクエストになります。npm に到達できない場合、サンドボックスはすでに存在するバージョンで開始されます。

## セッション、モデル、およびアンドゥ

- `/new` はクリーンな会話からやり直します。プロジェクトファイルは削除されません。
- `/resume` と `/continue` は以前の会話を呼び出します。
- `/model` は、セッションのモデル、思考モード、および推論の労力を変更します。プロジェクト ヘッダーには、モデル セレクターと思考スライダーもあります。 **バランスの取れた** は中間の停止であり、ほとんどの作業に推奨される設定です。
- `/undo` は、コード、会話、またはその両方を以前の時点に復元します。これは、望ましくない変更を元に戻す最も簡単な方法です。

会話履歴は、リポジトリではなく、プロジェクトの Deepsand 状態ボリュームに存在します。

## 権限とサンドボックス

ターミナルはコンテナ内にあるため、`/workspace` にあるプロジェクトと明示的に共有したディレクトリが表示されますが、コンピュータ上にはそれ以外は何も表示されません。

DeepCode が別のディレクトリ、ネットワーク宛先、ツール、または別のリソースを要求すると、Deepsand はサンドボックスをフリーズし、許可ダイアログを表示します。

- **アクセスを許可する** はリクエストを適用し、セッションを再開します。
- **今じゃない** は今回はそれを拒否します。 DeepCode は後でもう一度質問するかもしれません。
- **二度と聞かないでください** はそれを拒否し、Deepsand はそのパス (およびその下のすべて) またはそのホスト (およびそのサブドメイン) 自体を、言葉だけでなく拒否します。すべてのブロックは [アクセス許可] にリストされており、そこで再度解除できます。
- ディレクトリを承認すると、新しいマウントでコンテナが再作成されます。

機密ファイルを含むディレクトリを共有する前に、[サンドボックスの仕組み](./security) をお読みください。

## 端末が起動しない場合

- **画像がありません:** Deepsand が最初にビルドします。ビルドの進行状況については、**活動** を監視してください。
- **Docker Desktop が実行されていないか、スタックしています:** でエンジンを始動し、エンジンの始動が完了するまで待ちます。 Docker Desktop が実行されているが、エンジンが応答しない場合は、Docker Desktop を再起動します。 Deepsand が表示する場合は、アプリ内 **Docker Desktop を再起動します…** コントロールを使用します。それ以外の場合は、Windows で通知領域の Docker クジラを右クリックし、**再起動** を選択します。 macOS では、Docker メニュー バー アイコンを使用します。 Linux で Docker Desktop の **トラブルシューティング** メニューを開きます。 Docker Desktop を再起動すると、マシン上のすべてのコンテナが終了します。 [Docker FAQ](./faq#what-if-docker-desktop-is-not-running-or-has-stopped-responding)を参照してください。
- **API キーが見つからないか拒否されました:** **設定** を開いて有効なキーを保存します。
- **DeepCode が終了しました:** **走る** をもう一度押します。以前のセッションは `/resume` で再開できます。
