# Deepsandとは何ですか?

Deepsand は、AI コーディング アシスタントが独自の別個のワークスペース内でプロジェクトを支援できるデスクトップ アプリです。

別の部屋の作業台と考えてください。あなたは助けが必要なプロジェクトを持ち込みます。アシスタントはその作業台とあなたが渡した材料を使用できますが、家の残りの部分を歩き回ることはできません。

## 何に役立つのか

- Web サイトまたは小さなプログラムのバグを修正します。
- 既存のプロジェクトに機能を追加します。
- 継承したコード、または認識できないコードについて説明します。
- テスト、ドキュメント、または最初の草稿を作成します。
- アシスタントにマシン上の他のすべてへのアクセスを許可せずに、なじみのないリポジトリを探索します。

Docker がどのように機能するかを知る必要はなく、プロの開発者である必要もありません。フォルダを選択してボタンを押せば基本的な流れが利用できます。

## チャット ウィンドウを使用してみませんか?

チャット ウィンドウはコードを提案できますが、プロジェクトを実行したり、その周りのファイルを読んだり、提案が実際に機能するかどうかを確認したりすることはできません。

Deepsand はアシスタントに実際のプロジェクトと実際のツールを提供します。ワークスペースは、コマンドの実行、ファイルの編集、結果のテストを行うことができ、その作業はワークスペースによってコンピューターの他の部分から切り離されます。

## 「独立したワークスペース」とは

アシスタントには、選択したプロジェクト フォルダーと意図的に共有したフォルダーが表示されます。ドキュメント、写真、ダウンロード、他のプロジェクト、パスワード、またはディスクの残りの部分は自動的には表示されません。

ワークスペースの外で何かが必要な場合は、要求する必要があります。 Deepsand はアシスタントを一時停止し、リクエストを表示します。あなたが承認するまでは何も共有されません。

## 誰のためのものなのか

- **コーディングが初めての人:** は、最初にコンテナー ツールを学習せずに、小規模プロジェクトの支援を受けられます。
- **経験豊富な開発者:** は AI エージェントに制限された環境を与え、正確な Docker コマンドを検査し、ネットワークとツールのアクセスを制御します。
- **2本目のハンドが欲しい人は：** は、マシン全体を公開するのではなく、アシスタントを 1 つのプロジェクトに集中させます。

## あなたがコントロールできるもの

- 各プロジェクトが使用するフォルダー。
- アシスタントがアクセスできる追加フォルダー (存在する場合)。
- どの Web サイトに連絡する可能性があるか。
- ワークスペースにインストールされているツール。
- どのモデルと認証情報が使用されるか。
- ワークスペースの開始時と停止時。
