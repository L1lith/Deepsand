# DeepSeek API キーを取得する

Deepsand には、アシスタントを機能させるためのモデル プロバイダーが必要です。デフォルト設定では DeepSeek を使用します。このページでは、アカウントの作成、クレジットの追加、API キーの作成、Deepsand への保存の手順を説明します。

別のプロバイダーからの API キーをすでにお持ちの場合は、[すでに持っているキーを使用する](#use-a-key-you-already-have) に進んでください。

## 始める前に

必要なものは次のとおりです。

- 電子メール アドレスまたはサポートされているサインイン アカウント。
- API クレジットの支払い方法。
- キーを作成して Deepsand に貼り付けるには数分かかります。

DeepSeek API は、DeepSeek チャット Web サイトおよびモバイル アプリとは別に請求されます。 API プラットフォームにクレジットを追加すると、アシスタントがリクエストを行うことができるようになります。

## 1. DeepSeekアカウントを作成する

1. [DeepSeek API プラットフォーム](https://platform.deepseek.com/) を開きます。
2. **サインアップ** または **ログイン** を選択します。
3. 電子メール アドレスを使用してアカウントを作成するか、サポートされているサインイン オプションのいずれかを使用します。
4. プラットフォームから要求された場合は、メール アドレスまたは電話番号を確認します。

## 2. クレジットを追加する

1. API プラットフォームにサインインします。
2. ダッシュボードで請求またはチャージセクションを開きます。
3. 使用するクレジットの量を追加します。
4. 支払いを完了してください。

API の使用量はこの残高から差し引かれます。プラットフォームには、現在の残高、使用量、価格が表示されます。 Deepsand を試している間は、少量から始めてください。後でさらに追加することもできます。

## 3. API キーを作成します

1. プラットフォームの **API キー** セクションを開きます。
2. **新しい API キーを作成する** または同等のボタンを選択します。
3. キーに、**Deepsand** などのわかりやすい名前を付けます。
4. キーを作成し、すぐにコピーします。

通常、キーは 1 回だけ表示されます。これをパスワードのように扱います。それを持っている人は誰でもあなたのアカウントのクレジットを使用できます。

## 4. キーを Deepsand に保存します

1. Deepsand を開きます。
2. **設定** を開きます。
3. デフォルトの認証情報の下にある **APIキー** フィールドを見つけます。
4. キーを貼り付けます。
5. **キーを保存**を選択します。

Deepsand は、設定ファイルではなく、オペレーティング システムのキーストアにキーを保存します。保存後、ウィンドウには最後の 4 文字のみが表示されるため、キーを再度公開することなく、キーが存在することを確認できます。

アプリ全体のキーは、ホスト DeepCode 構成もプロジェクトも独自のキーを提供しない場合に使用されます。プロジェクト レベルのキーが引き続き優先されます。

## すでに持っているキーを使用する

すでに API キーを持っている場合は、DeepSeek アカウントを作成する必要はありません。

- すべてのプロジェクトでこれを使用するには、**設定** を開き、**APIキー** フィールドにキーを入力して保存します。
- 別のエンドポイントまたはモデルを使用するには、**設定** またはプロジェクト独自の資格情報でベース URL とモデルも設定します。
- 1 つのプロジェクトに対してのみキーを保持するには、代わりにそのプロジェクトの設定を開いてそこにキーを入力します。

プロバイダーは、DeepCode CLI が呼び出すことができる API を公開する必要があります。 DeepSeek 以外のプロバイダーを使用している場合は、DeepSeek のデフォルトではなく、そのベース URL とモデル名を入力します。

## 何かがうまくいかない場合

- **キーが拒否されました:** は、プラットフォーム上に新しいキーを作成し、保存されているキーを置き換えます。
- **残高が空です:** は API アカウントにクレジットを追加します。チャットのサブスクリプションによって、API の使用料が自動的に支払われるわけではありません。
- **アシスタントがプロバイダーに接続できません:** プロジェクトのネットワーク モードと許可リストを確認します。モデルのエンドポイントに到達できる必要があります。
- **キーを削除したい場合:** **設定** を開き、**キーを削除します** を選択します。
