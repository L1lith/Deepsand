# ダウンロード Deepsand

Deepsand は、Windows、macOS、Linux で使用できます。このページではお使いのシステムが検出されますが、別のマシンにダウンロードする場合は、別のプラットフォームを選択できます。

<DownloadPicker />

## インストールする前に

- Deepsand は Docker を使用して、独自のサンドボックスで各プロジェクトを実行します。 Docker Desktop を Windows または macOS にインストールするか、Docker Engine を Linux にインストールします。
- モデル API キーが必要です。 [DeepSeek API キーを取得する](./guide/deepseek-api)、または既存のプロバイダー キーを使用します。
- 最初の起動ではサンドボックス イメージを構築できますが、これには数分かかる場合があります。

## インストール後

1. Deepsandを起動します。
2. **設定** を開き、モデルの API キーを保存します。
3. プロジェクトを作成し、その作業ディレクトリを選択します。
4. **走る** を押してサンドボックスを開始します。

完全な初回実行ウォークスルーについては、[はじめる](./guide/getting-started) をお読みください。
