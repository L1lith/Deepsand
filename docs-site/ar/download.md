# تحميل Deepsand

Deepsand متاح لـ Windows وmacOS وLinux. تكتشف الصفحة نظامك، ولكن يمكنك اختيار نظام أساسي آخر إذا كنت تقوم بالتنزيل لجهاز مختلف.

<DownloadPicker />

## قبل التثبيت

- يستخدم Deepsand Docker لتشغيل كل مشروع في وضع الحماية الخاص به. قم بتثبيت Docker Desktop على Windows أو macOS أو Docker Engine على Linux.
- ستحتاج إلى مفتاح طراز API. [احصل على مفتاح DeepSeek API](./guide/deepseek-api)، أو استخدم مفتاح الموفر الموجود.
- يمكن أن يؤدي الإطلاق الأول إلى إنشاء صورة وضع الحماية، الأمر الذي قد يستغرق بضع دقائق.

## بعد التثبيت

1. ابدأ تشغيل Deepsand.
2. افتح **إعدادات** واحفظ مفتاح API للطراز الخاص بك.
3. قم بإنشاء مشروع واختيار دليل العمل الخاص به.
4. اضغط على **يجري** لبدء وضع الحماية.

اقرأ [ابدء](./guide/getting-started) للاطلاع على الإرشادات الكاملة للتشغيل الأول.
