# احصل على مفتاح DeepSeek API

يحتاج Deepsand إلى موفر نموذج لتشغيل المساعد. يستخدم التكوين الافتراضي DeepSeek. تستعرض هذه الصفحة كيفية إنشاء حساب وإضافة رصيد وإنشاء مفتاح API وحفظه في Deepsand.

إذا كان لديك بالفعل مفتاح API من موفر آخر، فانتقل إلى [استخدم المفتاح الذي لديك بالفعل](#use-a-key-you-already-have).

## قبل أن تبدأ

سوف تحتاج إلى:

- عنوان بريد إلكتروني أو حساب تسجيل دخول مدعوم.
- طريقة دفع للحصول على رصيد API.
- بضع دقائق لإنشاء المفتاح ولصقه في Deepsand.

يتم إصدار فاتورة DeepSeek API بشكل منفصل عن موقع الدردشة DeepSeek وتطبيق الهاتف المحمول. إن إضافة رصيد على منصة API هو ما يسمح للمساعد بتقديم الطلبات.

## 1. قم بإنشاء حساب DeepSeek

1. افتح [منصة DeepSeek API](https://platform.deepseek.com/).
2. حدد **اشتراك** أو **تسجيل الدخول**.
3. قم بإنشاء حساب باستخدام عنوان بريدك الإلكتروني، أو استخدم أحد خيارات تسجيل الدخول المدعومة.
4. تحقق من عنوان بريدك الإلكتروني أو رقم هاتفك إذا طلبت منك المنصة ذلك.

## 2. أضف رصيدًا

1. قم بتسجيل الدخول إلى منصة API.
2. افتح قسم الفوترة أو تعبئة الرصيد في لوحة التحكم.
3. أضف مبلغ الرصيد الذي تريد استخدامه.
4. أكمل الدفع.

يتم خصم استخدام API من هذا الرصيد. تعرض المنصة الرصيد الحالي والاستخدام والتسعير. ابدأ بكمية صغيرة أثناء تجربة Deepsand؛ يمكنك إضافة المزيد لاحقا.

## 3. قم بإنشاء مفتاح API

1. افتح قسم **مفاتيح API** بالمنصة.
2. حدد **قم بإنشاء مفتاح API جديد** أو الزر المعادل.
3. قم بتسمية المفتاح باسم ستتعرف عليه، مثل **Deepsand**.
4. قم بإنشاء المفتاح ونسخه على الفور.

عادة ما يتم عرض المفتاح مرة واحدة فقط. تعامل معها ككلمة مرور: يمكن لأي شخص لديه هذه الكلمة أن ينفق الرصيد في حسابك.

## 4. احفظ المفتاح في Deepsand

1. افتح Deepsand.
2. افتح **إعدادات**.
3. ابحث عن الحقل **مفتاح API** ضمن بيانات الاعتماد الافتراضية.
4. الصق المفتاح.
5. حدد **حفظ المفتاح**.

يقوم Deepsand بتخزين المفتاح في مخزن المفاتيح الخاص بنظام التشغيل الخاص بك، وليس في ملف الإعدادات الخاص به. تعرض النافذة الأحرف الأربعة الأخيرة فقط بعد الحفظ، لذا يمكنك التأكد من وجود المفتاح دون الكشف عنه مرة أخرى.

يتم استخدام المفتاح على مستوى التطبيق عندما لا يوفر تكوين المضيف DeepCode أو المشروع مفتاحًا خاصًا به. لا يزال المفتاح على مستوى المشروع له الأسبقية.

## استخدم المفتاح الذي لديك بالفعل

إذا كان لديك بالفعل مفتاح API، فلن تحتاج إلى إنشاء حساب DeepSeek.

- لاستخدامه في كل مشروع، افتح **إعدادات**، وأدخل المفتاح في حقل **مفتاح API**، واحفظه.
- لاستخدام نقطة نهاية أو نموذج مختلف، قم أيضًا بتعيين عنوان URL الأساسي والنموذج في **إعدادات** أو في بيانات الاعتماد الخاصة بالمشروع.
- للاحتفاظ بمفتاح لمشروع واحد فقط، افتح إعدادات هذا المشروع وأدخله هناك بدلاً من ذلك.

يجب أن يعرض الموفر API الذي يمكن لـ DeepCode CLI الاتصال به. إذا كنت تستخدم موفر خدمة غير DeepSeek، فأدخل عنوان URL الأساسي واسم الطراز الخاص به بدلاً من إعدادات DeepSeek الافتراضية.

## إذا كان هناك شيء لا يعمل

- يقوم **المفتاح مرفوض:** بإنشاء مفتاح جديد على النظام الأساسي واستبدال المفتاح المخزن.
- **الرصيد فارغ:** إضافة رصيد إلى حساب API. لا يقوم اشتراك الدردشة بتمويل استخدام API تلقائيًا.
- **لا يمكن للمساعد الوصول إلى الموفر:** تحقق من وضع الشبكة والقائمة المسموح بها للمشروع. يجب أن تكون نقطة نهاية النموذج قابلة للوصول.
- **تريد إزالة المفتاح:** افتح **إعدادات** وحدد **إزالة المفتاح**.
