# باستخدام محطة DeepCode

يقوم Deepsand بتشغيل [DeepCode CLI](https://github.com/lessweb/deepcode-cli) داخل صندوق الحماية. علامة التبويب **صالة** هي جلسة DeepCode مباشرة: اكتب طلبًا باللغة العادية، أو استخدم أحد أوامر الشرطة المائلة في DeepCode للتحكم في الجلسة.

لا تقم بتثبيت DeepCode على جهازك الخاص. يقوم Deepsand بتشغيل CLI في حاوية المشروع، حيث يمكنه رؤية `/workspace` والأدلة التي قمت بمشاركتها.

تعرف على المزيد على [الصفحة الرئيسية لمشروع DeepCode](https://deepcode.vegamo.cn/) أو في [مستودع DeepCode](https://github.com/lessweb/deepcode-cli).

## ابدأ جلسة

1. حدد مشروعًا في الشريط الجانبي.
2. اضغط على **يجري**.
3. انتظر حتى يبدأ وضع الحماية. إذا كانت الصورة مفقودة، فإن Deepsand ينشئها أولاً ويعرض مخرجات البناء في **نشاط**.
4. تظهر محطة DeepCode عندما يكون CLI جاهزًا.

يؤدي إيقاف وضع الحماية إلى إنهاء الحاوية. يؤدي بدء المشروع مرة أخرى إلى استئناف محادثة DeepCode السابقة عند وجودها.

## اطلب من DeepCode أن يفعل شيئًا ما

اكتب طلبًا عاديًا ثم اضغط على **يدخل**. على سبيل المثال:

```text
Find the failing test in this project and explain what is wrong.
```

يمكن لـ DeepCode قراءة الملفات وتحريرها في مساحة العمل، وتشغيل الأوامر، واستخدام الأدوات المحددة للمشروع. يمكنك البقاء متحكمًا: عندما يحتاج إلى شيء ما خارج مساحة العمل، يقوم Deepsand بإيقاف صندوق الحماية مؤقتًا ويطلب منك أولاً.

## أوامر القطع الرئيسية

تبدأ أوامر الشرطة المائلة بـ `/`. تؤدي كتابة `/` من تلقاء نفسها إلى فتح قائمة الأوامر.

| الأمر | ماذا يفعل |
| --- | --- |
| `/new` | ابدأ محادثة جديدة |
| `/resume` | اختر محادثة سابقة للمتابعة |
| `/fork` | شوكة المحادثة الحالية |
| `/continue` | أكمل المحادثة النشطة، أو اختر محادثة لاستئنافها |
| `/model` | تبديل النموذج وطريقة التفكير وجهد الاستدلال |
| `/raw` | تبديل وضع العرض: التمرير العادي أو البسيط أو الخام |
| `/init` | قم بإنشاء ملف `AGENTS.md` مع تعليمات المشروع |
| `/skills` | اذكر المهارات المتاحة لـ DeepCode |
| `/mcp` | إظهار حالة خادم MCP والأدوات المتاحة |
| `/undo` | استعادة الكود المحادثة أو كليهما إلى نقطة سابقة |
| `/exit` | قم بإنهاء DeepCode |

قد يكون لدى المشروع بالفعل `AGENTS.md`؛ تحقق قبل استخدام `/init` حتى لا تستبدل التعليمات الموجودة بالفعل.

## اختصارات لوحة المفاتيح

| مفتاح | العمل |
| --- | --- |
| `Enter` | أرسل الموجه |
| `Shift+Enter` | أدخل سطرًا جديدًا |
| `Ctrl+J` | أدخل سطرًا جديدًا |
| `Esc` | مقاطعة منعطف النموذج الحالي |
| `Ctrl+V` | قم بلصق صورة عندما يدعم النموذج المحدد الصور |
| `Ctrl+D` مرتين | قم بإنهاء DeepCode |

بعد مقاطعة المنعطف باستخدام `Esc`، يمكنك كتابة طلب آخر. لم يتم إعادة تشغيل وضع الحماية.

## الجلسات والنماذج والتراجع

- يبدأ `/new` من جديد بمحادثة نظيفة. لا يتم حذف ملفات المشروع.
- يعيد `/resume` و`/continue` محادثة سابقة.
- يقوم `/model` بتغيير النموذج وطريقة التفكير وجهد التفكير في الجلسة. يحتوي رأس المشروع أيضًا على محدد نموذج وشريط تمرير للتفكير؛ **متوازن** هي المحطة الوسطى والإعداد الموصى به لمعظم الأعمال.
- يقوم `/undo` باستعادة الكود أو المحادثة أو كليهما إلى نقطة سابقة. إنها أسرع طريقة للتراجع عن التغيير الذي لم تريده.

يوجد سجل المحادثة في وحدة تخزين حالة Deepsand الخاصة بالمشروع، وليس في المستودع الخاص بك.

## الأذونات ووضع الحماية

الوحدة الطرفية موجودة داخل الحاوية، لذا فهي ترى المشروع في `/workspace` والمجلدات التي قمت بمشاركتها بشكل صريح، ولا شيء آخر على جهاز الكمبيوتر الخاص بك.

عندما يطلب DeepCode دليلاً آخر أو وجهة شبكة أو أداة أو مورد آخر، يقوم Deepsand بتجميد صندوق الحماية ويعرض مربع حوار الأذونات.

- يقوم **منح الوصول** بتطبيق الطلب واستئناف الجلسة.
- يرفض **ينكر** ذلك ويخبر DeepCode أن القرار نهائي.
- تؤدي الموافقة على الدليل إلى إعادة إنشاء الحاوية بالتركيب الجديد.

اقرأ [كيف يعمل صندوق الرمل](./security) قبل مشاركة دليل يحتوي على ملفات حساسة.

## إذا لم تبدأ المحطة

- **الصورة مفقودة:** Deepsand يبنيها أولاً. شاهد **نشاط** للتعرف على تقدم البناء.
- قم بتشغيل **Docker Desktop لا يعمل أو أنه عالق:** وانتظر حتى ينتهي المحرك من التشغيل. إذا كان Docker Desktop قيد التشغيل ولكن محركه لا يجيب، فأعد تشغيل Docker Desktop. استخدم عنصر التحكم **إعادة تشغيل Docker Desktop...** داخل التطبيق عندما يعرضه Deepsand. بخلاف ذلك، في Windows، انقر بزر الماوس الأيمن فوق الحوت Docker في منطقة الإعلام واختر **إعادة تشغيل**؛ على macOS، استخدم رمز شريط القائمة Docker؛ على Linux، افتح قائمة Docker Desktop الخاصة بـ **استكشاف الأخطاء وإصلاحها**. تؤدي إعادة تشغيل Docker Desktop إلى إنهاء كل حاوية على الجهاز. انظر [الأسئلة الشائعة حول Docker](./faq#what-if-docker-desktop-is-not-running-or-has-stopped-responding).
- **مفتاح API مفقود أو مرفوض:** افتح **إعدادات** واحفظ مفتاحًا صالحًا.
- **تم الخروج من DeepCode:** اضغط على **يجري** مرة أخرى. يمكن استئناف الجلسة السابقة باستخدام `/resume`.
