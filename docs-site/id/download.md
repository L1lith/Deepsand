# Unduh Deepsand

Deepsand tersedia untuk Windows, macOS dan Linux. Halaman tersebut mendeteksi sistem Anda, tetapi Anda dapat memilih platform lain jika Anda mengunduh untuk mesin lain.

<DownloadPicker />

## Sebelum Anda menginstal

- Deepsand menggunakan Docker untuk menjalankan setiap proyek di kotak pasirnya sendiri. Instal Docker Desktop di Windows atau macOS, atau Docker Engine di Linux.
- Anda memerlukan kunci model API. [Dapatkan kunci DeepSeek API](./guide/deepseek-api), atau gunakan kunci penyedia yang ada.
- Peluncuran pertama dapat membuat gambar sandbox, yang mungkin memerlukan waktu beberapa menit.

## Setelah Anda menginstal

1. Mulai Deepsand.
2. Buka **Pengaturan** dan simpan kunci API model Anda.
3. Buat proyek dan pilih direktori kerjanya.
4. Tekan **Berlari** untuk memulai kotak pasir.

Baca [Memulai](./guide/getting-started) untuk panduan lengkap pertama kali dijalankan.

## Semua rilis

Jika versi terbaru masih diterbitkan, atau Anda memerlukan versi yang lebih lama, buka
[Halaman rilis GitHub](https://github.com/L1lith/Deepsand/releases).
