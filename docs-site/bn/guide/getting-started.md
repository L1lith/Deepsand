# শুরু হচ্ছে

Deepsand আপনাকে আপনার কম্পিউটারের বাকি অংশে সেই সহকারীকে অ্যাক্সেস না দিয়ে একটি বাস্তব প্রকল্পে একজন AI কোডিং সহকারীর সাথে কাজ করতে সহায়তা করে৷ মৌলিক প্রবাহ ব্যবহার করার জন্য আপনাকে Docker বা কমান্ড লাইন বোঝার দরকার নেই।

আপনি যদি প্রথমে বড় ছবি চান, [Deepsand কি?](./what-is-deepsand) পড়ুন।

## প্রয়োজনীয়তা

- Docker Desktop Windows বা macOS, অথবা Linux-এ Docker Engine।
- একটি Windows, macOS বা Linux কম্পিউটার। [ডাউনলোড পাতা](../download) সিস্টেমটি সনাক্ত করে এবং মিলিত ইনস্টলারদের তালিকা করে।
- আপনি উৎস থেকে Deepsand নির্মাণ না করা পর্যন্ত কোন Node.js বা Rust ইনস্টলেশনের প্রয়োজন নেই।

Deepsand একটি স্যান্ডবক্স শুরু করার আগে Docker Desktop অবশ্যই চলমান থাকবে৷ যদি ডেমন এখনও শুরু হয়, স্ট্যাটাস স্ট্রিপ তাই বলে এবং আবার চেক করার প্রস্তাব দেয়। Docker Desktop চলমান কিন্তু প্রতিক্রিয়াহীন হতে পারে; যদি Deepsand বলে ডেমন উত্তর দিচ্ছে না, Docker Desktop পুনরায় চালু করুন। যখন Deepsand Docker Desktop সনাক্ত করে তখন এটি একটি **Docker Desktop পুনরায় চালু করুন...** নিয়ন্ত্রণ দেখায়। [Docker Desktop চলমান না হলে বা সাড়া দেওয়া বন্ধ করলে কী করবেন](./faq#what-if-docker-desktop-is-not-running-or-has-stopped-responding) দেখুন।

## ইনস্টল করুন

[Deepsand ডাউনলোড পৃষ্ঠা](../download) খুলুন। এটি আপনার অপারেটিং সিস্টেম সনাক্ত করে এবং বর্তমান GitHub রিলিজ থেকে সর্বশেষ Windows, macOS এবং Linux ইনস্টলারদের তালিকা করে। আপনার কম্পিউটারের জন্য প্যাকেজটি চয়ন করুন, এটি ইনস্টল করুন, তারপর Deepsand শুরু করুন৷

আপনি যদি নিজেই Deepsand ডেভেলপ করেন, রিপোজিটরি README-এ সোর্স-বিল্ড এবং হট-রিলোড কমান্ড রয়েছে।

## প্রথম রান

Deepsand ব্যবহার করার আগে আপনার DeepCode ইনস্টল বা কনফিগার করার দরকার নেই৷ Deepsand স্যান্ডবক্সের ভিতরে DeepCode চালায় এবং মডেল এবং এন্ডপয়েন্টের জন্য বুদ্ধিমান ডিফল্টের সাথে আসে।

আপনার প্রয়োজন একটি মডেল API কী। পরবর্তী বিভাগে ব্যাখ্যা করা হয়েছে কিভাবে একটি DeepSeek কী পেতে হয়, অথবা আপনি অন্য প্রদানকারীর কাছ থেকে একটি কী ব্যবহার করতে পারেন। এটি **সেটিংস → API কী** এ সংরক্ষণ করুন।

যদি আপনি ইতিমধ্যেই এই কম্পিউটারে DeepCode CLI ব্যবহার করেন, তাহলে Deepsand আপনার বিদ্যমান DeepCode কনফিগারেশন থেকে মডেল, বেস URL এবং কী উত্তরাধিকারী হতে পারে। একটি প্রকল্প তার নিজস্ব সেটিংসে সেই শংসাপত্রগুলিকে ওভাররাইড করতে পারে।

## একটি API কী পান

সহকারী চালানোর আগে Deepsand একটি মডেল প্রদানকারীর থেকে একটি API কী প্রয়োজন৷

- **আপনার যদি একটি না থাকে:** [একটি DeepSeek API কী পান](./deepseek-api) অনুসরণ করুন। এটি একটি অ্যাকাউন্ট তৈরি করে, ক্রেডিট যোগ করে, একটি কী তৈরি করে এবং Deepsand-এ ফিরে আসে।
- **আপনার যদি ইতিমধ্যে একটি থাকে:** **সেটিংস** খুলুন, এটি **API কী** ক্ষেত্রে পেস্ট করুন এবং **কী সংরক্ষণ করুন** নির্বাচন করুন।
- **আপনি যদি একটি প্রকল্প-নির্দিষ্ট কী চান:** সেই প্রকল্পের সেটিংস খুলুন এবং পরিবর্তে এটি সেখানে প্রবেশ করুন৷

অ্যাপ-ওয়াইড কী আপনার অপারেটিং সিস্টেমের কীস্টোরে রাখা হয়, Deepsand-এর স্টেট ফাইলে নয়। উইন্ডোটি সংরক্ষণ করার পরে শুধুমাত্র শেষ চারটি অক্ষর দেখায়।

## একটি প্রকল্প তৈরি করুন

1. সাইডবারে **নতুন প্রকল্প** নির্বাচন করুন।
2. প্রকল্পের একটি নাম দিন।
3. কাজের ডিরেক্টরি নির্বাচন করুন।
4. প্রকল্পটি তৈরি করুন।

কাজের ডিরেক্টরি স্যান্ডবক্সের ভিতরে `/workspace` হয়ে যায়। Deepsand ফাইল সিস্টেম রুট, আপনার হোম ডিরেক্টরি, শংসাপত্রের দোকান এবং এর নিজস্ব ডেটা ডিরেক্টরির মতো পাথগুলি প্রত্যাখ্যান করে।

## একটি মডেল চয়ন করুন

বেশিরভাগ কাজের জন্য একটি **ফ্ল্যাশ মডেল** ব্যবহার করুন। Deepsand ডিফল্ট `deepseek-v4-flash`, যা দৈনন্দিন কোডিং, ব্যাখ্যা এবং সম্পাদনার জন্য সস্তা পছন্দ। `deepseek-v4-pro`-এ স্যুইচ করুন শুধুমাত্র তখনই যখন ফ্ল্যাশ কোনো কাজের সাথে স্পষ্টভাবে লড়াই করছে; প্রো মডেল চালানোর জন্য আরো খরচ.

আপনি **সেটিংস**-এ মডেল পরিবর্তন করতে পারেন, প্রোজেক্ট হেডার থেকে, অথবা DeepCode টার্মিনালে `/model` দিয়ে।

## একটি চিন্তার স্তর চয়ন করুন

থিংকিং স্লাইডারটি প্রজেক্ট হেডারে মডেল নির্বাচকের পাশে। মডেলটি উত্তর দেওয়ার আগে কতটা যুক্তি করে তা নিয়ন্ত্রণ করে।

- **বন্ধ:** কোন চিন্তা নেই। দ্রুততম, কিন্তু সর্বনিম্ন সতর্কতা.
- **দ্রুত:** একটু চিন্তাভাবনা, ছোট সুনির্দিষ্ট সম্পাদনার জন্য।
- **সুষম:** মধ্যপন্থী চিন্তা এবং মধ্যম স্টপ। এটি বাস্তব কাজের জন্য বুদ্ধিমান ডিফল্ট।
- **গভীর:** সর্বাধিক যুক্তি। সবচেয়ে ধীর এবং সবচেয়ে ব্যয়বহুল।
- **ডিফল্ট:** হোস্ট `settings.json` কে ডিফার করুন; যদি এটি কিছু না বলে, DeepCode ব্যালেন্সড-এ ফিরে আসে।

বেশিরভাগ কাজের জন্য **সুষম**-এ স্লাইডার রাখুন। এটি প্রতিটি অনুরোধে সবচেয়ে ধীর, সবচেয়ে ব্যয়বহুল যুক্তির জন্য অর্থ প্রদান না করেই ভাল ফলাফল দেয়। শুধুমাত্র সত্যিকারের কঠিন সমস্যার জন্য **গভীর** ব্যবহার করুন এবং ছোট, অনুমানযোগ্য সম্পাদনার জন্য **বন্ধ** বা **দ্রুত** ব্যবহার করুন।

## একটি প্রকল্প চালান

1. প্রকল্প নির্বাচন করুন.
2. **চালান** টিপুন।
3. ছবিটি অনুপস্থিত থাকলে, Deepsand প্রথমে এটি তৈরি করে এবং কার্যকলাপ ট্যাবে বিল্ড আউটপুট দেখায়।
4. DeepCode CLI কন্টেইনারের ভিতরে শুরু হয় এবং টার্মিনালে প্রদর্শিত হয়।

স্যান্ডবক্স থামানো ধারক শেষ হয়. এটি আবার শুরু করা পূর্ববর্তী DeepCode সেশন পুনরায় শুরু করে যখন একটি বিদ্যমান থাকে।

## DeepCode টার্মিনাল ব্যবহার করে

**টার্মিনাল** ট্যাব হল লাইভ DeepCode CLI সেশন। একটি অনুরোধ টাইপ করুন এবং **প্রবেশ করুন** টিপুন, অথবা সেশন নিয়ন্ত্রণ করতে একটি স্ল্যাশ কমান্ড ব্যবহার করুন। `/new` একটি নতুন কথোপকথন শুরু করে, `/resume` আগেরটি চালিয়ে যায়, `/model` মডেল পরিবর্তন করে, এবং `/` কমান্ড মেনু খোলে।

প্রধান কমান্ড, কীবোর্ড শর্টকাট এবং পুনরুদ্ধারের পদক্ষেপের জন্য [DeepCode টার্মিনাল ব্যবহার করে](./deepcode-terminal) পড়ুন।

## অনুমতি অনুরোধের উত্তর

যখন DeepCode একটি ডিরেক্টরি, একটি নেটওয়ার্ক গন্তব্য, একটি টুল বা অন্য সম্পদ প্রয়োজন, Deepsand স্যান্ডবক্স বিরতি দেয় এবং অনুরোধ দেখায়।

- **অ্যাক্সেস মঞ্জুর করুন** অনুরোধের অনুমতি দেয় এবং সেশন পুনরায় শুরু করে।
- **এখন না** এবার তা প্রত্যাখ্যান করেছে; মডেল পরে আবার জিজ্ঞাসা করতে পারে.
- **আবার জিজ্ঞাসা করবেন না** এটি প্রত্যাখ্যান করে, এবং Deepsand তারপর সেই পথ (এবং এটির অধীনে থাকা সমস্ত কিছু) বা সেই হোস্ট (এবং এর সাবডোমেনগুলি) নিজেই প্রত্যাখ্যান করে, শুধু কথায় নয়। প্রতিটি ব্লক অনুমতিতে তালিকাভুক্ত করা হয়েছে, যেখানে আপনি এটি আবার তুলতে পারেন।
- একটি ডিরেক্টরি অনুদান নতুন মাউন্ট সংযুক্ত করে ধারকটিকে পুনরায় তৈরি করে।

সংবেদনশীল ফাইল রয়েছে এমন একটি ডিরেক্টরিতে অ্যাক্সেস দেওয়ার আগে [স্যান্ডবক্স কিভাবে কাজ করে](./security) পড়ুন।
