# একটি DeepSeek API কী পান

Deepsand সহকারীকে পাওয়ার জন্য একটি মডেল প্রদানকারীর প্রয়োজন৷ ডিফল্ট কনফিগারেশন DeepSeek ব্যবহার করে। এই পৃষ্ঠাটি একটি অ্যাকাউন্ট তৈরি করা, ক্রেডিট যোগ করা, একটি API কী তৈরি করা এবং এটি Deepsand-এ সংরক্ষণ করে।

যদি আপনার কাছে ইতিমধ্যেই অন্য প্রদানকারীর থেকে একটি API কী থাকে, তাহলে [আপনার কাছে ইতিমধ্যে একটি কী ব্যবহার করুন](#use-a-key-you-already-have) এ যান।

## আপনি শুরু করার আগে

আপনার প্রয়োজন হবে:

- একটি ইমেল ঠিকানা বা একটি সমর্থিত সাইন-ইন অ্যাকাউন্ট৷
- API ক্রেডিট এর জন্য একটি পেমেন্ট পদ্ধতি।
- কী তৈরি করতে এবং এটিকে Deepsand-এ পেস্ট করতে কয়েক মিনিট।

DeepSeek API ডিপসিক চ্যাট ওয়েবসাইট এবং মোবাইল অ্যাপ থেকে আলাদাভাবে বিল করা হয়। API প্ল্যাটফর্মে ক্রেডিট যোগ করা সহকারীকে অনুরোধ করতে দেয়।

## 1. একটি DeepSeek অ্যাকাউন্ট তৈরি করুন৷

1. [DeepSeek API প্ল্যাটফর্ম](https://platform.deepseek.com/) খুলুন।
2. **সাইন আপ করুন** বা **লগ ইন করুন** নির্বাচন করুন।
3. আপনার ইমেল ঠিকানা দিয়ে একটি অ্যাকাউন্ট তৈরি করুন, বা সমর্থিত সাইন-ইন বিকল্পগুলির একটি ব্যবহার করুন৷
4. প্ল্যাটফর্ম আপনাকে জিজ্ঞাসা করলে আপনার ইমেল ঠিকানা বা ফোন নম্বর যাচাই করুন।

## 2. ক্রেডিট যোগ করুন

1. API প্ল্যাটফর্মে সাইন ইন করুন।
2. ড্যাশবোর্ডে বিলিং বা টপ-আপ বিভাগটি খুলুন।
3. আপনি ব্যবহার করতে চান ক্রেডিট পরিমাণ যোগ করুন.
4. পেমেন্ট সম্পূর্ণ করুন।

API ব্যবহার এই ব্যালেন্স থেকে কাটা হয়। প্ল্যাটফর্মটি বর্তমান ব্যালেন্স, ব্যবহার এবং মূল্য দেখায়। আপনি Deepsand চেষ্টা করার সময় অল্প পরিমাণ দিয়ে শুরু করুন; আপনি পরে আরো যোগ করতে পারেন.

## 3. একটি API কী তৈরি করুন৷

1. প্ল্যাটফর্মের **API কী** বিভাগটি খুলুন।
2. **নতুন API কী তৈরি করুন** বা সমতুল্য বোতাম নির্বাচন করুন।
3. কীটিকে আপনি চিনতে পারবেন এমন একটি নাম দিন, যেমন **Deepsand**।
4. কী তৈরি করুন এবং অবিলম্বে অনুলিপি করুন।

কী সাধারণত একবারই দেখানো হয়। এটিকে একটি পাসওয়ার্ডের মতো ব্যবহার করুন: যার কাছে এটি আছে তারা আপনার অ্যাকাউন্টে ক্রেডিট ব্যয় করতে পারে৷

## 4. Deepsand এ কী সংরক্ষণ করুন

1. Deepsand খুলুন।
2. **সেটিংস** খুলুন।
3. ডিফল্ট শংসাপত্রের অধীনে **API কী** ক্ষেত্রটি খুঁজুন।
4. কী পেস্ট করুন।
5. **কী সংরক্ষণ করুন** নির্বাচন করুন।

Deepsand আপনার অপারেটিং সিস্টেমের কীস্টোরে কী সংরক্ষণ করে, তার সেটিংস ফাইলে নয়। উইন্ডোটি সংরক্ষণ করার পরে শুধুমাত্র শেষ চারটি অক্ষর দেখায়, যাতে আপনি নিশ্চিত করতে পারেন যে একটি কী আবার প্রকাশ না করে উপস্থিত রয়েছে।

অ্যাপ-ওয়াইড কী ব্যবহার করা হয় যখন হোস্ট DeepCode কনফিগারেশন বা কোনও প্রকল্প তার নিজস্ব কী সরবরাহ করে না। একটি প্রকল্প-স্তরের কী এখনও অগ্রাধিকার নেয়।

## আপনার কাছে ইতিমধ্যে একটি কী ব্যবহার করুন

আপনার যদি ইতিমধ্যেই একটি API কী থাকে তবে আপনাকে একটি DeepSeek অ্যাকাউন্ট তৈরি করতে হবে না।

- প্রতিটি প্রকল্পের জন্য এটি ব্যবহার করতে, **সেটিংস** খুলুন, **API কী** ক্ষেত্রে কী লিখুন এবং এটি সংরক্ষণ করুন।
- একটি ভিন্ন এন্ডপয়েন্ট বা মডেল ব্যবহার করতে, **সেটিংস** বা প্রকল্পের নিজস্ব শংসাপত্রে ভিত্তি URL এবং মডেল সেট করুন৷
- শুধুমাত্র একটি প্রকল্পের জন্য একটি কী রাখতে, সেই প্রকল্পের সেটিংস খুলুন এবং পরিবর্তে এটি সেখানে প্রবেশ করুন৷

প্রদানকারীকে অবশ্যই একটি API প্রকাশ করতে হবে যা DeepCode CLI কল করতে পারে৷ আপনি যদি একটি নন-DeepSeek প্রদানকারী ব্যবহার করেন, তাহলে DeepSeek ডিফল্টের পরিবর্তে এর ভিত্তি URL এবং মডেলের নাম লিখুন।

## কিছু কাজ না হলে

- **কী প্রত্যাখ্যান করা হয়েছে:** প্ল্যাটফর্মে একটি নতুন কী তৈরি করুন এবং সঞ্চিত একটি প্রতিস্থাপন করুন।
- **ভারসাম্য খালি:** API অ্যাকাউন্টে ক্রেডিট যোগ করুন। একটি চ্যাট সাবস্ক্রিপশন স্বয়ংক্রিয়ভাবে API ব্যবহারের অর্থ প্রদান করে না।
- **সহকারী প্রদানকারীর কাছে পৌঁছাতে পারে না:** প্রকল্পের নেটওয়ার্ক মোড এবং অনুমোদিত তালিকা পরীক্ষা করুন। মডেল এন্ডপয়েন্ট অবশ্যই পৌঁছাতে হবে।
- **আপনি কীটি সরাতে চান:** **সেটিংস** খুলুন এবং **চাবি সরান** নির্বাচন করুন।
