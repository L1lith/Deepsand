# DeepCode টার্মিনাল ব্যবহার করে

Deepsand স্যান্ডবক্সের ভিতরে [DeepCode CLI](https://github.com/lessweb/deepcode-cli) চালায়। **টার্মিনাল** ট্যাব হল একটি লাইভ DeepCode সেশন: সাধারণ ভাষায় একটি অনুরোধ টাইপ করুন, অথবা সেশন নিয়ন্ত্রণ করতে DeepCode-এর স্ল্যাশ কমান্ডগুলির একটি ব্যবহার করুন৷

আপনি আপনার নিজের মেশিনে DeepCode ইনস্টল করবেন না। Deepsand প্রকল্পের কন্টেইনারে CLI শুরু করে, যেখানে এটি `/workspace` এবং আপনার শেয়ার করা ডিরেক্টরিগুলি দেখতে পারে৷

[DeepCode প্রকল্পের হোম পেজ](https://deepcode.vegamo.cn/) বা [DeepCode সংগ্রহস্থল](https://github.com/lessweb/deepcode-cli)-এ আরও জানুন।

## একটি অধিবেশন শুরু করুন

1. সাইডবারে একটি প্রকল্প নির্বাচন করুন।
2. **চালান** টিপুন।
3. স্যান্ডবক্স শুরু হওয়ার জন্য অপেক্ষা করুন। ছবিটি অনুপস্থিত থাকলে, Deepsand প্রথমে এটি তৈরি করে এবং **কার্যকলাপ**-এ বিল্ড আউটপুট দেখায়।
4. DeepCode টার্মিনাল উপস্থিত হয় যখন CLI প্রস্তুত হয়।

স্যান্ডবক্স থামানো ধারক শেষ হয়. প্রজেক্ট শুরু করলে পূর্ববর্তী DeepCode কথোপকথনটি পুনরায় শুরু হয় যখন একটি বিদ্যমান থাকে।

## DeepCode কে কিছু করতে বলুন

একটি সাধারণ অনুরোধ টাইপ করুন এবং **প্রবেশ করুন** টিপুন। যেমন:

```text
Find the failing test in this project and explain what is wrong.
```

DeepCode কর্মক্ষেত্রে ফাইলগুলি পড়তে এবং সম্পাদনা করতে পারে, কমান্ড চালাতে পারে এবং প্রকল্পের জন্য নির্বাচিত সরঞ্জামগুলি ব্যবহার করতে পারে। আপনি নিয়ন্ত্রণে থাকুন: যখন এটির কর্মক্ষেত্রের বাইরে কিছুর প্রয়োজন হয়, Deepsand স্যান্ডবক্সে বিরতি দেয় এবং প্রথমে আপনাকে জিজ্ঞাসা করে।

## প্রধান স্ল্যাশ কমান্ড

স্ল্যাশ কমান্ড `/` দিয়ে শুরু হয়। `/` নিজে থেকে টাইপ করলে কমান্ড মেনু খোলে।

| আদেশ | এটা কি করে |
| --- | --- |
| `/new` | একটি নতুন কথোপকথন শুরু করুন |
| `/resume` | চালিয়ে যেতে একটি পূর্ববর্তী কথোপকথন চয়ন করুন |
| `/fork` | বর্তমান কথোপকথন কাঁটা |
| `/continue` | সক্রিয় কথোপকথন চালিয়ে যান, অথবা পুনরায় শুরু করতে একটি বেছে নিন |
| `/model` | মডেল, চিন্তা মোড এবং যুক্তি প্রচেষ্টা স্যুইচ করুন |
| `/raw` | ডিসপ্লে মোড টগল করুন: সাধারণ, লাইট বা কাঁচা স্ক্রলব্যাক |
| `/init` | প্রকল্প নির্দেশাবলী সহ একটি `AGENTS.md` ফাইল তৈরি করুন |
| `/skills` | DeepCode এর কাছে উপলব্ধ দক্ষতা তালিকাভুক্ত করুন |
| `/mcp` | MCP সার্ভারের স্থিতি এবং উপলব্ধ সরঞ্জামগুলি দেখান |
| `/undo` | কোড, কথোপকথন বা উভয়ই একটি আগের পয়েন্টে পুনরুদ্ধার করুন |
| `/exit` | DeepCode প্রস্থান করুন |

একটি প্রকল্প ইতিমধ্যে একটি `AGENTS.md` থাকতে পারে; `/init` ব্যবহার করার আগে চেক করুন যাতে আপনি ইতিমধ্যে সেখানে থাকা নির্দেশাবলী প্রতিস্থাপন না করেন।

## কীবোর্ড শর্টকাট

| কী | কর্ম |
| --- | --- |
| `Enter` | প্রম্পট পাঠান |
| `Shift+Enter` | একটি নতুন লাইন ঢোকান |
| `Ctrl+J` | একটি নতুন লাইন ঢোকান |
| `Esc` | বর্তমান মডেল পালা বাধা |
| `Ctrl+V` | নির্বাচিত মডেল যখন ছবি সমর্থন করে তখন একটি ছবি আটকান |
| `Ctrl+D` দুবার | DeepCode প্রস্থান করুন |

`Esc` দিয়ে একটি পালা বাধা দেওয়ার পরে, আপনি অন্য অনুরোধ টাইপ করতে পারেন। স্যান্ডবক্স পুনরায় আরম্ভ করা হয় না.

## সেশন, মডেল এবং পূর্বাবস্থায় ফেরান

- `/new` একটি পরিষ্কার কথোপকথন দিয়ে শুরু হয়। প্রকল্প ফাইল মুছে ফেলা হয় না.
- `/resume` এবং `/continue` একটি আগের কথোপকথন ফিরিয়ে আনে।
- `/model` সেশনের জন্য মডেল, চিন্তার মোড এবং যুক্তি প্রচেষ্টা পরিবর্তন করে। প্রজেক্ট হেডারে একটি মডেল নির্বাচক এবং একটি চিন্তা স্লাইডার রয়েছে; **সুষম** হল মধ্যম স্টপ এবং বেশিরভাগ কাজের জন্য প্রস্তাবিত সেটিং।
- `/undo` কোড, কথোপকথন বা উভয়কেই আগের পয়েন্টে পুনরুদ্ধার করে। আপনি চান না এমন পরিবর্তন থেকে ফিরে আসার দ্রুততম উপায়।

কথোপকথনের ইতিহাস প্রকল্পের Deepsand স্টেট ভলিউমে থাকে, আপনার সংগ্রহস্থলে নয়।

## অনুমতি এবং স্যান্ডবক্স

টার্মিনালটি কন্টেইনারের ভিতরে রয়েছে, তাই এটি `/workspace`-এ প্রজেক্ট এবং আপনি স্পষ্টভাবে শেয়ার করা ডিরেক্টরিগুলি এবং আপনার কম্পিউটারে অন্য কিছু দেখতে পায় না।

যখন DeepCode অন্য একটি ডিরেক্টরি, একটি নেটওয়ার্ক গন্তব্য, একটি টুল বা অন্য সম্পদের জন্য জিজ্ঞাসা করে, তখন Deepsand স্যান্ডবক্স ফ্রিজ করে এবং একটি অনুমতি ডায়ালগ দেখায়।

- **অ্যাক্সেস মঞ্জুর করুন** অনুরোধটি প্রয়োগ করে এবং সেশন পুনরায় শুরু করে।
- **অস্বীকার করুন** এটি প্রত্যাখ্যান করে এবং DeepCode কে বলে যে সিদ্ধান্তটি চূড়ান্ত।
- একটি ডিরেক্টরি অনুমোদন করা নতুন মাউন্টের সাথে ধারকটিকে পুনরায় তৈরি করে।

সংবেদনশীল ফাইল রয়েছে এমন একটি ডিরেক্টরি শেয়ার করার আগে [স্যান্ডবক্স কিভাবে কাজ করে](./security) পড়ুন।

## টার্মিনাল চালু না হলে

- **ছবিটি অনুপস্থিত:** Deepsand প্রথমে এটি তৈরি করে। নির্মাণের অগ্রগতির জন্য **কার্যকলাপ** দেখুন।
- **Docker Desktop চলছে না বা আটকে আছে:** এটি শুরু করুন এবং ইঞ্জিন শুরু হওয়া শেষ হওয়ার জন্য অপেক্ষা করুন। যদি Docker Desktop চলছে কিন্তু এর ইঞ্জিন উত্তর দিচ্ছে না, তাহলে Docker Desktop পুনরায় চালু করুন। যখন Deepsand এটি দেখায় তখন ইন-অ্যাপ **Docker Desktop পুনরায় চালু করুন...** নিয়ন্ত্রণ ব্যবহার করুন। অন্যথায়, Windows-এ বিজ্ঞপ্তি এলাকায় Docker তিমিতে ডান-ক্লিক করুন এবং **রিস্টার্ট করুন** নির্বাচন করুন; macOS-এ Docker মেনু বার আইকন ব্যবহার করুন; Linux-এ Docker Desktop-এর **সমস্যা সমাধান** মেনু খুলুন। Docker Desktop পুনঃসূচনা করা হলে মেশিনের প্রতিটি কন্টেইনার শেষ হয়ে যায়। [Docker FAQ](./faq#what-if-docker-desktop-is-not-running-or-has-stopped-responding) দেখুন।
- **API কী অনুপস্থিত বা প্রত্যাখ্যাত:** **সেটিংস** খুলুন এবং একটি বৈধ কী সংরক্ষণ করুন।
- **DeepCode প্রস্থান হয়েছে:** আবার **চালান** টিপুন। আগের সেশন `/resume` দিয়ে আবার শুরু করা যেতে পারে।
