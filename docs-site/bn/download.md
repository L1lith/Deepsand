# Deepsand ডাউনলোড করুন

Deepsand Windows, macOS এবং Linux এর জন্য উপলব্ধ। পৃষ্ঠাটি আপনার সিস্টেম শনাক্ত করে, কিন্তু আপনি যদি একটি ভিন্ন মেশিনের জন্য ডাউনলোড করেন তবে আপনি অন্য প্ল্যাটফর্ম বেছে নিতে পারেন।

<DownloadPicker />

## আপনি ইনস্টল করার আগে

- Deepsand Docker ব্যবহার করে প্রতিটি প্রকল্পের নিজস্ব স্যান্ডবক্সে চালানোর জন্য। Windows বা macOS-এ Docker Desktop, বা Linux-এ Docker Engine ইনস্টল করুন।
- আপনি একটি মডেল API কী প্রয়োজন হবে. [একটি DeepSeek API কী পান](./guide/deepseek-api), অথবা একটি বিদ্যমান প্রদানকারী কী ব্যবহার করুন।
- প্রথম লঞ্চটি স্যান্ডবক্স চিত্র তৈরি করতে পারে, যা কয়েক মিনিট সময় নিতে পারে।

## আপনি ইনস্টল করার পরে

1. Deepsand শুরু করুন।
2. **সেটিংস** খুলুন এবং আপনার মডেল API কী সংরক্ষণ করুন।
3. একটি প্রকল্প তৈরি করুন এবং এর কার্যকারী ডিরেক্টরি নির্বাচন করুন।
4. স্যান্ডবক্স শুরু করতে **চালান** টিপুন।

সম্পূর্ণ প্রথম-রানের ওয়াকথ্রুটির জন্য [শুরু হচ্ছে](./guide/getting-started) পড়ুন।
