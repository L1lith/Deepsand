# DeepSeek API 키 받기

Deepsand는 어시스턴트에 전원을 공급하기 위해 모델 제공자가 필요합니다. 기본 구성은 DeepSeek를 사용합니다. 이 페이지에서는 계정 생성, 크레딧 추가, API 키 생성 및 Deepsand에 저장하는 과정을 안내합니다.

다른 제공업체의 API 키가 이미 있는 경우 [이미 가지고 있는 키를 사용하세요](#use-a-key-you-already-have)로 건너뛰세요.

## 시작하기 전에

다음이 필요합니다.

- 이메일 주소 또는 지원되는 로그인 계정.
- API 크레딧 결제 방법입니다.
- 키를 생성하고 Deepsand에 붙여넣는 데 몇 분 정도 걸립니다.

DeepSeek API는 DeepSeek 채팅 웹사이트 및 모바일 앱과 별도로 요금이 청구됩니다. API 플랫폼에 크레딧을 추가하면 보조자가 요청할 수 있습니다.

## 1. DeepSeek 계정 만들기

1. [DeepSeek API 플랫폼](https://platform.deepseek.com/)를 엽니다.
2. **가입** 또는 **로그인**를 선택합니다.
3. 이메일 주소로 계정을 만들거나 지원되는 로그인 옵션 중 하나를 사용하세요.
4. 플랫폼에서 요청하는 경우 이메일 주소나 전화번호를 확인하세요.

## 2. 크레딧 추가

1. API 플랫폼에 로그인합니다.
2. 대시보드에서 청구 또는 충전 섹션을 엽니다.
3. 사용하려는 크레딧 금액을 추가하세요.
4. 결제를 완료하세요.

API 사용량은 이 잔액에서 차감됩니다. 플랫폼에는 현재 잔액, 사용량 및 가격이 표시됩니다. Deepsand를 시도하는 동안 소량으로 시작하십시오. 나중에 더 추가할 수 있습니다.

## 3. API 키 생성

1. 플랫폼의 **API 키** 섹션을 엽니다.
2. **새로운 API 키 생성** 또는 이에 상응하는 버튼을 선택합니다.
3. 키에 **Deepsand**와 같이 인식할 수 있는 이름을 지정하십시오.
4. 키를 생성하고 즉시 복사하세요.

키는 일반적으로 한 번만 표시됩니다. 이를 비밀번호처럼 취급하십시오. 비밀번호를 알고 있는 사람은 누구나 귀하의 계정에서 크레딧을 사용할 수 있습니다.

## 4. Deepsand에 키를 저장합니다.

1. Deepsand를 엽니다.
2. **설정**를 엽니다.
3. 기본 자격 증명 아래에서 **API 키** 필드를 찾으세요.
4. 키를 붙여넣으세요.
5. **키 저장**를 선택합니다.

Deepsand는 설정 파일이 아닌 운영 체제의 키 저장소에 키를 저장합니다. 창에는 저장 후 마지막 4개 문자만 표시되므로 키를 다시 노출하지 않고도 키가 존재하는지 확인할 수 있습니다.

앱 전체 키는 호스트 DeepCode 구성이나 프로젝트가 자체 키를 제공하지 않을 때 사용됩니다. 프로젝트 수준 키가 여전히 우선 적용됩니다.

## 이미 가지고 있는 키를 사용하세요

API 키가 이미 있는 경우 DeepSeek 계정을 만들 필요가 없습니다.

- 모든 프로젝트에 사용하려면 **설정**를 열고 **API 키** 필드에 키를 입력한 후 저장하세요.
- 다른 엔드포인트나 모델을 사용하려면 **설정** 또는 프로젝트 자체 자격 증명에서 기본 URL과 모델도 설정하세요.
- 하나의 프로젝트에 대해서만 키를 유지하려면 해당 프로젝트의 설정을 열고 대신 입력하세요.

공급자는 DeepCode CLI가 호출할 수 있는 API를 노출해야 합니다. DeepSeek가 아닌 공급자를 사용하는 경우 DeepSeek 기본값 대신 기본 URL과 모델 이름을 입력하십시오.

## 뭔가 작동하지 않는 경우

- **키가 거부되었습니다.**는 플랫폼에서 새 키를 생성하고 저장된 키를 교체합니다.
- **잔액이 비어 있습니다.**는 API 계정에 크레딧을 추가합니다. 채팅 구독은 API 사용량에 자동으로 자금을 지원하지 않습니다.
- **어시스턴트가 제공자에게 연락할 수 없습니다:**는 프로젝트의 네트워크 모드와 허용 목록을 확인합니다. 모델 엔드포인트에 도달할 수 있어야 합니다.
- **키를 제거하고 싶습니다.** **설정**를 열고 **키 제거**를 선택합니다.
