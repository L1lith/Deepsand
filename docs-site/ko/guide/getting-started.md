# 시작하기

Deepsand는 AI 코딩 도우미에게 컴퓨터의 나머지 부분에 대한 액세스 권한을 부여하지 않고도 실제 프로젝트에서 AI 코딩 도우미와 함께 작업할 수 있도록 도와줍니다. 기본 흐름을 사용하기 위해 Docker 또는 명령줄을 이해할 필요는 없습니다.

먼저 더 큰 그림을 원한다면 [Deepsand란 무엇입니까?](./what-is-deepsand)를 읽어보세요.

## 요구사항

- Windows 또는 macOS의 Docker Desktop 또는 Linux의 Docker Engine.
- Windows, macOS 또는 Linux 컴퓨터. [다운로드 페이지](../download)는 시스템을 감지하고 일치하는 설치 프로그램을 나열합니다.
- 소스에서 Deepsand를 빌드하지 않는 한 Node.js 또는 Rust 설치가 필요하지 않습니다.

Deepsand가 샌드박스를 시작하려면 먼저 Docker Desktop가 실행되고 있어야 합니다. 데몬이 여전히 시작 중이면 상태 표시줄에 그렇게 표시되고 다시 확인하라는 메시지가 표시됩니다. Docker Desktop는 실행 중이지만 응답하지 않을 수도 있습니다. Deepsand에서 데몬이 응답하지 않는다고 표시되면 Docker Desktop를 다시 시작하세요. Deepsand가 Docker Desktop를 감지하면 **Docker Desktop를 다시 시작하세요...** 컨트롤이 표시됩니다. [Docker Desktop가 실행되지 않거나 응답을 멈춘 경우 수행할 작업](./faq#what-if-docker-desktop-is-not-running-or-has-stopped-responding)를 참조하세요.

## 설치하다

[Deepsand 다운로드 페이지](../download)를 엽니다. 운영 체제를 감지하고 현재 GitHub 릴리스의 최신 Windows, macOS 및 Linux 설치 프로그램을 나열합니다. 컴퓨터에 맞는 패키지를 선택하고 설치한 다음 Deepsand를 시작하세요.

Deepsand 자체를 개발하는 경우 README 저장소에 source-build 및 hot-reload 명령이 있습니다.

## 첫 번째 실행

Deepsand를 사용하기 전에 DeepCode를 설치하거나 구성할 필요는 없습니다. Deepsand는 샌드박스 내에서 DeepCode를 실행하고 모델 및 엔드포인트에 대한 합리적인 기본값을 제공합니다.

필요한 것은 모델 API 키입니다. 다음 섹션에서는 DeepSeek 키를 얻는 방법을 설명합니다. 또는 다른 공급자의 키를 사용할 수도 있습니다. **설정 → API 키**에 저장하세요.

이 컴퓨터에서 이미 DeepCode CLI를 사용하고 있는 경우 Deepsand는 대신 기존 DeepCode 구성에서 모델, 기본 URL 및 키를 상속할 수 있습니다. 프로젝트는 자체 설정에서 해당 자격 증명을 재정의할 수도 있습니다.

## API 키 받기

Deepsand는 어시스턴트를 실행하기 전에 모델 제공자의 API 키가 필요합니다.

- **가지고 있지 않은 경우:**는 [DeepSeek API 키 받기](./deepseek-api)를 따릅니다. 계정 생성, 크레딧 추가, 키 생성 및 Deepsand로 돌아가는 과정을 안내합니다.
- **이미 갖고 있는 경우:** **설정**를 열고 **API 키** 필드에 붙여넣은 다음 **키 저장**를 선택합니다.
- **프로젝트별 키를 원하는 경우:**는 해당 프로젝트의 설정을 열고 대신 입력합니다.

앱 전체 키는 Deepsand의 상태 파일이 아닌 운영 체제의 키 저장소에 보관됩니다. 창에는 저장 후 마지막 4개 문자만 표시됩니다.

## 프로젝트 만들기

1. 사이드바에서 **새 프로젝트**를 선택합니다.
2. 프로젝트 이름을 지정하십시오.
3. 작업 디렉터리를 선택합니다.
4. 프로젝트를 생성합니다.

작업 디렉터리는 샌드박스 내부에서 `/workspace`가 됩니다. Deepsand는 파일 시스템 루트, 홈 디렉터리, 자격 증명 저장소 및 자체 데이터 디렉터리와 같은 경로를 거부합니다.

## 모델을 선택하세요

대부분의 작업에는 **플래시 모델**를 사용하십시오. Deepsand의 기본값은 `deepseek-v4-flash`로, 일상적인 코딩, 설명 및 편집에 가장 저렴한 선택입니다. 플래시가 작업에 어려움을 겪고 있는 경우에만 `deepseek-v4-pro`로 전환하십시오. 프로 모델은 실행하는 데 더 많은 비용이 듭니다.

**설정**, 프로젝트 헤더에서 또는 DeepCode 터미널의 `/model`를 사용하여 모델을 변경할 수 있습니다.

## 사고 수준을 선택하세요

생각 슬라이더는 프로젝트 헤더의 모델 선택기 옆에 있습니다. 모델이 응답하기 전에 얼마나 많은 추론을 수행하는지 제어합니다.

- **끄다:** 생각하지 마세요. 가장 빠르지만 가장 조심스럽지 않습니다.
- **빠른:**는 잘 지정된 작은 편집을 위해 약간의 생각을 합니다.
- **균형:** 적당한 사고와 중간 정지. 이는 실제 작업에 적합한 기본값입니다.
- **깊은:** 최대 추론. 가장 느리고 가장 비쌉니다.
- **기본:**는 호스트 `settings.json`를 따릅니다. 아무 말도 하지 않으면 DeepCode는 Balanced로 돌아갑니다.

대부분의 작업에서는 슬라이더를 **균형 잡힌**에 유지하세요. 모든 요청에 ​​대해 가장 느리고 가장 비용이 많이 드는 추론 비용을 지불하지 않고도 좋은 결과를 제공합니다. 정말 어려운 문제에만 **깊은**를 사용하고, 작고 예측 가능한 편집에는 **끄다** 또는 **빠른**를 사용하세요.

## 프로젝트 실행

1. 프로젝트를 선택합니다.
2. **달리다**를 누르세요.
3. 이미지가 누락된 경우 Deepsand는 먼저 이미지를 빌드하고 활동 탭에 빌드 출력을 표시합니다.
4. DeepCode CLI는 컨테이너 내부에서 시작하여 터미널에 나타납니다.

샌드박스를 중지하면 컨테이너가 종료됩니다. 다시 시작하면 이전 DeepCode 세션이 있으면 다시 시작됩니다.

## DeepCode 터미널 사용

**단말기** 탭은 라이브 DeepCode CLI 세션입니다. 요청을 입력하고 **입력하다**를 누르거나 슬래시 명령을 사용하여 세션을 제어하십시오. `/new`는 새로운 대화를 시작하고, `/resume`는 이전 대화를 계속하고, `/model`는 모델을 변경하고, `/`는 명령 메뉴를 엽니다.

주요 명령, 키보드 단축키 및 복구 단계에 대해서는 [DeepCode 터미널 사용](./deepcode-terminal)를 읽어보세요.

## 권한 요청에 응답

DeepCode에 디렉터리, 네트워크 대상, 도구 또는 다른 리소스가 필요한 경우 Deepsand는 샌드박스를 일시 중지하고 요청을 표시합니다.

- **액세스 권한 부여**는 요청을 허용하고 세션을 재개합니다.
- **부인하다**는 이를 거부하고 결정이 최종적이라고 모델에 알립니다.
- 디렉터리 권한 부여는 새 마운트가 연결된 컨테이너를 다시 만듭니다.

민감한 파일이 포함된 디렉토리에 대한 액세스 권한을 부여하기 전에 [샌드박스 작동 방식](./security)를 읽으십시오.

## 물건을 찾을 수 있는 곳

| 면적 | 그것이 보여주는 것 |
| --- | --- |
| 터미널 | 샌드박스 내부의 라이브 DeepCode 세션. |
| 권한 | 공유 디렉터리, 네트워크 허용 목록 및 감사 추적. |
| 도구 | 프로젝트 이미지에 포함된 도구입니다. 선택 항목을 변경하면 이미지가 다시 작성됩니다. |
| 비밀 | 암호화된 값은 시작 시 환경 변수로 주입됩니다. |
| 활동 | 정확한 `docker run` 인수, 빌드 로그 및 차단된 송신 시도. |
