# Deepsand란 무엇입니까?

Deepsand는 AI 코딩 도우미가 별도의 작업 공간 내에서 프로젝트를 도울 수 있는 데스크톱 앱입니다.

다른 방에 있는 작업대라고 생각해보세요. 도움을 원하는 프로젝트를 가져옵니다. 조수는 작업대와 당신이 건네주는 재료를 사용할 수 있지만 집의 나머지 부분을 돌아다닐 수는 없습니다.

## 어떤 용도로 유용합니까?

- 웹사이트나 작은 프로그램의 버그를 수정합니다.
- 기존 프로젝트에 기능을 추가합니다.
- 상속받았거나 인식할 수 없는 코드를 설명합니다.
- 테스트, 문서 또는 초안 작성.
- 보조자에게 컴퓨터의 다른 모든 항목에 대한 액세스 권한을 부여하지 않고 익숙하지 않은 저장소를 탐색합니다.

Docker가 어떻게 작동하는지 알 필요도 없고, 시작하기 위해 전문 개발자가 될 필요도 없습니다. 폴더를 선택하고 버튼을 누르면 기본 흐름을 이용할 수 있습니다.

## 왜 채팅창을 사용하지 않는 걸까요?

채팅 창은 코드를 제안할 수 있지만 프로젝트를 실행하거나 주변의 파일을 읽거나 제안이 실제로 작동하는지 확인할 수는 없습니다.

Deepsand는 조수에게 실제 프로젝트와 실제 도구를 제공합니다. 명령을 실행하고, 파일을 편집하고, 결과를 테스트할 수 있는 동시에 작업 공간은 해당 작업을 컴퓨터의 나머지 부분과 분리합니다.

## "별도의 작업 공간"이 의미하는 것

도우미는 귀하가 선택한 프로젝트 폴더와 귀하가 의도적으로 공유한 폴더를 볼 수 있습니다. 문서, 사진, 다운로드, 기타 프로젝트, 비밀번호 또는 디스크의 나머지 부분은 자동으로 표시되지 않습니다.

작업 공간 외부에서 필요한 것이 있으면 물어봐야 합니다. Deepsand는 어시스턴트를 일시 중지하고 요청을 표시합니다. 승인할 때까지는 아무 것도 공유되지 않습니다.

## 누구를 위한 것인가

- **코딩을 처음 접하는 사람들:** 컨테이너 도구를 먼저 배우지 않고도 소규모 프로젝트에 대한 도움을 받을 수 있습니다.
- **숙련된 개발자:**는 AI 에이전트에 제한된 환경을 제공하고 정확한 Docker 명령을 검사하며 네트워크 및 도구 액세스를 제어합니다.
- **두 번째 손을 원하는 사람:** 전체 시스템을 노출하는 대신 보조자가 하나의 프로젝트에 집중하도록 합니다.

## 당신이 통제할 수 있는 것

- 각 프로젝트가 사용하는 폴더입니다.
- 어시스턴트가 접근할 수 있는 추가 폴더(있는 경우)
- 어떤 웹사이트에 접속할 수 있는지.
- 작업공간에 어떤 도구가 설치되어 있나요?
- 어떤 모델과 자격 증명이 사용됩니까?
- 작업공간이 시작되고 중지될 때.
