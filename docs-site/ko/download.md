# Deepsand 다운로드

Deepsand는 Windows, macOS 및 Linux에 사용할 수 있습니다. 페이지에서 시스템을 감지하지만 다른 시스템용으로 다운로드하는 경우 다른 플랫폼을 선택할 수 있습니다.

<DownloadPicker />

## 설치하기 전에

- Deepsand는 Docker를 사용하여 자체 샌드박스에서 각 프로젝트를 실행합니다. Windows 또는 macOS에 Docker Desktop를 설치하거나 Linux에 Docker Engine를 설치합니다.
- 모델 API 키가 필요합니다. [DeepSeek API 키 받기](./guide/deepseek-api)를 사용하거나 기존 공급자 키를 사용하세요.
- 처음 실행하면 샌드박스 이미지를 빌드할 수 있으며 이 작업에는 몇 분 정도 걸릴 수 있습니다.

## 설치한 후

1. Deepsand를 시작합니다.
2. **설정**를 열고 모델 API 키를 저장합니다.
3. 프로젝트를 생성하고 작업 디렉터리를 선택합니다.
4. 샌드박스를 시작하려면 **달리다**를 누르세요.

전체 첫 실행 연습을 보려면 [시작하기](./guide/getting-started)를 읽어보세요.
