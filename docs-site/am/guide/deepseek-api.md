# DeepSeek API ቁልፍ ያግኙ

Deepsand ረዳቱን ለማብቃት ሞዴል አቅራቢ ያስፈልገዋል። ነባሪ ውቅር DeepSeekን ይጠቀማል። ይህ ገጽ አካውንት በመፍጠር፣ ክሬዲት በመጨመር፣ API ቁልፍ በመስራት እና በDeepsand ውስጥ በማስቀመጥ ያልፋል።

ከሌላ አቅራቢ የAPI ቁልፍ ካለዎት ወደ [አስቀድመው ያለዎትን ቁልፍ ይጠቀሙ](#use-a-key-you-already-have) ይዝለሉ።

## ከመጀመርዎ በፊት

ያስፈልግዎታል:

- የኢሜል አድራሻ ወይም የሚደገፍ የመግቢያ መለያ።
- ለ API ክሬዲት የመክፈያ ዘዴ።
- ቁልፉን ለመፍጠር ጥቂት ደቂቃዎች እና ወደ Deepsand ለጥፍ።

DeepSeek API ከ DeepSeek ቻት ድህረ ገጽ እና የሞባይል መተግበሪያ ተለይቶ ይከፈላል። በ API መድረክ ላይ ክሬዲት መጨመር ረዳቱ እንዲጠይቅ የሚፈቅደው ነው።

## 1. DeepSeek መለያ ይፍጠሩ

1. [DeepSeek API መድረክ](https://platform.deepseek.com/) ን ይክፈቱ።
2. **ይመዝገቡ** ወይም **ግባ** ን ይምረጡ።
3. በኢሜል አድራሻዎ መለያ ይፍጠሩ ወይም ከሚደገፉት የመግቢያ አማራጮች ውስጥ አንዱን ይጠቀሙ።
4. መድረኩ ከጠየቀዎት የኢሜል አድራሻዎን ወይም የስልክ ቁጥርዎን ያረጋግጡ።

## 2. ክሬዲት አክል

1. ወደ API መድረክ ይግቡ።
2. በዳሽቦርዱ ውስጥ የሂሳብ አከፋፈል ወይም የመሙያ ክፍልን ይክፈቱ።
3. ለመጠቀም የሚፈልጉትን የብድር መጠን ያክሉ።
4. ክፍያውን ያጠናቅቁ.

የAPI አጠቃቀም ከዚህ ቀሪ ሂሳብ ተቀንሷል። መድረኩ የአሁኑን ቀሪ ሂሳብ፣ አጠቃቀም እና ዋጋ ያሳያል። Deepsand በሚሞክሩበት ጊዜ በትንሽ መጠን ይጀምሩ; በኋላ ላይ ተጨማሪ ማከል ይችላሉ.

## 3. የ API ቁልፍ ይፍጠሩ

1. የመድረኩን **API ቁልፎች** ክፍል ይክፈቱ።
2. **አዲስ የAPI ቁልፍ ፍጠር** ወይም ተመጣጣኝ ቁልፍን ይምረጡ።
3. እንደ **Deepsand** ያለ እርስዎ የሚያውቁትን ስም ለቁልፉ ይስጡት።
4. ቁልፉን ይፍጠሩ እና ወዲያውኑ ይቅዱት.

ቁልፉ ብዙውን ጊዜ አንድ ጊዜ ብቻ ነው የሚታየው. እንደ የይለፍ ቃል ያዙት፡ ማንኛውም ያለው ሰው ክሬዲቱን በሂሳብዎ ላይ ማውጣት ይችላል።

## 4. ቁልፉን በ Deepsand ውስጥ ያስቀምጡ

1. Deepsand ን ይክፈቱ።
2. **ቅንብሮች** ን ይክፈቱ።
3. በነባሪ ምስክርነቶች ስር የ **API ቁልፍ** መስክን ያግኙ።
4. ቁልፉን ለጥፍ።
5. **ቁልፍ አስቀምጥ** ን ይምረጡ።

Deepsand ቁልፉን የሚያከማቻል በእርስዎ የስርዓተ ክወና ቁልፍ ማከማቻ ውስጥ እንጂ በሴቲንግ ፋይሉ ውስጥ አይደለም። መስኮቱ ከተቀመጠ በኋላ የመጨረሻዎቹን አራት ቁምፊዎች ብቻ ያሳያል, ስለዚህ ቁልፉን እንደገና ሳያጋልጡ መኖሩን ማረጋገጥ ይችላሉ.

የመተግበሪያ-ሰፊው ቁልፍ ጥቅም ላይ የሚውለው የአስተናጋጁ DeepCode ውቅርም ሆነ አንድ ፕሮጀክት የራሱን ቁልፍ ሲያቀርብ ነው። የፕሮጀክት ደረጃ ቁልፍ አሁንም ይቀድማል።

## አስቀድመው ያለዎትን ቁልፍ ይጠቀሙ

የAPI ቁልፍ ካለህ DeepSeek መለያ መፍጠር አያስፈልግህም።

- ለእያንዳንዱ ፕሮጀክት ለመጠቀም፣ **ቅንብሮች** ን ይክፈቱ፣ ቁልፉን በ**API ቁልፍ** መስክ ያስገቡ እና ያስቀምጡት።
- የተለየ የመጨረሻ ነጥብ ወይም ሞዴል ለመጠቀም መሰረታዊ URL እና ሞዴሉን በ**ቅንብሮች** ወይም በፕሮጄክቱ በራሱ ምስክርነቶች ላይ ያቀናብሩ።
- ቁልፍን ለአንድ ፕሮጀክት ብቻ ለማቆየት የፕሮጀክቱን መቼቶች ይክፈቱ እና በምትኩ እዚያ ያስገቡት።

አቅራቢው DeepCode CLI ሊደውልለት የሚችለውን API ማጋለጥ አለበት። DeepSeek ያልሆነን አቅራቢ እየተጠቀሙ ከሆነ ከ DeepSeek ነባሪዎች ይልቅ የዋናውን URL እና የሞዴል ስም ያስገቡ።

## የሆነ ነገር ካልሰራ

- **ቁልፉ ውድቅ ተደርጓል፡-** በመድረክ ላይ አዲስ ቁልፍ ይፍጠሩ እና የተቀመጠውን ይተኩ.
- **ሚዛኑ ባዶ ነው፡-** ወደ API መለያ ክሬዲት ይጨምሩ። የውይይት ምዝገባ ለAPI አጠቃቀም በራስ-ሰር የገንዘብ ድጋፍ አይሰጥም።
- **ረዳቱ አቅራቢውን ማግኘት አይችልም፡-** የፕሮጀክቱን የአውታረ መረብ ሁኔታ እና የፍቃድ ዝርዝርን ያረጋግጡ። የአምሳያው የመጨረሻ ነጥብ ሊደረስበት የሚችል መሆን አለበት.
- **ቁልፉን ማስወገድ ይፈልጋሉ፡-** **ቅንብሮች** ን ይክፈቱ እና **ቁልፍ አስወግድ** ን ይምረጡ።
