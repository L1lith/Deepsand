# በመከለያው ስር

ይህ ገጽ የስርዓቱን ቴክኒካዊ ቅርፅ ለሚፈልጉ ገንቢዎች ነው። ግልጽ የሆነ የቋንቋ ማብራሪያ እየፈለጉ ከሆነ፣ በ[Deepsand ምንድን ነው?](./what-is-deepsand) ይጀምሩ።

## አርክቴክቸር

Deepsand ሶስት ዋና ንብርብሮች ያሉት የታውሪ ዴስክቶፕ መተግበሪያ ነው።

- **መስኮቱ** የ SolidJS በይነገጽ ነው። ግዛት ይሰጣል እና intents ይልካል; ፖሊሲን አይወስንም.
- **የ Tauri ንብርብር** የዴስክቶፕ ትዕዛዞችን ያጋልጣል እና ተመሳሳይ የትዕዛዝ ገጽን ወደ loopback HTTP አገልጋይ ለርቀት ደንበኞች ይተረጉመዋል።
- **`deepsand-core`** የደንቦቹ ባለቤት ነው። የመንገዱ ማረጋገጫ፣ የ`docker run` ዕቅድ፣ የፈቃድ ደላላ፣ የኢግሬስ ተኪ፣ የተመሰጠረ ሚስጥራዊ መደብር እና የግዛት ማከማቻ ሁሉም እዚያ ይኖራሉ።

የዴስክቶፕ አፕሊኬሽኑ እና የትእዛዝ መስመር ሾፌሩ `deepsandctl` ተመሳሳዩን ኮር ይጠቀማሉ፣ ስለዚህ በደህንነት ውሳኔ ሊለያዩ አይችሉም።

## አንድ ፕሮጀክት, አንድ ኮንቴይነር

እያንዳንዱ ፕሮጀክት የራሱ የሆነ የ Docker መያዣ እና የራሱ የግዛት መጠን ያገኛል። የፕሮጀክት ማውጫው በ `/workspace` ላይ ተጭኗል; ሌሎች የአስተናጋጅ ማውጫዎች ግልጽ የገንዘብ ድጎማዎችን ይፈልጋሉ።

`policy::plan_run` ሙሉውን `docker run` argv በአንድ ቦታ ይገነባል። የእንቅስቃሴ ትሩ የሚያሳየው ትክክለኛውን እቅድ፣ ተራራዎችን፣ ችሎታዎችን፣ የአውታረ መረብ ሁነታን እና ተነባቢ-ብቻ መንገዶችን ጨምሮ።

መያዣው ሆን ተብሎ የተገደበ ነው፡-

- የስር ፋይል ስርዓቱ ተነባቢ-ብቻ ነው፣ ለ`/tmp` እና `/run` መጠናቸው tmpfs mounts ያለው።
- የምላሽ ስፑል እና የስቴት ማውጫ ተነባቢ-ብቻ ተጭነዋል።
- የኮንቴይነር አሂድ ጊዜ ሶኬቶች በስም ውድቅ ተደርገዋል።
- DeepCode ከመሮጥ በፊት ችሎታዎች ወድቀዋል፣ እና `no-new-privileges` ተዘጋጅቷል።
- የኮንቴይነር ማስኬጃ ሶኬቶች እና ሌሎች የተከለከሉ ጋራዎች ደካማ እቅድ ከማውጣት ይልቅ ተዘግተው አይሳኩም።

## ፈቃዶች

ማጠሪያው ተጨማሪ መዳረሻ ሊጠይቅ ይችላል፣ ግን ሊሰጠው አይችልም። የፈቃድ ጥያቄ ወደ spool ይጻፋል; አስተናጋጁ ደላላ አረጋግጦ መያዣውን ለአፍታ ያቆማል። ኦፕሬተሩ ጥያቄውን አይቶ ይወስናል።

የማውጫ ጥያቄን ማጽደቅ እቃውን በአዲስ ማሰሪያ ማሰሪያ እንደገና ይፈጥራል እና ክፍለ-ጊዜውን ይቀጥላል። እምቢታ ከሁለቱ መልሶች አንዱ ነው፣ እና ሞዴሉ የትኛው ነው፡ **እንደገና አትጠይቅ** የመጨረሻ እንደሆነ ይነገራል፣ **አሁን አይደለም** በዚህ ጊዜ ውድቅ አድርጎ ሞዴሉ በኋላ ሊጠይቅ እንደሚችል ተናግሯል። የመጨረሻው እምቢታ በፕሮጀክቱ ላይ ተከማችቶ በአስተናጋጁ ተፈጻሚነት ይኖረዋል፡ ለመንገዱም ሆነ ከሱ በታች ላለው ማንኛውም ተራራ በጭራሽ አይፈጠርም እና እምቢ ያለ አስተናጋጅ ንዑስ ጎራዎችን የሚሸፍን ውድቅ ህግ ይሆናል። እገዳዎች በፍቃዶች ውስጥ ተዘርዝረዋል እና እዚያ ሊነሱ ይችላሉ ፣ ምክንያቱም ወደ ኋላ የማይመለስ ውሳኔ ከምርጫ ይልቅ ወጥመድ ነው።

ማጠሪያው ላለው ነገር ጥያቄ ከማብራሪያ ጋር ውድቅ ተደርጓል። ምንም አውቶማቲክ ማጽደቂያ መንገድ የለም፣ ምክንያቱም ጸጥ ያለ ማፅደቅ ኦፕሬተሩ በጭራሽ አልሰጠም።

## አውታረ መረብ

የአውታረ መረብ ፖሊሲ ​​አራት ሁነታዎች አሉት፡

| ሁነታ | ባህሪ |
| --- | --- |
| `none` | በDeepsand egress ፕሮክሲ በኩል የአምሳያው የመጨረሻ ነጥብ ብቻ። |
| `allowlisted` | የአምሳያው የመጨረሻ ነጥብ፣ ተኪ እና የተሰየሙ አስተናጋጆች፣ አድራሻዎች እና ወደቦች። |
| `internet` | የበይነመረብ መዳረሻ፣በመያዣው ውስጥ የታገዱ የአካባቢ እና የግል ክልሎች። |
| `full` | ያለ የአከባቢ አውታረ መረብ እገዳ የበይነመረብ መዳረሻ። |

የአስተናጋጅ ስም ግቤት በፕሮክሲው ተፈትቷል፣ እሱም ግላዊ፣ መልሶ መመለሻ፣ አገናኝ-አካባቢያዊ እና የተያዙ ውጤቶችን ውድቅ ያደርጋል። የአድራሻ ግቤት በቀጥታ የሚተገበረው በመያዣው ነው፣ ይህም የውሂብ ጎታ ደንበኛ ወይም ሌላ ኤችቲቲፒ ያልሆኑ ፕሮግራሞች እንዲገናኙ ያስችላቸዋል። የተሰየመ ወደብ በአስተናጋጁ loopback ላይ ብቻ ታትሟል።

## ሚስጥሮች እና ዝመናዎች

ሚስጥሮች በእረፍት ጊዜ በስርዓተ ክወናው ቁልፍ ማከማቻ በተያዘ ቁልፍ የተመሰጠሩ ናቸው። ወደ መያዣው በአከባቢው ፋይል ይተላለፋሉ ፣ በጭራሽ እንደ የትዕዛዝ መስመር እሴት ፣ እና የሚወጉት ማጠሪያው ሲጀመር ብቻ ነው።

ልቀት ግንቦች የተፈረሙ ዝመናዎችን ከመጫንዎ በፊት ያረጋግጡ። የመፈረሚያ ቁልፉ በማከማቻው ውስጥ በጭራሽ አይከማችም።

## የትእዛዝ መስመር

`deepsandctl` ጭንቅላት የሌለውን ገጽ ያቀርባል፡-

```bash
deepsandctl doctor
deepsandctl plan <project> --offline
deepsandctl run <project>
deepsandctl watch <project>
deepsandctl requests <project>
deepsandctl network <project> <mode>
```

`plan --offline` ትክክለኛውን `docker run` argv መያዣ ሳይጀምር ያትማል፣ ይህም የተለወጠ ፖሊሲን ለመገምገም ይጠቅማል።
