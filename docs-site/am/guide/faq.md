# በተደጋጋሚ የሚጠየቁ ጥያቄዎች

## DeepCode የእኔን የቤት ማውጫ ያየዋል?

ቁጥር፡ ማጠሪያው የፕሮጀክት ማውጫውን በ`/workspace` እና በግልጽ የሰጧቸውን ማውጫዎች ይመለከታል። የተቀረው የአስተናጋጅ ፋይል ስርዓት አልተሰካም።

## የማውጫ ጥያቄን ሳጸድቅ ምን ይሆናል?

Deepsand ማውጫውን በስጦታ ያክላል፣ መያዣውን ከአዲሱ ተራራ ጋር በማያያዝ እንደገና ይፈጥራል እና የDeepCode ክፍለ ጊዜን ይቀጥላል። እየሮጠ ያለ ማጠሪያ እንደገና ሳይፈጠር የማስያዣ ተራራ ማግኘት አይችልም።

## የእኔ ንግግሮች የት ነው የተከማቹት?

የውይይት ታሪክ፣ ክፍለ-ጊዜዎች፣ አባሪዎች እና የመነጩ ችሎታዎች በእያንዳንዱ ፕሮጀክት Docker መጠን ይኖራሉ። በዲስክ ላይ ያለው የፕሮጀክት አቃፊ የእርስዎን ኮድ እና ፋይሎች ብቻ ይዟል።

አንድን ፕሮጀክት ከDeepsand ማስወገድ ያንን መጠን አይሰርዘውም። የፕሮጀክትን DeepCode ውሂብ ማጽዳት ድምጹን ያስወግዳል ነገር ግን የፕሮጀክት ማህደሩን ሳይነካ ይተወዋል።

## የAPI ቁልፎች እና ሚስጥሮች የት ተቀምጠዋል?

ሚስጥሮች በእረፍት ጊዜ የተመሰጠሩት በስርዓተ ክወናው ቁልፍ ማከማቻ ቁልፍ ነው፣ እና ሲጀመር ብቻ እንደ አካባቢ ተለዋዋጮች ወደ ማጠሪያው ውስጥ ይገባሉ። በይነገጹ ስሞችን እና ርዝመቶችን ያሳያል፣ በጭራሽ የተከማቹ እሴቶችን አያሳይም።

ምስክርነቶች እንዲሁም ከአስተናጋጅዎ DeepCode ውቅር ሊወረሱ ይችላሉ። በፕሮጀክት አቃፊ ውስጥ አልተገለበጡም።

## እያንዳንዱ ፕሮጀክት የተለየ ሞዴል መጠቀም ይችላል?

አዎ። አንድ ፕሮጀክት የአስተናጋጁን ውቅር ሊወርስ ወይም ሞዴሉን፣ ቤዝ ዩአርኤል እና ምስክርነቶችን በራሱ መቼት መሻር ይችላል። የራስጌ መምረጫው ለፕሮጀክቱ ሞዴል መምረጥም ይችላል; **ወደ ማዋቀር ቀጥል** ማለት ፕሮጀክቱ አንዱን አይሰካም ማለት ነው።

## ወጪዎችን ለመቀነስ የትኛውን ሞዴል መጠቀም አለብኝ?

ለአብዛኛዎቹ ተግባራት የፍላሽ ሞዴል ተጠቀም። Deepsand ወደ `deepseek-v4-flash` ነባሪ ነው፣ ይህም ለዕለታዊ ኮድ፣ ማብራሪያ እና አርትዖቶች ርካሽ ምርጫ ነው። `deepseek-v4-pro` ለስራ ፍላሽ በግልፅ እየታገለ ነው ወይም ተጨማሪ አቅሙን ያስፈልግሀል፣ምክንያቱም ፕሮ ሞዴሉ ለማሄድ የበለጠ ዋጋ ያስከፍላል።

ሞዴሎችን ከፕሮጀክት ራስጌ ወይም ከ`/model` ጋር በDeepCode ተርሚናል ይቀይሩ። Deepsand ን ለመጀመሪያ ጊዜ እየሞከሩ ከሆነ በፍላሽ ይጀምሩ እና የሚፈልገው ተግባር ሲኖርዎት ብቻ ወደ ፕሮ ይንቀሳቀሱ።

## የአስተሳሰብ ተንሸራታች ምን ያደርጋል?

የአስተሳሰብ ተንሸራታች በፕሮጀክቱ ራስጌ ውስጥ ካለው ሞዴል መራጭ ቀጥሎ ነው. ሞዴሉ መልስ ከመስጠቱ በፊት ምን ያህል ምክንያት እንደሚሠራ ይቆጣጠራል.

| አቁም | ምን ማለት ነው |
| --- | --- |
| **ጠፍቷል** | መልስ ከመስጠትዎ በፊት አያስቡ. በጣም ፈጣኑ, ግን ትንሹ ጥንቃቄ. |
| **ፈጣን** | ትንሽ አስተሳሰብ፣ ለትንንሽ በደንብ ለተገለጹ አርትዖቶች። |
| **ሚዛናዊ** | መጠነኛ አስተሳሰብ። መካከለኛ ማቆሚያ እና ለትክክለኛው ሥራ ምክንያታዊ ነባሪ. |
| **ጥልቅ** | ሞዴሉ የቻለውን ያህል አስብ። በጣም ቀርፋፋ እና በጣም ውድ። |
| **ነባሪ** | ወደ አስተናጋጁ `settings.json` ያስተላልፉ; ምንም የማይል ከሆነ፣ DeepCode ወደ ሚዛናዊነት ይመለሳል። |

ለአብዛኛዎቹ ተግባራት ተንሸራታቹን በ**ሚዛናዊ** ላይ ያቆዩት። መካከለኛ አቀማመጥ ነው, እና በእያንዳንዱ ጥያቄ ላይ በጣም ቀርፋፋ, በጣም ውድ የሆነ ምክንያት ሳይከፍል ጥሩ ውጤቶችን ይሰጣል. ለትክክለኛ አስቸጋሪ ችግሮች ብቻ ወደ **ጥልቅ** ይውሰዱ እና **ጠፍቷል** ወይም **ፈጣን** ትንንሽ ሊገመቱ የሚችሉ አርትዖቶችን ይጠቀሙ።

## Deepsand ከ DeepSeek ጋር ብቻ ነው የሚሰራው?

አይ DeepSeek ነባሪው ነው ምክንያቱም ሞዴሉ እና የመጨረሻ ነጥብ Deepsand ስለሚጓጓዝ Deepsand ግን DeepCode CLI በሞዴል ስም፣ ቤዝ URL እና API ቁልፍ ያዋቅራል። APIን የሚያጋልጥ ሌላ አቅራቢ ላይ ሊጠቁሙት ይችላሉ CLI ሊደውልለት የሚችለው በተለምዶ ከOpenAI ጋር ተኳሃኝ የሆነ የመጨረሻ ነጥብ።

የአቅራቢውን መሰረት ዩአርኤል እና ሞዴል በ**ቅንብሮች** ወይም በራሱ የፕሮጀክት ምስክርነቶች ያቀናብሩ እና የአቅራቢውን API ቁልፍ በተመሳሳይ ቦታ ያከማቹ። የማጠሪያው ኔትወርክ ፖሊሲ የአቅራቢውን የመጨረሻ ነጥብ መፍቀድ አለበት።

## Docker Desktop የማይሰራ ከሆነ ወይም ምላሽ መስጠቱን ካቆመስ?

Deepsand ያለ Docker ሞተር ማጠሪያ ማስጀመር አይችልም። Docker Desktop የማይሰራ ከሆነ ያስጀምሩት እና ሞተሩ ተጀምሮ እስኪያልቅ ይጠብቁ። Deepsand መስኮቱ ትኩረቱን ሲመልስ እንደገና ይፈትሻል፣ እና የሁኔታ ስትሪፕ እንደገና መሞከርን ይሰጣል።

አንዳንድ ጊዜ Docker Desktop አሁንም እየሰራ ነው ነገር ግን ሞተሩ ምላሽ መስጠት አቁሟል። Deepsand እንደገና ማስጀመር ያንን አያስተካክለውም። Docker Desktop ራሱ እንደገና መጀመር አለበት።

- **በሚታይበት ጊዜ የውስጠ-መተግበሪያ መቆጣጠሪያውን ይጠቀሙ።** Deepsand Docker Desktopን ካገኘ፣ በሁኔታ ስትሪፕ ወይም ተርሚናል ማስጠንቀቂያ ላይ **Docker Desktop እንደገና ያስጀምሩ…** ያሳያል። ያ መቆጣጠሪያ በWindows ላይ የሚጠቀመውን የWSL ሂደትን ጨምሮ የDocker ሞተሩን እንደገና ያስጀምረዋል እና መያዣው እንደገና እስኪጀምር ድረስ ይጠብቃል።
- **Windows** በማሳወቂያ ቦታ ላይ የ Docker ዌል በቀኝ ጠቅ ያድርጉ እና **እንደገና ጀምር** ን ይምረጡ። ያ አማራጭ ከጠፋ፣ Docker Desktop ን ይክፈቱ፣ **መላ መፈለግ**ን፣ ከዚያ **Docker Desktop እንደገና ያስጀምሩ**ን ይምረጡ።
- **macOS** በምናሌው አሞሌ ውስጥ የ Docker ዌል ጠቅ ያድርጉ እና **እንደገና ጀምር** ን ይምረጡ።
- **Linux** የ Docker Desktop ሜኑ ይክፈቱ፣ **መላ መፈለግ**ን፣ ከዚያ **Docker Desktop እንደገና ያስጀምሩ**ን ይምረጡ። ከDocker Desktop ይልቅ Docker Engine የሚጠቀሙ ከሆነ አገልግሎቱን እንደገና ያስጀምሩ ለምሳሌ `sudo systemctl restart docker`።

Docker Desktop ን እንደገና ማስጀመር በማሽኑ ላይ ያለውን እያንዳንዱን ኮንቴይነር ያበቃል፣ ከDeepsand ጋር ያልተገናኙ ኮንቴይነሮችንም ይጨምራል። Deepsand ዳግም ማስጀመር ያቀርባል ነገር ግን በራስ-ሰር አያደርገውም። ለመድረክ-ተኮር ምናሌ [የ Docker መላ መፈለጊያ ሰነድ](https://docs.docker.com/desktop/troubleshoot-and-support/troubleshoot/) ይመልከቱ።

## Deepsand ያለ በይነመረብ መዳረሻ መጠቀም እችላለሁ?

ሞዴሉ የመጨረሻ ነጥብ ያስፈልገዋል. በ`none` አውታረ መረብ ሁነታ፣ በDeepsand ፕሮክሲ በኩል የሚደረስበት የመጨረሻው ነጥብ ብቻ ነው። የሚያስፈልጋቸውን አስተናጋጆች ካልፈቀዱ በስተቀር ጥቅል ጭነቶች እና ሌሎች የአውታረ መረብ መዳረሻ አይሳኩም።

## Deepsandን እንዴት ማዘመን እችላለሁ?

**ቅንብሮች** ን ከዚያ **ዝማኔዎች** ን ይክፈቱ እና አዲስ ስሪት እንዳለ ያረጋግጡ። ልቀት የተፈረሙ የተጫኑ ዝማኔዎችን ይገነባል እና አንዱን ከጫኑ በኋላ መተግበሪያውን እንደገና ያስጀምሩት። ዝማኔን መጫን የአሸዋ ሳጥኖችን መስራት ያቆማል።

## የትእዛዝ መስመር በይነገጽ አለ?

አዎ። `deepsandctl` እንደ `doctor`፣ `plan`፣ `run`፣ `watch`፣ `requests` እና `network` ያሉ ጭንቅላት የሌላቸው ትዕዛዞችን ይሰጣል። የዴስክቶፕ መተግበሪያ እና CLI በ`deepsand-core` ውስጥ ተመሳሳይ የመመሪያ ኮድ ይጋራሉ።

## የደህንነት ጉዳይ እንዴት ሪፖርት አደርጋለሁ?

ለደህንነት ችግር የህዝብ ጉዳይ አይክፈቱ። በማጠራቀሚያው የደህንነት ሪፖርት ማድረጊያ ጣቢያ በኩል ጠባቂዎቹን በግል ያግኙ እና ችግሩን እንደገና ለማባዛት በቂ ዝርዝር ያካትቱ።
