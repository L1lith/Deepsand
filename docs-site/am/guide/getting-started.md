# እንደ መጀመር

Deepsand ያንን ረዳት ለተቀረው ኮምፒውተርዎ መዳረሻ ሳይሰጡ ከ AI ኮድ ረዳት ጋር በእውነተኛ ፕሮጀክት ላይ እንዲሰሩ ያግዝዎታል። መሠረታዊውን ፍሰት ለመጠቀም Docker ወይም የትእዛዝ መስመርን መረዳት አያስፈልግም።

መጀመሪያ ትልቁን ምስል ከፈለጉ፣ [Deepsand ምንድን ነው?](./what-is-deepsand) ን ያንብቡ።

## መስፈርቶች

- Docker Desktop በWindows ወይም macOS፣ ወይም Docker Engine በLinux ላይ።
- Windows፣ macOS ወይም Linux ኮምፒውተር። [ማውረዶች ገጽ](../download) ስርዓቱን ይገነዘባል እና ተዛማጅ ጫኚዎችን ይዘረዝራል።
- Node.js ከምንጩ ካልገነቡ በቀር ምንም Node.js ወይም Rust መጫን አያስፈልግም።

Docker Desktop ማጠሪያ ከመጀመሩ በፊት Docker Desktop መሮጥ አለበት። ዴሞን አሁንም እየጀመረ ከሆነ፣ የሁኔታ ስትሪፕ እንዲህ ይላል እና እንደገና ለማየት ያቀርባል። Docker Desktop እንዲሁ እየሰራ ሊሆን ይችላል ነገር ግን ምላሽ የማይሰጥ; Deepsand ዴሞን እየመለሰ አይደለም ካለ፣ Docker Desktop እንደገና ያስጀምሩ። Deepsand Docker Desktop ሲያገኝ የ**Docker Desktop እንደገና ያስጀምሩ…** መቆጣጠሪያ ያሳያል። [Docker Desktop እየሰራ ካልሆነ ወይም ምላሽ መስጠቱን ካቆመ ምን ማድረግ እንዳለበት](./faq#what-if-docker-desktop-is-not-running-or-has-stopped-responding) ይመልከቱ።

## ጫን

[Deepsand ማውረዶች ገጽ](../download) ን ይክፈቱ። የእርስዎን ኦፐሬቲንግ ሲስተም ፈልጎ ያገኛል እና የቅርብ ጊዜዎቹን Windows፣ macOS እና Linux ጫኚዎችን ከአሁኑ የGitHub ልቀቶች ይዘረዝራል። ለኮምፒዩተርዎ ጥቅሉን ይምረጡ እና ይጫኑት እና ከዚያ Deepsand ይጀምሩ።

Deepsand እራሱ እየገነቡ ከሆነ፣ ማከማቻው README የምንጭ-ግንባታ እና ትኩስ-መጫን ትዕዛዞች አሉት።

## መጀመሪያ ሩጡ

DeepCode ከመጠቀምዎ በፊት መጫን ወይም ማዋቀር አያስፈልግዎትም። Deepsand በማጠሪያው ውስጥ DeepCode ን ያስኬዳል እና ለአምሳያው እና የመጨረሻ ነጥብ ምክንያታዊ ነባሪዎች አሉት።

የሚያስፈልግህ አንድ ነገር ሞዴል API ቁልፍ ነው. የሚቀጥለው ክፍል DeepSeek እንዴት ማግኘት እንደሚችሉ ያብራራል፣ ወይም ከሌላ አቅራቢ ቁልፍ መጠቀም ይችላሉ። በ **ቅንጅቶች → API ቁልፍ** ውስጥ ያስቀምጡት.

አስቀድመህ DeepCode CLI በዚህ ኮምፒውተር ላይ የምትጠቀም ከሆነ፣ Deepsand በምትኩ ሞዴሉን፣ ቤዝ URL እና ቁልፍ ካለህ የDeepCode ውቅር መውረስ ይችላል። አንድ ፕሮጀክት እነዚያን ምስክርነቶች በራሱ መቼት መሻር ይችላል።

## የAPI ቁልፍ ያግኙ

Deepsand ረዳቱ ከመሮጡ በፊት ከአንድ ሞዴል አቅራቢ የ API ቁልፍ ያስፈልገዋል።

- **ከሌለህ፡-** [DeepSeek API ቁልፍ ያግኙ](./deepseek-api) ተከተል። መለያ በመፍጠር፣ ክሬዲት በመጨመር፣ ቁልፍ በመስራት እና ወደ Deepsand በመመለስ ያልፋል።
- **አስቀድመው አንድ ካለዎት፡-** **ቅንብሮች** ን ይክፈቱ፣ ወደ **API ቁልፍ** መስክ ይለጥፉት እና **ቁልፍ አስቀምጥ** ን ይምረጡ።
- **ፕሮጀክት-ተኮር ቁልፍ ከፈለጉ፡-** የፕሮጀክቱን መቼቶች ይክፈቱ እና በምትኩ እዚያ ያስገቡት።

የመተግበሪያ-ሰፊ ቁልፉ በDeepsand ግዛት ፋይል ውስጥ ሳይሆን በእርስዎ የስርዓተ ክወና ቁልፍ ማከማቻ ውስጥ ይቀመጣል። መስኮቱ ከተቀመጠ በኋላ የመጨረሻዎቹን አራት ቁምፊዎች ብቻ ያሳያል.

## ፕሮጀክት ፍጠር

1. በጎን አሞሌው ውስጥ **አዲስ ፕሮጀክት** ን ይምረጡ።
2. ለፕሮጀክቱ ስም ይስጡት.
3. የስራ ማውጫውን ይምረጡ።
4. ፕሮጀክቱን ይፍጠሩ.

የስራ ማውጫው በማጠሪያው ውስጥ `/workspace` ይሆናል። Deepsand እንደ የፋይል ሲስተም ስር፣ የቤትዎ ማውጫ፣ የማረጋገጫ መደብሮች እና የራሱ የውሂብ ማውጫ ያሉ ዱካዎችን አይቀበልም።

## ሞዴል ይምረጡ

ለአብዛኛዎቹ ተግባራት **ብልጭታ ሞዴል** ይጠቀሙ። Deepsand ወደ `deepseek-v4-flash` ነባሪ ነው፣ ይህም ለዕለታዊ ኮድ፣ ማብራሪያ እና አርትዖቶች ርካሽ ምርጫ ነው። ብልጭታ ከአንድ ተግባር ጋር ሲታገል ብቻ ወደ `deepseek-v4-pro` ቀይር። የፕሮ ሞዴል ለማሄድ የበለጠ ወጪ ያስከፍላል።

ሞዴሉን በ**ቅንብሮች**፣ ከፕሮጀክት ራስጌ ወይም ከ`/model` ጋር በDeepCode ተርሚናል መቀየር ይችላሉ።

## የአስተሳሰብ ደረጃ ይምረጡ

የአስተሳሰብ ተንሸራታች በፕሮጀክቱ ራስጌ ውስጥ ካለው ሞዴል መራጭ ቀጥሎ ነው. አምሳያው መልስ ከመስጠቱ በፊት ምን ያህል ምክንያት እንደሚሠራ ይቆጣጠራል.

- **ጠፍቷል፡** ምንም ማሰብ. በጣም ፈጣኑ, ግን ትንሹ ጥንቃቄ.
- **ፈጣን:** ትንሽ ማሰብ፣ ለትንንሽ በደንብ ለተገለጹ አርትዖቶች።
- **ሚዛናዊ፡** መጠነኛ አስተሳሰብ እና መካከለኛ ማቆሚያ። ይህ ለእውነተኛ ሥራ ምክንያታዊ ነባሪ ነው።
- **ጥልቅ፡** ከፍተኛ ምክንያት። በጣም ቀርፋፋ እና በጣም ውድ።
- **ነባሪ፡** ወደ አስተናጋጅ `settings.json` ማስተላለፍ; ምንም የማይል ከሆነ፣ DeepCode ወደ ሚዛናዊነት ይመለሳል።

ለአብዛኛዎቹ ተግባራት ተንሸራታቹን በ**ሚዛናዊ** ላይ ያቆዩት። በእያንዳንዱ ጥያቄ ላይ በጣም ቀርፋፋ, በጣም ውድ የሆነ ምክንያት ሳይከፍሉ ጥሩ ውጤቶችን ይሰጣል. **ጥልቅ** ለትክክለኛ አስቸጋሪ ችግሮች ብቻ፣ እና **ጠፍቷል** ወይም **ፈጣን** ለትንንሽ ሊገመቱ ለሚችሉ አርትዖቶች ይጠቀሙ።

## ፕሮጀክት አሂድ

1. ፕሮጀክቱን ይምረጡ.
2. **ሩጡ** ን ይጫኑ።
3. ምስሉ ከጠፋ, Deepsand መጀመሪያ ይገነባዋል እና በእንቅስቃሴ ትር ውስጥ ያለውን የግንባታ ውጤት ያሳያል.
4. DeepCode CLI በመያዣው ውስጥ ይጀምራል እና በተርሚናል ውስጥ ይታያል።

የአሸዋ ሳጥኑን ማቆም መያዣውን ያበቃል. እሱን እንደገና ማስጀመር አንድ ሲኖር የቀደመውን የDeepCode ክፍለ ጊዜ ይቀጥላል።

## የ DeepCode ተርሚናል በመጠቀም

የ**ተርሚናል** ትር የቀጥታ DeepCode CLI ክፍለ ጊዜ ነው። ጥያቄ ይተይቡ እና **አስገባ** ን ይጫኑ፣ ወይም ክፍለ-ጊዜውን ለመቆጣጠር slash ትዕዛዝ ይጠቀሙ። `/new` አዲስ ውይይት ይጀምራል፣ `/resume` የቀደመውን ይቀጥላል፣ `/model` ሞዴሉን ይለውጣል፣ እና `/` የትእዛዝ ሜኑ ይከፍታል።

ለዋና ትዕዛዞች ፣ የቁልፍ ሰሌዳ አቋራጮች እና የመልሶ ማግኛ ደረጃዎች [የ DeepCode ተርሚናል በመጠቀም](./deepcode-terminal) ን ያንብቡ።

## የፍቃድ ጥያቄዎችን መመለስ

DeepCode ማውጫ፣ የኔትወርክ መድረሻ፣ መሳሪያ ወይም ሌላ ግብአት ሲፈልግ Deepsand ማጠሪያውን ባለበት አቁሞ ጥያቄውን ያሳያል።

- **መዳረሻ ይስጡ** ጥያቄውን ይፈቅዳል እና ክፍለ-ጊዜውን ይቀጥላል።
- **አሁን አይደለም** በዚህ ጊዜ እምቢ አለ; ሞዴሉ በኋላ እንደገና ሊጠይቅ ይችላል.
- **እንደገና አትጠይቅ** እምቢ አለ፣ እና Deepsand ከዛ መንገዱን (እና በእሱ ስር ያለውን ሁሉ) ወይም ያንን አስተናጋጅ (እና ንዑስ ጎራዎቹ) በቃላት ብቻ ሳይሆን በራሱ እምቢ ይላል። እያንዳንዱ ብሎክ በፍቃዶች ውስጥ ተዘርዝሯል፣ እዚያም እንደገና ማንሳት ይችላሉ።
- የማውጫ ግራንት አዲሱን ተራራ በማያያዝ መያዣውን እንደገና ይፈጥራል።

ሚስጥራዊነት ያላቸው ፋይሎችን የያዘ ማውጫ መዳረሻ ከመስጠትዎ በፊት [ማጠሪያው እንዴት እንደሚሰራ](./security) ን ያንብቡ።
