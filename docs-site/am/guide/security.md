# ማጠሪያው እንዴት እንደሚሰራ

በግልፅ ቃላቶች፡ ረዳቱ በመረጡት ፕሮጀክት እና ባጸደቋቸው አቃፊዎች ውስጥ መስራት ይችላል እና በኮምፒዩተርዎ ላይ ሌላ ቦታ የለም።

የDeepsand የተስፋ ቃል ጠባብ እና ሊሞከር የሚችል ነው፡ ማጠሪያው የፕሮጀክት ማውጫውን እና እርስዎ በግልጽ የሰጧቸውን ማውጫዎች ሊደርስ ይችላል፣ እና ሌላ ምንም የለም።

## ድንበሩ

መያዣው Deepsand ከመረጠው ማሰሪያ ውጭ ስለ አስተናጋጁ ፋይል ስርዓት ምንም እይታ የለውም። ሌሎች የአስተናጋጅ ዱካዎች በመያዣው ተራራ የስም ቦታ ውስጥ የሉም፣ ስለዚህ የሚያመልጥበት የአስተናጋጅ ፋይል የለም።

እዚህ የተገለፀው ሁሉም ነገር በዚያ ድንበር ላይ በጥልቀት መከላከያ ነው.

## የሚተገበረው

- ከአስተናጋጁ የስራ ቦታ እና ግልጽ ስጦታዎች ብቻ ተጭነዋል።
- የምላሽ ስፑል እና የስቴት ማውጫ ተነባቢ-ብቻ ተጭነዋል።
- የኮንቴይነር አሂድ ጊዜ ሶኬቶች በስም ውድቅ ተደርገዋል።
- የኮንቴይነር ስርወ ፋይል ስርዓቱ ተነባቢ-ብቻ ነው፣ ለ`/tmp` እና `/run` መጠን ያላቸው ጊዜያዊ የፋይል ስርዓቶች አሉት።
- ተምሳሌታዊ ማገናኛዎች መንገዱ ከመፈተሸ በፊት መፍትሄ ያገኛሉ፣ ስለዚህ ማገናኛ የተከለከለውን ኢላማ መደበቅ አይችልም።
- DeepCode ከመሮጥ በፊት መብቶች ይጣላሉ፣ እና `no-new-privileges` መልሰው እንዳያገኙ ይከለክላቸዋል።

## የአውታረ መረብ ሁነታዎች

| ሁነታ | የሚፈቅደው |
| --- | --- |
| የለም | በDeepsand ፕሮክሲ በኩል የአምሳያው የመጨረሻ ነጥብ ብቻ። |
| የተፈቀደ | የአምሳያው የመጨረሻ ነጥብ፣ ተኪ፣ እና አስተናጋጆች ወይም አድራሻዎች በተፈቀደ ዝርዝሩ ላይ። |
| ኢንተርኔት | የበይነመረብ መዳረሻ፣ ከአካባቢያዊ እና ከግል ክልሎች ጋር በመያዣው ውስጥ ተዘግቷል። |
| ሙሉ | ያለ የአከባቢ አውታረ መረብ እገዳ የበይነመረብ መዳረሻ። ማጠሪያው በትክክል የአካባቢዎን አውታረ መረብ ሲፈልግ ብቻ ይጠቀሙ። |

የተፈቀደለት የአስተናጋጅ ስም በፕሮክሲው በኩል ያልፋል፣ እሱም ስሙን በራሱ ይፈታል እና ውጤቱን በግል አድራሻ ቦታ ላይ ውድቅ ያደርጋል። የተፈቀደ አድራሻ በቀጥታ በመያዣው ህግ ይፈቀዳል፣ ምክንያቱም የውሂብ ጎታ ደንበኛ ወይም ሌላ ኤችቲቲፒ ያልሆነ ፕሮግራም ፕሮክሲውን መጠቀም አይችሉም። በመግቢያው ውስጥ የተሰየመ ወደብ በአስተናጋጁ loopback ላይ ታትሟል፣ በጭራሽ በሁሉም በይነገጽ ላይ።

## እርስዎ ምን እንደሚወስኑ

Deepsand በፍፁም መዳረሻ አይሰጥም። ጥያቄው በሚጠይቀው መንገድ፣ አስተናጋጅ፣ መሳሪያ ወይም ግብአት ይደርስዎታል፣ እና እርስዎ እስኪወስኑ ድረስ ማጠሪያው ባለበት ቆሟል።

ማጠሪያው ላለው ነገር ጥያቄ ከማብራሪያው ጋር ውድቅ ተደርጓል፣ ምክንያቱም አውቶማቲክ ፍቃድ እርስዎ በጭራሽ ያልሰጡት ስምምነት ይሆናል። ማንኛውም አሻሚ ነገር ወደ እርስዎ ይደርሳል.

## የማይከላከለው

- የሞዴል አቅራቢው ወደ እሱ የላኩትን ይዘት ማየት ይችላል።
- በስራ ቦታ ላይ የሚያስቀምጧቸው ፋይሎች ለማጠሪያው ይታያሉ እና ሊለወጡ ወይም ሊሰረዙ ይችላሉ።
- የተበላሸ መሳሪያ ወይም የሞዴል መመሪያ አሁንም መድረስን ሊጠይቅ ይችላል። ውሳኔው የእርስዎ ነው.
- Docker እራሱ ከድንበሩ ውጪ ነው። Docker Desktop እና አስተናጋጁ ኦፕሬቲንግ ሲስተም አዘምኗል።
