# የ DeepCode ተርሚናል በመጠቀም

Deepsand በማጠሪያው ውስጥ [DeepCode CLI](https://github.com/lessweb/deepcode-cli) ያስኬዳል። የ**ተርሚናል** ትር የቀጥታ DeepCode ክፍለ ጊዜ ነው፡ ጥያቄን በመደበኛ ቋንቋ ይተይቡ፣ ወይም ክፍለ-ጊዜውን ለመቆጣጠር ከDeepCode slash ትዕዛዞች አንዱን ይጠቀሙ።

DeepCode በራስህ ማሽን ላይ አትጫንም። Deepsand CLIን በፕሮጀክቱ መያዣ ውስጥ ይጀምራል፣ እዚያም `/workspace` እና ያጋሯቸውን ማውጫዎች ማየት ይችላል።

በ[DeepCode ፕሮጀክት መነሻ ገጽ](https://deepcode.vegamo.cn/) ወይም በ[DeepCode ማከማቻ](https://github.com/lessweb/deepcode-cli) ላይ የበለጠ ይወቁ።

## ክፍለ ጊዜ ጀምር

1. በጎን አሞሌው ውስጥ ፕሮጀክት ይምረጡ።
2. **ሩጡ** ን ይጫኑ።
3. ማጠሪያው እስኪጀምር ድረስ ይጠብቁ። ምስሉ ከጠፋ, Deepsand መጀመሪያ ይገነባል እና የግንባታውን ውጤት በ **እንቅስቃሴ** ውስጥ ያሳያል.
4. DeepCode ተርሚናል CLI ዝግጁ ሲሆን ይታያል።

የአሸዋ ሳጥኑን ማቆም መያዣውን ያበቃል. ፕሮጀክቱን እንደገና መጀመር አንድ ሲኖር የቀደመውን የDeepCode ውይይት ይቀጥላል።

## የሆነ ነገር እንዲያደርግ DeepCode ይጠይቁ

መደበኛ ጥያቄ ይተይቡ እና **አስገባ** ን ይጫኑ። ለምሳሌ፡-

```text
Find the failing test in this project and explain what is wrong.
```

DeepCode ፋይሎችን በስራ ቦታ ማንበብ እና ማርትዕ፣ ትዕዛዞችን ማስኬድ እና ለፕሮጀክቱ የተመረጡትን መሳሪያዎች መጠቀም ይችላል። እርስዎ እንደተቆጣጠሩት ይቆያሉ፡ ከስራ ቦታ ውጭ የሆነ ነገር ሲፈልግ፣ Deepsand ማጠሪያውን ባለበት ያቆማል እና መጀመሪያ ይጠይቅዎታል።

## ዋና slash ትዕዛዞች

የSlash ትዕዛዞች በ`/` ይጀምራሉ። `/`ን በራሱ መተየብ የትእዛዝ ሜኑ ይከፍታል።

| ትዕዛዝ | ምን ያደርጋል |
| --- | --- |
| `/new` | አዲስ ውይይት ጀምር |
| `/resume` | ለመቀጠል የቀደመ ውይይት ይምረጡ |
| `/fork` | የአሁኑን ውይይት ሹካ |
| `/continue` | ንቁ ውይይቱን ይቀጥሉ፣ ወይም ከቆመበት ለመቀጠል አንዱን ይምረጡ |
| `/model` | ሞዴሉን ይቀይሩ, የአስተሳሰብ ሁነታ እና የማመዛዘን ጥረት |
| `/raw` | የማሳያ ሁነታን ቀይር፡ መደበኛ፣ ቀላል ወይም ጥሬ ማሸብለል |
| `/init` | የ `AGENTS.md` ፋይል ከፕሮጀክት መመሪያዎች ጋር ይፍጠሩ |
| `/skills` | ለ DeepCode ያሉትን ችሎታዎች ይዘርዝሩ |
| `/mcp` | MCP አገልጋይ ሁኔታ እና የሚገኙ መሣሪያዎች አሳይ |
| `/undo` | ኮድ፣ ውይይቱን ወይም ሁለቱንም ወደ ቀደመው ነጥብ ይመልሱ |
| `/exit` | DeepCode አቋርጥ |

አንድ ፕሮጀክት አስቀድሞ `AGENTS.md` ሊኖረው ይችላል; ቀደም ሲል የነበሩትን መመሪያዎች እንዳይተኩ `/init` ከመጠቀምዎ በፊት ያረጋግጡ።

## የቁልፍ ሰሌዳ አቋራጮች

| ቁልፍ | ድርጊት |
| --- | --- |
| `Enter` | መጠየቂያውን ላክ |
| `Shift+Enter` | አዲስ መስመር አስገባ |
| `Ctrl+J` | አዲስ መስመር አስገባ |
| `Esc` | የአሁኑን ሞዴል መዞር አቋርጥ |
| `Ctrl+V` | የተመረጠው ሞዴል ምስሎችን ሲደግፍ ምስል ለጥፍ |
| `Ctrl+D` ሁለት ጊዜ | DeepCode አቋርጥ |

ከ`Esc` ጋር መዞርን ካቋረጡ በኋላ ሌላ ጥያቄ መተየብ ይችላሉ። ማጠሪያው እንደገና አልተጀመረም።

## ፋይሎችን ወደ ተርሚናል በመጣል ላይ

አንድ ፋይል ወደ ተርሚናል ይጎትቱ እና ዱካው ለእርስዎ ተጽፏል።

- በፕሮጀክት ማህደር ውስጥ ያለ ፋይል ወይም ከፕሮጀክቱ ጋር ባጋሩት ማውጫ ውስጥ ማጠሪያው ቀድሞ ወደታየበት (`/workspace/...` ወይም `/grants/...`) ተጠቅሷል። ምንም አልተቀዳም።
- ከማንኛውም ቦታ የመጣ ፋይል በማጠሪያው ውስጥ ወደ `/tmp/deepsand-incoming` ይገለበጣል፣ እና Deepsand በመጀመሪያ ይጠይቃል። ያ አቃፊ የማንኛውም ማከማቻ አካል አይደለም፣ስለዚህ የወደቀ ፋይል በቁርጠኝነት ውስጥ ሊጠናቀቅ አይችልም፣ እና ማጠሪያው እንደገና ሲፈጠር ይጠፋል። መገናኛው የ **እንደገና አታስጠነቅቀኝ** ማብሪያ / ማጥፊያ አለው ፣ እሱም እንደ **መቼቶች → ባህሪ → ከፕሮጀክቱ ውጭ ፋይሎችን ከመጣልዎ በፊት ያስጠነቅቁ** ተመሳሳይ መቼት ነው።

## እንደተዘመኑ መቆየት

DeepCode CLI በማጠሪያ ምስል ውስጥ ተጭኗል፣ እና ማጠሪያው እራሱን ማዘመን አይችልም። ከእያንዳንዱ ጅምር በፊት Deepsand npm የቅርብ ጊዜ ልቀት ምን እንደሆነ ይጠይቃል እና ምስሉ የቆየ ካለው በመጀመሪያ የምስሉን ክፍል እንደገና ይገነባል - ስለዚህ ተርሚናል ቀድሞውኑ እንዲያዘምኑ በሚጠይቅ ስሪት ላይ በጭራሽ አይከፈትም። መልሱ ለሩብ ሰዓት አንድ ሰዓት ይታወሳል, ስለዚህ ይህ በአንድ ሩጫ ከአንድ ጥያቄ ይልቅ አንድ ጥያቄ ነው, እና npm መድረስ ካልተቻለ ማጠሪያው ቀድሞውኑ ባለው ስሪት ይጀምራል.

## ክፍለ-ጊዜዎች፣ ሞዴሎች እና መቀልበስ

- `/new` በንጹህ ውይይት ይጀምራል። የፕሮጀክት ፋይሎች አልተሰረዙም።
- `/resume` እና `/continue` የቀደመ ውይይትን ያመጣሉ ።
- `/model` ለክፍለ-ጊዜው ሞዴሉን, የአስተሳሰብ ሁነታን እና የማመዛዘን ጥረትን ይለውጣል. የፕሮጀክቱ ራስጌ ሞዴል መራጭ እና የአስተሳሰብ ተንሸራታች አለው; **ሚዛናዊ** መካከለኛ ማቆሚያ እና ለአብዛኛው ስራ የሚመከረው መቼት ነው።
- `/undo` ኮድን፣ ውይይቱን ወይም ሁለቱንም ወደ ቀደመው ነጥብ ይመልሳል። ካልፈለጉት ለውጥ ለመውጣት ፈጣኑ መንገድ ነው።

የውይይት ታሪክ የሚኖረው በፕሮጀክቱ Deepsand የግዛት መጠን ነው እንጂ በእርስዎ ማከማቻ ውስጥ አይደለም።

## ፍቃዶች ​​እና ማጠሪያው

ተርሚናሉ በመያዣው ውስጥ ነው፣ ስለዚህ ፕሮጀክቱን በ`/workspace` እና እርስዎ ያጋሯቸውን ማውጫዎች ያያል፣ እና በኮምፒውተርዎ ላይ ምንም የለም።

DeepCode ሌላ ማውጫ፣ የአውታረ መረብ መድረሻ፣ መሳሪያ ወይም ሌላ ሃብት ሲጠይቅ Deepsand ማጠሪያውን ያቀዘቅዘዋል እና የፍቃድ ንግግር ያሳያል።

- **መዳረሻ ይስጡ** ጥያቄውን ተግባራዊ ያደርጋል እና ክፍለ-ጊዜውን ይቀጥላል።
- **አሁን አይደለም** በዚህ ጊዜ እምቢ አለ; DeepCode በኋላ እንደገና ሊጠይቅ ይችላል።
- **እንደገና አትጠይቅ** እምቢ አለ፣ እና Deepsand ከዛ መንገዱን (እና በእሱ ስር ያለውን ሁሉ) ወይም ያንን አስተናጋጅ (እና ንዑስ ጎራዎቹ) በቃላት ብቻ ሳይሆን በራሱ እምቢ ይላል። እያንዳንዱ ብሎክ በፍቃዶች ውስጥ ተዘርዝሯል፣ እዚያም እንደገና ማንሳት ይችላሉ።
- ማውጫን ማጽደቅ እቃውን በአዲሱ ተራራ እንደገና ይፈጥራል።

ሚስጥራዊነት ያላቸው ፋይሎችን የያዘ ማውጫ ከማጋራትዎ በፊት [ማጠሪያው እንዴት እንደሚሰራ](./security) ን ያንብቡ።

## ተርሚናል ካልጀመረ

- **ምስሉ ጠፍቷል፡-** Deepsand መጀመሪያ ይገነባዋል። ለግንባታ እድገት **እንቅስቃሴ** ይመልከቱ።
- **Docker Desktop እየሰራ አይደለም ወይም ተጣብቋል፡** አስነሳው እና ሞተሩ መጀመሩን እስኪጨርስ ድረስ ጠብቅ። Docker Desktop እየሰራ ከሆነ ግን ሞተሩ የማይመለስ ከሆነ Docker Desktop እንደገና ያስጀምሩ። Deepsand ሲያሳየው የውስጠ-መተግበሪያውን **Docker Desktop እንደገና ያስጀምሩ…** መቆጣጠሪያ ተጠቀም። ያለበለዚያ በ Windows የማሳወቂያ ቦታ ላይ የ Docker ዌል በቀኝ ጠቅ ያድርጉ እና **እንደገና ጀምር** ን ይምረጡ። በ macOS ላይ የ Docker ምናሌ አሞሌ አዶን ይጠቀሙ; በ Linux የ Docker Desktop's **መላ መፈለግ** ምናሌን ይክፈቱ። Docker Desktop ን እንደገና ማስጀመር በማሽኑ ላይ ያለውን እያንዳንዱን መያዣ ያበቃል። [የ Docker FAQ](./faq#what-if-docker-desktop-is-not-running-or-has-stopped-responding) ይመልከቱ።
- **የAPI ቁልፍ ጠፍቷል ወይም ውድቅ ተደርጓል፡-** **ቅንብሮች** ን ይክፈቱ እና የሚሰራ ቁልፍ ያስቀምጡ።
- **DeepCode ወጥቷል፡** እንደገና **ሩጡ** ን ይጫኑ። ያለፈው ክፍለ ጊዜ በ`/resume` መቀጠል ይችላል።
