# Deepsand አውርድ

Deepsand ለWindows፣ macOS እና Linux ይገኛል። ገጹ የእርስዎን ስርዓት ያውቃል፣ ነገር ግን ለሌላ ማሽን እያወረዱ ከሆነ ሌላ መድረክ መምረጥ ይችላሉ።

<DownloadPicker />

## ከመጫንዎ በፊት

- Deepsand እያንዳንዱን ፕሮጀክት በራሱ ማጠሪያ ውስጥ ለማስኬድ Docker ይጠቀማል። Docker Desktop በWindows ወይም macOS ላይ ወይም Docker Engine በLinux ላይ ጫን።
- ሞዴል API ቁልፍ ያስፈልግዎታል። [DeepSeek API ቁልፍ ያግኙ](./guide/deepseek-api)፣ ወይም ያለውን የአቅራቢ ቁልፍ ተጠቀም።
- የመጀመሪያው ማስጀመሪያ የአሸዋ ሳጥን ምስል ሊገነባ ይችላል፣ ይህም ጥቂት ደቂቃዎችን ሊወስድ ይችላል።

## ከጫኑ በኋላ

1. Deepsand ጀምር።
2. **ቅንብሮች** ን ይክፈቱ እና ሞዴልዎን API ቁልፍ ያስቀምጡ።
3. ፕሮጀክት ይፍጠሩ እና የስራ ማውጫውን ይምረጡ።
4. ማጠሪያውን ለመጀመር **ሩጡ** ን ይጫኑ።

ለሙሉ የመጀመሪያ አሂድ ጉዞ [እንደ መጀመር](./guide/getting-started) አንብብ።

## ሁሉም የተለቀቁ

የቅርቡ ግንባታ አሁንም እየታተመ ከሆነ ወይም የቆየ ስሪት ከፈለጉ ይክፈቱት።
[GitHub የሚለቀቅ ገጽ](https://github.com/L1lith/Deepsand/releases).
