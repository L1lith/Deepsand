# Qu'est-ce que Deepsand ?

Deepsand est une application de bureau qui permet à un assistant de codage IA de vous aider dans un projet dans son propre espace de travail séparé.

Considérez-le comme un établi dans une autre pièce. Vous apportez le projet pour lequel vous souhaitez de l’aide. L'assistant peut utiliser cet établi et les matériaux que vous lui remettez, mais il ne peut pas se promener dans le reste de votre maison.

## A quoi ça sert

- Correction d'un bug dans un site Web ou un petit programme.
- Ajout d'une fonctionnalité à un projet existant.
- Expliquer le code dont vous avez hérité ou que vous ne reconnaissez pas.
- Rédaction de tests, de documentation ou d'une première ébauche.
- Explorer un référentiel inconnu sans donner à un assistant accès à tout le reste sur votre machine.

Vous n'avez pas besoin de savoir comment fonctionne Docker et vous n'avez pas besoin d'être un développeur professionnel pour commencer. Si vous pouvez choisir un dossier et appuyer sur un bouton, vous pouvez utiliser le flux de base.

## Pourquoi ne pas simplement utiliser une fenêtre de discussion ?

Une fenêtre de discussion peut suggérer du code, mais elle ne peut pas exécuter votre projet, lire les fichiers qui l'entourent ou vérifier si sa suggestion fonctionne réellement.

Deepsand donne à l'assistant un vrai projet et de vrais outils. Il peut exécuter des commandes, modifier des fichiers et tester le résultat, tandis que l'espace de travail éloigne ce travail du reste de votre ordinateur.

## Que signifie « un espace de travail séparé »

L'assistant voit le dossier de projet que vous choisissez et les dossiers que vous partagez délibérément. Il ne voit pas automatiquement vos documents, photos, téléchargements, autres projets, mots de passe ou le reste de votre disque.

Lorsqu’il a besoin de quelque chose en dehors de l’espace de travail, il doit le demander. Deepsand met l'assistant en pause et vous montre la demande. Rien n'est partagé jusqu'à ce que vous l'approuviez.

## Pour qui c'est

- **Les personnes qui débutent dans le codage :** obtient de l'aide pour un petit projet sans apprendre au préalable un outil de conteneur.
- **Développeurs expérimentés :** offre à un agent IA un environnement limité, inspecte la commande Docker exacte et contrôle l'accès au réseau et aux outils.
- **Quiconque souhaite une deuxième paire de mains :** permet à l'assistant de se concentrer sur un projet au lieu d'exposer une machine entière.

## Ce dont vous gardez le contrôle

- Quel dossier chaque projet utilise.
- Quels dossiers supplémentaires, le cas échéant, l'assistant peut atteindre.
- Quels sites Web il peut contacter.
- Quels outils sont installés dans l'espace de travail.
- Quel modèle et informations d'identification sont utilisés.
- Lorsque l'espace de travail démarre et s'arrête.
