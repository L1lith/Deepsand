# Télécharger Deepsand

Deepsand est disponible pour Windows, macOS et Linux. La page détecte votre système, mais vous pouvez choisir une autre plate-forme si vous téléchargez pour une autre machine.

<DownloadPicker />

## Avant d'installer

- Deepsand utilise Docker pour exécuter chaque projet dans son propre bac à sable. Installez Docker Desktop sur Windows ou macOS, ou Docker Engine sur Linux.
- Vous aurez besoin d’une clé modèle API. [Obtenez une clé DeepSeek API](./guide/deepseek-api), ou utilisez une clé de fournisseur existante.
- Le premier lancement peut créer l’image sandbox, ce qui peut prendre quelques minutes.

## Après avoir installé

1. Démarrez Deepsand.
2. Ouvrez **Paramètres** et enregistrez la clé de votre modèle API.
3. Créez un projet et choisissez son répertoire de travail.
4. Appuyez sur **Courir** pour démarrer le bac à sable.

Lisez [Commencer](./guide/getting-started) pour la présentation complète de la première exécution.
