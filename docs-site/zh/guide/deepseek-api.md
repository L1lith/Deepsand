# 获取 DeepSeek API 密钥

Deepsand 需要模型提供者来为助手提供支持。默认配置使用 DeepSeek。此页面将逐步介绍创建帐户、添加信用、制作 API 密钥并将其保存在 Deepsand 中。

如果您已经拥有其他提供商提供的 API 密钥，请跳至 [使用您已有的密钥](#use-a-key-you-already-have)。

## 开始之前

您将需要：

- 电子邮件地址或支持的登录帐户。
- API 信用的支付方式。
- 需要几分钟时间来创建密钥并将其粘贴到 Deepsand 中。

DeepSeek API 与 DeepSeek 聊天网站和移动应用程序分开计费。在API平台上添加积分，就可以让助手提出请求。

## 1.创建DeepSeek账户

1. 打开[DeepSeek API平台](https://platform.deepseek.com/)。
2. 选择**报名**或**登录**。
3. 使用您的电子邮件地址创建帐户，或使用支持的登录选项之一。
4. 如果平台要求您验证您的电子邮件地址或电话号码。

## 2.添加信用

1. 登录API平台。
2. 打开仪表板中的计费或充值部分。
3. 添加您想要使用的信用额度。
4. 完成付款。

API 使用量将从该余额中扣除。该平台显示当前余额、使用情况和定价。当您尝试 Deepsand 时，请从少量开始；您可以稍后添加更多。

## 3.创建API密钥

1. 打开平台的 **API按键** 部分。
2. 选择 **创建新的 API 密钥** 或等效按钮。
3. 为密钥指定一个您能识别的名称，例如 **Deepsand**。
4. 创建密钥并立即复制。

密钥通常只显示一次。将其视为密码：拥有该密码的任何人都可以在您的帐户上使用积分。

## 4. 将密钥保存在Deepsand中

1. 打开Deepsand。
2. 打开**设置**。
3. 在默认凭据下找到 **API钥匙** 字段。
4. 粘贴密钥。
5. 选择**保存密钥**。

Deepsand 将密钥存储在操作系统的密钥库中，而不是其设置文件中。保存后，窗口仅显示最后四个字符，因此您可以确认密钥是否存在，而无需再次暴露它。

当主机 DeepCode 配置和项目均不提供自己的密钥时，将使用应用程序范围的密钥。项目级密钥仍然优先。

## 使用您已有的密钥

如果您已有 API 密钥，则无需创建 DeepSeek 帐户。

- 要将其用于每个项目，请打开 **设置**，在 **API钥匙** 字段中输入密钥，然后保存。
- 要使用不同的端点或模型，还要在 **设置** 或项目自己的凭据中设置基本 URL 和模型。
- 要仅为一个项目保留密钥，请打开该项目的设置并在其中输入它。

提供程序必须公开 DeepCode CLI 可以调用的 API。如果您使用非 DeepSeek 提供程序，请输入其基本 URL 和模型名称，而不是 DeepSeek 默认值。

## 如果有什么不起作用

- **密钥被拒绝：** 在平台上创建一个新密钥并替换存储的密钥。
- **余额为空：** 向 API 帐户添加信用。聊天订阅不会自动为 API 使用提供资金。
- **助理无法联系到提供商：** 检查项目的网络模式和白名单。模型端点必须可达。
- **您想要删除密钥：** 打开**设置**并选择**移除钥匙**。
