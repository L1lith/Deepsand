# Deepsand是什么？

Deepsand 是一款桌面应用程序，可让 AI 编码助手在其自己的独立工作区中帮助完成项目。

将其视为另一个房间的工作台。您提出您需要帮助的项目。助手可以使用该工作台和您递给它的材料，但它不能在您家里的其他地方闲逛。

## 它有什么用

- 修复网站或小程序中的错误。
- 向现有项目添加功能。
- 解释您继承或不识别的代码。
- 编写测试、文档或初稿。
- 探索一个不熟悉的存储库，而无需让助手访问您计算机上的其他所有内容。

您无需了解 Docker 的工作原理，也无需成为专业开发人员即可开始。如果您可以选择一个文件夹并按下按钮，则可以使用基本流程。

## 为什么不直接使用聊天窗口呢？

聊天窗口可以建议代码，但它无法运行您的项目、读取其周围的文件或检查其建议是否实际有效。

Deepsand为助手提供了真实的项目和真实的工具。它可以运行命令、编辑文件并测试结果，而工作区则使这些工作远离计算机的其他部分。

## “单独的工作空间”是什么意思

助手会看到您选择的项目文件夹以及您有意共享的文件夹。它不会自动查看您的文档、照片、下载、其他项目、密码或磁盘的其余部分。

当它需要工作空间之外的东西时，它必须提出请求。 Deepsand 暂停助手并向您显示请求。在您批准之前，不会共享任何内容。

## 它是为谁而设

- **刚刚接触编码的人：** 无需先学习容器工具即可获得小型项目的帮助。
- **经验丰富的开发人员：** 为 AI 代理提供有界环境，检查确切的 Docker 命令，并控制网络和工具访问。
- **任何想要第二双手的人：** 让助手专注于一个项目，而不是暴露一整台机器。

## 您能掌控的事情

- 每个项目使用哪个文件夹。
- 助理可以访问哪些额外文件夹（如果有）。
- 它可能会联系哪些网站。
- 工作区中安装了哪些工具。
- 使用哪种型号和凭据。
- 工作区启动和停止时。
