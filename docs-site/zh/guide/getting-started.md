# 入门

Deepsand 可帮助您在实际项目中与 AI 编码助手一起工作，而无需让该助手访问计算机的其余部分。您无需了解 Docker 或命令行即可使用基本流程。

如果您想先了解全局，请阅读 [Deepsand是什么？](./what-is-deepsand)。

## 要求

- Windows 或 macOS 上的 Docker Desktop，或 Linux 上的 Docker Engine。
- Windows、macOS 或 Linux 计算机。 [下载页面](../download) 检测系统并列出匹配的安装程序。
- 除非您从源代码构建 Deepsand，否则不需要安装 Node.js 或 Rust。

Docker Desktop 必须先运行，Deepsand 才能启动沙箱。如果守护进程仍在启动，状态条会显示此信息并建议再次检查。 Docker Desktop 也可能正在运行但无响应；如果 Deepsand 表示守护进程没有应答，请重新启动 Docker Desktop。当 Deepsand 检测到 Docker Desktop 时，它显示 **重启Docker Desktop…** 控件。参见 [如果 Docker Desktop 未运行或停止响应该怎么办](./faq#what-if-docker-desktop-is-not-running-or-has-stopped-responding)。

## 安装

打开[Deepsand下载页面](../download)。它会检测您的操作系统并列出当前 GitHub 版本中的最新 Windows、macOS 和 Linux 安装程序。选择适合您计算机的软件包，安装它，然后启动 Deepsand。

如果您正在开发 Deepsand 本身，存储库 README 具有源构建和热重载命令。

## 第一次运行

在使用 Deepsand 之前，您不需要安装或配置 DeepCode。 Deepsand 在沙箱内运行 DeepCode，并为模型和端点提供合理的默认值。

您需要的一件事是一把 API 型号的钥匙。下一节将介绍如何获取 DeepSeek 密钥，或者您也可以使用其他提供商提供的密钥。保存在**设置 → API 键**中。

如果您已在此计算机上使用 DeepCode CLI，则 Deepsand 可以从现有的 DeepCode 配置继承模型、基本 URL 和密钥。项目还可以在自己的设置中覆盖这些凭据。

## 获取 API 密钥

Deepsand 需要模型提供商提供的 API 密钥才能运行助手。

- **如果您没有：** 跟随 [获取 DeepSeek API 密钥](./deepseek-api)。它逐步完成创建帐户、添加信用、制作密钥并返回 Deepsand。
- **如果您已经拥有：** 打开 **设置**，将其粘贴到 **API钥匙** 字段中并选择 **保存密钥**。
- **如果您想要特定于项目的密钥：** 打开该项目的设置并在那里输入。

应用程序范围的密钥保存在操作系统的密钥库中，而不是 Deepsand 的状态文件中。保存后窗口仅显示最后四个字符。

## 创建一个项目

1. 在侧栏中选择 **新项目**。
2. 为项目命名。
3. 选择工作目录。
4. 创建项目。

沙箱内的工作目录变为`/workspace`。 Deepsand 拒绝​​文件系统根目录、主目录、凭证存储及其自己的数据目录等路径。

## 选择型号

对于大多数任务，请使用 **闪光型号**。 Deepsand 默认为 `deepseek-v4-flash`，这是日常编码、解释和编辑的更便宜的选择。仅当闪存明显难以完成任务时才切换到 `deepseek-v4-pro`；专业版的运行成本更高。

您可以从项目标题中更改 **设置** 中的模型，或者使用 DeepCode 终端中的 `/model` 更改模型。

## 选择思维层次

思考滑块位于项目标题中模型选择器的旁边。它控制模型在回答之前进行多少推理。

- **离开：** 没有思考。最快，但最不小心。
- **快的：** 一点思考，用于小的、明确的编辑。
- **均衡：** 温和思维，中止。这是实际工作中合理的默认设置。
- **深的：**最大推理。最慢也最贵。
- **默认：** 服从主机 `settings.json`；如果它什么也没说，DeepCode 就会回到平衡状态。

对于大多数任务，将滑块保持在 **均衡** 上。它可以提供良好的结果，而无需为每个请求进行最慢、最昂贵的推理。仅针对真正困难的问题使用 **深的**，而针对小型、可预测的编辑使用 **离开** 或 **快的**。

## 运行一个项目

1. 选择项目。
2. 按 **跑步**。
3. 如果图像丢失，Deepsand 首先构建它并在“活动”选项卡中显示构建输出。
4. DeepCode CLI 在容器内启动并出现在终端中。

停止沙箱会结束容器。再次启动它会恢复上一个 DeepCode 会话（如果存在）。

## 使用 DeepCode 终端

**终端** 选项卡是实时 DeepCode CLI 会话。键入请求并按 **进入**，或使用斜杠命令来控制会话。 `/new` 开始新的对话，`/resume` 继续之前的对话，`/model` 更改模型，`/` 打开命令菜单。

阅读 [使用 DeepCode 终端](./deepcode-terminal) 了解主要命令、键盘快捷键和恢复步骤。

## 答复权限请求

当 DeepCode 需要目录、网络目标、工具或其他资源时，Deepsand 会暂停沙箱并显示请求。

- **授予访问权限** 允许请求并恢复会话。
- **否定** 拒绝​​并告诉模型该决定是最终的。
- 目录授权会重新创建附加了新挂载的容器。

在授予对包含敏感文件的目录的访问权限之前，请阅读 [沙箱如何工作](./security)。

## 去哪里找东西

|面积 |它显示了什么 |
| --- | --- |
|终端|沙箱内的实时 DeepCode 会话。 |
|权限|共享目录、网络白名单和审计跟踪。 |
|工具|工具已融入项目映像中。更改选择会重建图像。 |
|秘密 |在启动时作为环境变量注入的加密值。 |
|活动 |确切的 `docker run` 参数、构建日志和阻止的出口尝试。 |
