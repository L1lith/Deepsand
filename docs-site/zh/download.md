# 下载Deepsand

Deepsand 适用于 Windows、macOS 和 Linux。该页面会检测您的系统，但如果您要为不同的计算机下载，则可以选择其他平台。

<DownloadPicker />

## 安装之前

- Deepsand 使用 Docker 在自己的沙箱中运行每个项目。在 Windows 或 macOS 上安装 Docker Desktop，或在 Linux 上安装 Docker Engine。
- 您将需要一把 API 型号的钥匙。 [获取 DeepSeek API 密钥](./guide/deepseek-api)，或使用现有的提供商密钥。
- 首次启动可以构建沙盒映像，这可能需要几分钟的时间。

## 安装后

1. 启动Deepsand。
2. 打开 **设置** 并保存您的模型 API 密钥。
3. 创建一个项目并选择其工作目录。
4. 按 **跑步** 启动沙箱。

请阅读 [入门](./guide/getting-started) 以获取完整的首次运行演练。
