# Download Deepsand

Deepsand is available for Windows, macOS and Linux. The page detects your system, but you can choose another platform if you are downloading for a different machine.

<DownloadPicker />

## Before you install

- Deepsand uses Docker to run each project in its own sandbox. Install Docker Desktop on Windows or macOS, or Docker Engine on Linux.
- You will need a model API key. [Get a DeepSeek API key](./guide/deepseek-api), or use an existing provider key.
- The first launch can build the sandbox image, which may take a few minutes.

## After you install

1. Start Deepsand.
2. Open **Settings** and save your model API key.
3. Create a project and choose its working directory.
4. Press **Run** to start the sandbox.

Read [Getting started](./guide/getting-started) for the full first-run walkthrough.

## All releases

If the latest build is still being published, or you need an older version, open the
[GitHub releases page](https://github.com/L1lith/Deepsand/releases).
