# Saukewa: Deepsand

Deepsand yana samuwa don Windows, macOS da Linux. Shafin yana gano tsarin ku, amma kuna iya zaɓar wani dandamali idan kuna zazzagewa don na'ura daban.

Saukewa: <DownloadPicker />

## Kafin ka shigar

- Deepsand yana amfani da Docker don gudanar da kowane aiki a cikin akwatin yashi. Sanya Docker Desktop akan Windows ko macOS, ko Docker Engine akan Linux.
- Kuna buƙatar ƙirar API maɓallin. [Samu maɓallin DeepSeek API](./guide/deepseek-api), ko amfani da maɓallin mai bayarwa data kasance.
- Ƙaddamarwar farko na iya gina hoton sandbox, wanda zai ɗauki ƴan mintuna.

## Bayan kun girka

1. Fara Deepsand.
2. Bude **Saituna** kuma adana maɓallin API samfurin ku.
3. Ƙirƙiri aikin kuma zaɓi littafin jagorar sa.
4. Latsa **Gudu** don fara akwatin yashi.

Karanta [Farawa](./guide/getting-started) don cikakken tafiya ta farko.
