# Descargar Deepsand

Deepsand está disponible para Windows, macOS y Linux. La página detecta su sistema, pero puede elegir otra plataforma si está descargando para una máquina diferente.

<DownloadPicker />

## Antes de instalar

- Deepsand usa Docker para ejecutar cada proyecto en su propia zona de pruebas. Instale Docker Desktop en Windows o macOS, o Docker Engine en Linux.
- Necesitará una clave modelo API. [Obtenga una clave DeepSeek API](./guide/deepseek-api), o utilice una clave de proveedor existente.
- El primer lanzamiento puede crear la imagen de la zona de pruebas, lo que puede tardar unos minutos.

## Después de instalar

1. Inicie Deepsand.
2. Abra **Ajustes** y guarde la clave de su modelo API.
3. Cree un proyecto y elija su directorio de trabajo.
4. Presione **Correr** para iniciar la zona de pruebas.

Lea [Empezando](./guide/getting-started) para conocer el tutorial completo de primera ejecución.
