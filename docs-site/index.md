    details: Ask for a bug fix, a new feature, tests, or a plain-English explanation. DeepCode works in the project you choose, with the tools it needs.
  - title: Keep the rest of your computer private
    details: Your documents, photos, passwords, and other projects are not inside the workspace. DeepCode cannot browse them unless you explicitly allow it.
  - title: Stay in charge
    details: When the assistant needs another folder or a website, Deepsand pauses and asks. You approve or deny each request.
  - title: A guided terminal, not terminal expertise
    details: Create a project, press Run, and work with the assistant in the built-in terminal. You do not need to know terminal commands to start; Deepsand handles the container, and the guide explains the DeepCode commands you will actually use.
  - title: For beginners and experts
    details: Start with the guided flow. Explore models, tools, network rules, the audit trail, and signed updates when you are ready.
  - title: Open and auditable
    details: The policy code and security model are public. Developers can inspect exactly what the sandbox can and cannot reach.
