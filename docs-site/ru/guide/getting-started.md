# Начиная

Deepsand помогает вам работать с помощником по программированию с использованием искусственного интеллекта над реальным проектом, не предоставляя этому помощнику доступ к остальной части вашего компьютера. Вам не нужно понимать Docker или командную строку, чтобы использовать базовый поток.

Если вам сначала нужна более широкая картина, прочитайте [Что такое Deepsand?](./what-is-deepsand).

## Требования

- Docker Desktop на Windows или macOS или Docker Engine на Linux.
- Компьютер Windows, macOS или Linux. [страница загрузок](../download) обнаруживает систему и выводит список подходящих установщиков.
- Установка Node.js или Rust не требуется, если вы не собираете Deepsand из исходного кода.

Docker Desktop должен быть запущен, прежде чем Deepsand сможет запустить песочницу. Если демон все еще запускается, полоса состояния сообщает об этом и предлагает проверить еще раз. Docker Desktop также может работать, но не отвечать на запросы; если Deepsand сообщает, что демон не отвечает, перезапустите Docker Desktop. Когда Deepsand обнаруживает Docker Desktop, он отображает элемент управления **Перезапустите Docker Desktop…**. См. [что делать, если Docker Desktop не запускается или перестал отвечать на запросы](./faq#what-if-docker-desktop-is-not-running-or-has-stopped-responding).

## Установить

Откройте [Страница загрузок Deepsand](../download). Он определяет вашу операционную систему и выводит список последних установщиков Windows, macOS и Linux из текущей версии GitHub. Выберите пакет для своего компьютера, установите его, затем запустите Deepsand.

Если вы разрабатываете сам Deepsand, в README репозитория есть команды сборки исходного кода и горячей перезагрузки.

## Первый запуск

Вам не требуется устанавливать или настраивать DeepCode перед использованием Deepsand. Deepsand запускает DeepCode внутри песочницы и имеет разумные значения по умолчанию для модели и конечной точки.

Единственное, что вам нужно, это ключ модели API. В следующем разделе объясняется, как получить ключ DeepSeek, или вы можете использовать ключ от другого поставщика. Сохраните его в **Настройки → Клавиша API**.

Если вы уже используете DeepCode CLI на этом компьютере, Deepsand может вместо этого унаследовать модель, базовый URL-адрес и ключ из вашей существующей конфигурации DeepCode. Проект также может переопределить эти учетные данные в своих настройках.

## Получите ключ API

Для запуска помощника Deepsand требуется ключ API от поставщика модели.

- **Если у вас его нет:** следует за [Получите ключ DeepSeek API](./deepseek-api). Он проходит через создание учетной записи, добавление кредита, создание ключа и возврат к Deepsand.
- **Если он у вас уже есть:** откройте **Настройки**, вставьте его в поле **Ключ API** и выберите **Сохранить ключ**.
- **Если вам нужен ключ для конкретного проекта:** откройте настройки этого проекта и введите его туда.

Ключ всего приложения хранится в хранилище ключей вашей операционной системы, а не в файле состояния Deepsand. После сохранения в окне отображаются только последние четыре символа.

## Создать проект

1. Выберите **Новый проект** на боковой панели.
2. Дайте проекту имя.
3. Выберите рабочий каталог.
4. Создайте проект.

Рабочий каталог внутри песочницы становится `/workspace`. Deepsand отказывается от таких путей, как корень файловой системы, ваш домашний каталог, хранилища учетных данных и собственный каталог данных.

## Выберите модель

Используйте **флеш-модель** для большинства задач. Deepsand по умолчанию имеет значение `deepseek-v4-flash`, что является более дешевым выбором для повседневного кодирования, пояснений и редактирования. Переключайтесь на `deepseek-v4-pro` только тогда, когда флеш явно не справляется с задачей; профессиональная модель стоит дороже в эксплуатации.

Вы можете изменить модель в **Настройки** из заголовка проекта или с помощью `/model` в терминале DeepCode.

## Выберите уровень мышления

Ползунок мышления находится рядом с переключателем модели в заголовке проекта. Он контролирует, сколько рассуждений делает модель перед ответом.

- **Выключенный:** не думаю. Самый быстрый, но наименее осторожный.
- **Быстрый:** немного подумаю, для небольших четко определенных правок.
- **Сбалансированный:** умеренное мышление и средняя остановка. Это разумное значение по умолчанию для реальной работы.
- **Глубокий:** максимум рассуждений. Самый медленный и дорогой.
- **По умолчанию:** передать вызов хосту `settings.json`; если он ничего не говорит, DeepCode возвращается к сбалансированному состоянию.

Для большинства задач оставьте ползунок на **Сбалансированный**. Это дает хорошие результаты без необходимости платить за самые медленные и дорогостоящие рассуждения по каждому запросу. Используйте **Глубокий** только для действительно сложных задач, а **Выключенный** или **Быстрый** — для небольших, предсказуемых изменений.

## Запустить проект

1. Выберите проект.
2. Нажмите **Бегать**.
3. Если образ отсутствует, Deepsand сначала создает его и отображает выходные данные сборки на вкладке «Активность».
4. DeepCode CLI запускается внутри контейнера и появляется в терминале.

Остановка песочницы завершает работу контейнера. При повторном запуске возобновляется предыдущий сеанс DeepCode, если он существует.

## Использование терминала DeepCode

Вкладка **Терминал** — это живой сеанс DeepCode CLI. Введите запрос и нажмите **Входить** или используйте косую черту для управления сеансом. `/new` начинает новый разговор, `/resume` продолжает предыдущий, `/model` меняет модель, а `/` открывает командное меню.

Прочтите [Использование терминала DeepCode](./deepcode-terminal), чтобы узнать об основных командах, сочетаниях клавиш и этапах восстановления.

## Ответ на запросы разрешений

Когда DeepCode нужен каталог, сетевой адрес, инструмент или другой ресурс, Deepsand приостанавливает работу песочницы и отображает запрос.

- **Предоставить доступ** разрешает запрос и возобновляет сеанс.
- **Отрицать** отказывается и сообщает модели, что решение окончательное.
- Предоставление каталога воссоздает контейнер с присоединенным новым монтированием.

Прочтите [Как работает песочница](./security), прежде чем предоставлять доступ к каталогу, содержащему конфиденциальные файлы.

## Где найти вещи

| Площадь | Что это показывает |
| --- | --- |
| Терминал | Живая сессия DeepCode внутри песочницы. |
| Разрешения | Общие каталоги, список разрешенных сетей и журнал аудита. |
| Инструменты | Инструменты, встроенные в изображение проекта. Изменение выделения перестраивает изображение. |
| Секреты | Зашифрованные значения, внедряемые как переменные среды при запуске. |
| Деятельность | Точные аргументы `docker run`, журнал сборки и заблокированные попытки выхода. |
