# Получите ключ DeepSeek API

Deepsand нужен поставщик моделей для работы помощника. В конфигурации по умолчанию используется DeepSeek. На этой странице рассказывается о создании учетной записи, добавлении кредита, создании ключа API и его сохранении в Deepsand.

Если у вас уже есть ключ API от другого провайдера, перейдите к [Используйте ключ, который у вас уже есть](#use-a-key-you-already-have).

## Прежде чем начать

Вам понадобится:

- Адрес электронной почты или поддерживаемая учетная запись для входа.
- Способ оплаты кредита API.
- Несколько минут на создание ключа и вставку его в Deepsand.

Плата за DeepSeek API взимается отдельно от веб-сайта чата DeepSeek и мобильного приложения. Добавление кредита на платформе API позволяет помощнику делать запросы.

## 1. Создайте учетную запись DeepSeek.

1. Откройте [Платформа DeepSeek API](https://platform.deepseek.com/).
2. Выберите **Зарегистрироваться** или **Авторизоваться**.
3. Создайте учетную запись со своим адресом электронной почты или воспользуйтесь одним из поддерживаемых вариантов входа.
4. Подтвердите свой адрес электронной почты или номер телефона, если платформа попросит вас об этом.

## 2. Добавьте кредит

1. Войдите на платформу API.
2. Откройте раздел выставления счетов или пополнения баланса на панели управления.
3. Добавьте сумму кредита, которую вы хотите использовать.
4. Завершите оплату.

Использование API вычитается из этого баланса. Платформа показывает текущий баланс, использование и цены. Начните с небольшой суммы, пока пробуете Deepsand; вы можете добавить больше позже.

## 3. Создайте ключ API.

1. Откройте раздел платформы **Ключи API**.
2. Выберите **Создайте новый ключ API.** или аналогичную кнопку.
3. Дайте ключу знакомое имя, например **Deepsand**.
4. Создайте ключ и сразу скопируйте его.

Ключ обычно отображается только один раз. Относитесь к нему как к паролю: любой, у кого он есть, может потратить средства на вашем счету.

## 4. Сохраняем ключ в Deepsand.

1. Откройте Deepsand.
2. Откройте **Настройки**.
3. Найдите поле **Ключ API** в учетных данных по умолчанию.
4. Вставьте ключ.
5. Выберите **Сохранить ключ**.

Deepsand хранит ключ в хранилище ключей вашей операционной системы, а не в файле настроек. После сохранения в окне отображаются только последние четыре символа, поэтому вы можете подтвердить наличие ключа, не раскрывая его снова.

Ключ всего приложения используется, когда ни конфигурация хоста DeepCode, ни проект не предоставляют свой собственный ключ. Ключ уровня проекта по-прежнему имеет приоритет.

## Используйте ключ, который у вас уже есть

Если у вас уже есть ключ API, вам не нужно создавать учетную запись DeepSeek.

- Чтобы использовать его для каждого проекта, откройте **Настройки**, введите ключ в поле **Ключ API** и сохраните его.
- Чтобы использовать другую конечную точку или модель, также установите базовый URL-адрес и модель в **Настройки** или в собственных учетных данных проекта.
- Чтобы сохранить ключ только для одного проекта, откройте настройки этого проекта и введите его туда.

Поставщик должен предоставить API, который может вызывать DeepCode CLI. Если вы используете поставщика, не относящегося к DeepSeek, введите его базовый URL-адрес и название модели, а не значения по умолчанию DeepSeek.

## Если что-то не работает

- **Ключ отклонен:** создайте новый ключ на платформе и замените сохраненный.
- **Баланс пуст:** добавить кредит на счет API. Подписка на чат не обеспечивает автоматическое использование API.
- **Ассистент не может связаться с провайдером:** проверьте сетевой режим и белый список проекта. Конечная точка модели должна быть достижима.
- **Вы хотите удалить ключ:** откройте **Настройки** и выберите **Удалить ключ**.
