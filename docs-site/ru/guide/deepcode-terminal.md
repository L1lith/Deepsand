# Использование терминала DeepCode

Deepsand запускает [DeepCode CLI](https://github.com/lessweb/deepcode-cli) внутри песочницы. Вкладка **Терминал** представляет собой активный сеанс DeepCode: введите запрос на обычном языке или используйте одну из косых команд DeepCode для управления сеансом.

Вы не устанавливаете DeepCode на свой компьютер. Deepsand запускает CLI в контейнере проекта, где он может видеть `/workspace` и каталоги, которыми вы поделились.

Узнайте больше о [Домашняя страница проекта DeepCode](https://deepcode.vegamo.cn/) или [Репозиторий DeepCode](https://github.com/lessweb/deepcode-cli).

## Начать сеанс

1. Выберите проект на боковой панели.
2. Нажмите **Бегать**.
3. Подождите, пока запустится песочница. Если образ отсутствует, Deepsand сначала создает его и отображает выходные данные сборки в **Активность**.
4. Терминал DeepCode появляется, когда CLI готов.

Остановка песочницы завершает работу контейнера. Повторный запуск проекта возобновляет предыдущий диалог DeepCode, если он существует.

## Попросите DeepCode что-нибудь сделать.

Введите обычный запрос и нажмите **Входить**. Например:

```text
Find the failing test in this project and explain what is wrong.
```

DeepCode может читать и редактировать файлы в рабочей области, запускать команды и использовать инструменты, выбранные для проекта. Вы сохраняете контроль: когда ему нужно что-то за пределами рабочей области, Deepsand приостанавливает песочницу и сначала спрашивает вас.

## Основные команды косой черты

Команды слэша начинаются с `/`. Ввод `/` отдельно открывает командное меню.

| Команда | Что он делает |
| --- | --- |
| `/new` | Начать новый разговор |
| `/resume` | Выберите предыдущий разговор, чтобы продолжить |
| `/fork` | Разветвить текущий разговор |
| `/continue` | Продолжите активный разговор или выберите один из них, чтобы возобновить |
| `/model` | Переключите модель, режим мышления и усилие рассуждения |
| `/raw` | Переключить режим отображения: Обычный, Облегченный или Необработанный прокрутка назад |
| `/init` | Создайте файл `AGENTS.md` с инструкциями проекта |
| `/skills` | Перечислите навыки, доступные DeepCode |
| `/mcp` | Показать состояние сервера MCP и доступные инструменты |
| `/undo` | Восстановить код, разговор или и то, и другое на более раннюю точку |
| `/exit` | Выйти из DeepCode |

Проект может уже иметь `AGENTS.md`; проверьте перед использованием `/init`, чтобы не заменять уже имеющиеся инструкции.

## Сочетания клавиш

| Ключ | Действие |
| --- | --- |
| `Enter` | Отправить запрос |
| `Shift+Enter` | Вставить новую строку |
| `Ctrl+J` | Вставить новую строку |
| `Esc` | Прервать текущий поворот модели |
| `Ctrl+V` | Вставка изображения, если выбранная модель поддерживает изображения |
| `Ctrl+D` дважды | Выйти из DeepCode |

Прервав ход с помощью `Esc`, вы можете набрать еще один запрос. Песочница не перезапускается.

## Забрасывание файлов в терминал

Перетащите файл на терминал, и вам будет введен его путь.

- Файл внутри папки проекта или внутри каталога, к которому вы предоставили общий доступ с проектом, упоминается там, где песочница уже видит его (`/workspace/...` или `/grants/...`). Ничего не копируется.
- Файл из любого другого места копируется в `/tmp/deepsand-incoming` внутри песочницы, и Deepsand сначала спрашивает. Эта папка не является частью какого-либо репозитория, поэтому удаленный файл не может попасть в фиксацию и исчезает при воссоздании песочницы. В диалоговом окне есть переключатель **Не предупреждай меня больше**, который имеет ту же настройку, что и **Настройки → Поведение → Предупреждать перед удалением файлов из-за пределов проекта.**.

## Быть в курсе событий

DeepCode CLI установлен внутри образа песочницы, и песочница не может обновляться сама. Перед каждым запуском Deepsand спрашивает npm, какая последняя версия, и, если образ имеет более старую версию, сначала перестраивает эту часть образа — поэтому терминал никогда не открывается на версии, которая уже просит вас обновить. Ответ запоминается четверть часа, так что это один запрос, а не один за прогон, и если до npm не удается дозвониться, песочница запускается на той версии, которая у нее уже есть.

## Сессии, модели и отмена

- `/new` начинает с чистого разговора. Файлы проекта не удаляются.
- `/resume` и `/continue` возвращают предыдущий разговор.
- `/model` меняет модель, режим мышления и усилия по рассуждению для сеанса. В заголовке проекта также есть селектор модели и слайдер мышления; **Сбалансированный** — это средний упор и рекомендуемая настройка для большинства работ.
- `/undo` восстанавливает код, диалог или и то, и другое на более раннюю точку. Это самый быстрый способ отказаться от изменений, которых вы не хотели.

История разговоров хранится в томе состояния проекта Deepsand, а не в вашем репозитории.

## Разрешения и песочница

Терминал находится внутри контейнера, поэтому он видит проект по адресу `/workspace` и каталоги, которыми вы явно поделились, и ничего больше на вашем компьютере.

Когда DeepCode запрашивает другой каталог, сетевой адрес, инструмент или другой ресурс, Deepsand замораживает песочницу и отображает диалоговое окно разрешений.

- **Предоставить доступ** применяет запрос и возобновляет сеанс.
- **Не сейчас** на этот раз отказывается; DeepCode может спросить еще раз позже.
- **Не спрашивай больше** отказывается от него, а Deepsand затем отказывается от этого пути (и всего, что находится под ним) или от самого хоста (и его поддоменов), причем не только на словах. Каждый блок указан в разделе «Разрешения», где вы можете снять его снова.
- При утверждении каталога контейнер воссоздается с новым монтированием.

Прочтите [Как работает песочница](./security), прежде чем делиться каталогом, содержащим конфиденциальные файлы.

## Если терминал не запускается

- **Изображение отсутствует:** Deepsand собирает его первым. Следите за ходом сборки **Активность**.
- **Docker Desktop не работает или завис:** запустите его и подождите, пока двигатель завершит запуск. Если Docker Desktop работает, но его ядро ​​не отвечает, перезапустите Docker Desktop. Используйте элемент управления **Перезапустите Docker Desktop…** в приложении, когда Deepsand отображает его. В противном случае на Windows щелкните правой кнопкой мыши кит Docker в области уведомлений и выберите **Перезапуск**; на macOS используйте значок строки меню Docker; на Linux откройте меню **Устранение неполадок** Docker Desktop. Перезапуск Docker Desktop завершает работу каждого контейнера на машине. См. [Часто задаваемые вопросы по Docker](./faq#what-if-docker-desktop-is-not-running-or-has-stopped-responding).
- **Ключ API отсутствует или отклонен:** откройте **Настройки** и сохраните действительный ключ.
- **DeepCode вышел:** снова нажмите **Бегать**. Предыдущий сеанс можно возобновить с помощью `/resume`.
