# Скачать Deepsand

Deepsand доступен для Windows, macOS и Linux. Страница определяет вашу систему, но вы можете выбрать другую платформу, если загружаете для другой машины.

## Прежде чем установить

- Deepsand использует Docker для запуска каждого проекта в отдельной песочнице. Установите Docker Desktop на Windows или macOS или Docker Engine на Linux.
- Вам понадобится ключ модели API. [Получите ключ DeepSeek API](./guide/deepseek-api) или используйте существующий ключ поставщика.
- При первом запуске можно создать образ песочницы, что может занять несколько минут.

## После установки

1. Запустите Deepsand.
2. Откройте **Настройки** и сохраните ключ API вашей модели.
3. Создайте проект и выберите его рабочий каталог.
4. Нажмите **Бегать**, чтобы запустить песочницу.

Прочтите [Начиная](./guide/getting-started) для полного прохождения первого запуска.
