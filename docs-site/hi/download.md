# Deepsand डाउनलोड करें

Deepsand Windows, macOS और Linux के लिए उपलब्ध है। पेज आपके सिस्टम का पता लगाता है, लेकिन यदि आप किसी भिन्न मशीन के लिए डाउनलोड कर रहे हैं तो आप दूसरा प्लेटफ़ॉर्म चुन सकते हैं।

<DownloadPicker />

## इंस्टॉल करने से पहले

- Deepsand प्रत्येक प्रोजेक्ट को अपने स्वयं के सैंडबॉक्स में चलाने के लिए Docker का उपयोग करता है। Windows या macOS पर Docker Desktop, या Linux पर Docker Engine इंस्टॉल करें।
- आपको एक मॉडल API कुंजी की आवश्यकता होगी। [डीपसीक API कुंजी प्राप्त करें](./guide/deepseek-api), या मौजूदा प्रदाता कुंजी का उपयोग करें।
- पहला लॉन्च सैंडबॉक्स छवि बना सकता है, जिसमें कुछ मिनट लग सकते हैं।

## इंस्टॉल करने के बाद

1. Deepsand प्रारंभ करें.
2. **सेटिंग्स** खोलें और अपनी मॉडल API कुंजी सहेजें।
3. एक प्रोजेक्ट बनाएं और उसकी कार्यशील निर्देशिका चुनें।
4. सैंडबॉक्स प्रारंभ करने के लिए **दौड़ना** दबाएँ।

पूर्ण प्रथम-रन वॉकथ्रू के लिए [शुरू करना](./guide/getting-started) पढ़ें।

## सभी रिलीज़

यदि नवीनतम बिल्ड अभी भी प्रकाशित हो रहा है, या आपको पुराने संस्करण की आवश्यकता है, तो इसे खोलें
[GitHub पृष्ठ जारी करता है](https://github.com/L1lith/Deepsand/releases).
