# शुरू करना

Deepsand आपको किसी वास्तविक प्रोजेक्ट पर AI कोडिंग सहायक के साथ काम करने में मदद करता है, बिना उस सहायक को आपके कंप्यूटर के बाकी हिस्सों तक पहुंच प्रदान किए। मूल प्रवाह का उपयोग करने के लिए आपको Docker या कमांड लाइन को समझने की आवश्यकता नहीं है।

यदि आप पहले बड़ी तस्वीर चाहते हैं, तो [Deepsand क्या है?](./what-is-deepsand) पढ़ें।

## आवश्यकताएं

- Windows या macOS पर Docker Desktop, या Linux पर Docker Engine।
- एक Windows, macOS या Linux कंप्यूटर। [डाउनलोड पृष्ठ](../download) सिस्टम का पता लगाता है और मेल खाने वाले इंस्टॉलरों को सूचीबद्ध करता है।
- जब तक आप स्रोत से Deepsand का निर्माण नहीं कर रहे हैं, तब तक किसी Node.js या Rust इंस्टॉलेशन की आवश्यकता नहीं है।

Deepsand सैंडबॉक्स शुरू करने से पहले Docker Desktop को चलना चाहिए। यदि डेमॉन अभी भी शुरू हो रहा है, तो स्टेटस स्ट्रिप ऐसा कहती है और फिर से जांच करने की पेशकश करती है। Docker Desktop भी चल सकता है लेकिन अनुत्तरदायी; यदि Deepsand कहता है कि डेमॉन उत्तर नहीं दे रहा है, तो Docker Desktop को पुनरारंभ करें। जब Deepsand Docker Desktop का पता लगाता है तो यह **Docker Desktop पुनः प्रारंभ करें...** नियंत्रण दिखाता है। [यदि Docker Desktop नहीं चल रहा है या प्रत्युत्तर देना बंद कर दिया है तो क्या करें](./faq#what-if-docker-desktop-is-not-running-or-has-stopped-responding) देखें।

## स्थापित करना

[Deepsand डाउनलोड पृष्ठ](../download) खोलें. यह आपके ऑपरेटिंग सिस्टम का पता लगाता है और वर्तमान GitHub रिलीज़ से नवीनतम Windows, macOS और Linux इंस्टॉलर को सूचीबद्ध करता है। अपने कंप्यूटर के लिए पैकेज चुनें, इसे इंस्टॉल करें, फिर Deepsand प्रारंभ करें।

यदि आप स्वयं Deepsand विकसित कर रहे हैं, तो रिपॉजिटरी README में सोर्स-बिल्ड और हॉट-रीलोड कमांड हैं।

## पहली दौड़

Deepsand का उपयोग करने से पहले आपको DeepCode स्थापित या कॉन्फ़िगर करने की आवश्यकता नहीं है। Deepsand सैंडबॉक्स के अंदर DeepCode चलाता है और मॉडल और एंडपॉइंट के लिए समझदार डिफ़ॉल्ट के साथ आता है।

एक चीज़ जो आपको चाहिए वह है मॉडल API कुंजी। अगला भाग बताता है कि डीपसीक कुंजी कैसे प्राप्त करें, या आप किसी अन्य प्रदाता से कुंजी का उपयोग कर सकते हैं। इसे **सेटिंग्स → API कुंजी** में सेव करें।

यदि आप पहले से ही इस कंप्यूटर पर DeepCode CLI का उपयोग करते हैं, तो Deepsand आपके मौजूदा DeepCode कॉन्फ़िगरेशन से मॉडल, बेस यूआरएल और कुंजी प्राप्त कर सकता है। कोई प्रोजेक्ट अपनी सेटिंग्स में उन क्रेडेंशियल्स को ओवरराइड भी कर सकता है।

## एक API कुंजी प्राप्त करें

सहायक चलाने से पहले Deepsand को एक मॉडल प्रदाता से API कुंजी की आवश्यकता होती है।

- **यदि तुम्हारे पास ये नहीं है:**, [डीपसीक API कुंजी प्राप्त करें](./deepseek-api) का अनुसरण करें। यह एक खाता बनाने, क्रेडिट जोड़ने, एक कुंजी बनाने और Deepsand पर वापस आने से चलता है।
- **यदि आपके पास पहले से ही एक है:** **सेटिंग्स** खोलें, इसे **API कुंजी** फ़ील्ड में पेस्ट करें और **कुंजी सहेजें** चुनें।
- **यदि आप कोई प्रोजेक्ट-विशिष्ट कुंजी चाहते हैं:** उस प्रोजेक्ट की सेटिंग खोलें और इसके बजाय उसे वहां दर्ज करें।

ऐप-वाइड कुंजी आपके ऑपरेटिंग सिस्टम के कीस्टोर में रखी जाती है, Deepsand की स्टेट फ़ाइल में नहीं। सहेजने के बाद विंडो केवल अंतिम चार अक्षर दिखाती है।

## एक प्रोजेक्ट बनाएं

1. साइडबार में **नया प्रोजेक्ट** चुनें।
2. प्रोजेक्ट को एक नाम दें.
3. कार्यशील निर्देशिका चुनें.
4. प्रोजेक्ट बनाएं.

सैंडबॉक्स के अंदर कार्यशील निर्देशिका `/workspace` बन जाती है। Deepsand फ़ाइल सिस्टम रूट, आपकी होम निर्देशिका, क्रेडेंशियल स्टोर और अपनी स्वयं की डेटा निर्देशिका जैसे पथों को अस्वीकार करता है।

## एक मॉडल चुनें

अधिकांश कार्यों के लिए **फ़्लैश मॉडल** का उपयोग करें। Deepsand डिफ़ॉल्ट रूप से `deepseek-v4-flash` है, जो रोजमर्रा की कोडिंग, स्पष्टीकरण और संपादन के लिए सबसे सस्ता विकल्प है। `deepseek-v4-pro` पर तभी स्विच करें जब फ़्लैश स्पष्ट रूप से किसी कार्य से जूझ रहा हो; प्रो मॉडल को चलाने में अधिक लागत आती है।

आप मॉडल को **सेटिंग्स** में, प्रोजेक्ट हेडर से, या DeepCode टर्मिनल में `/model` के साथ बदल सकते हैं।

## सोच का एक स्तर चुनें

थिंकिंग स्लाइडर प्रोजेक्ट हेडर में मॉडल चयनकर्ता के बगल में है। यह नियंत्रित करता है कि मॉडल उत्तर देने से पहले कितना तर्क करता है।

- **बंद:** कोई सोच नहीं. सबसे तेज़, लेकिन सबसे कम सावधान।
- **जल्दी:** थोड़ी सोच, छोटे सुस्पष्ट संपादनों के लिए।
- **संतुलित:** मध्यम सोच और मध्यम पड़ाव। वास्तविक कार्य के लिए यह समझदार डिफ़ॉल्ट है।
- **गहरा:** अधिकतम तर्क. सबसे धीमा और सबसे महंगा.
- **गलती करना:** ने मेजबान `settings.json` को स्थगित कर दिया; यदि यह कुछ नहीं कहता है, तो DeepCode वापस Balanced पर आ जाता है।

अधिकांश कार्यों के लिए स्लाइडर को **संतुलित** पर रखें। यह हर अनुरोध पर सबसे धीमे, सबसे महंगे तर्क के लिए भुगतान किए बिना अच्छे परिणाम देता है। केवल वास्तव में कठिन समस्याओं के लिए **गहरा** का उपयोग करें, और छोटे, पूर्वानुमानित संपादनों के लिए **बंद** या **जल्दी** का उपयोग करें।

## एक प्रोजेक्ट चलाएँ

1. प्रोजेक्ट का चयन करें.
2. **दौड़ना** दबाएँ.
3. यदि छवि गायब है, तो Deepsand इसे पहले बनाता है और गतिविधि टैब में बिल्ड आउटपुट दिखाता है।
4. DeepCode CLI कंटेनर के अंदर शुरू होता है और टर्मिनल में दिखाई देता है।

सैंडबॉक्स को रोकने से कंटेनर समाप्त हो जाता है। एक के मौजूद होने पर इसे फिर से शुरू करने से पिछला DeepCode सत्र फिर से शुरू हो जाता है।

## DeepCode टर्मिनल का उपयोग करना

**टर्मिनल** टैब लाइव DeepCode CLI सत्र है। एक अनुरोध टाइप करें और **प्रवेश करना** दबाएँ, या सत्र को नियंत्रित करने के लिए स्लैश कमांड का उपयोग करें। `/new` एक नई बातचीत शुरू करता है, `/resume` पहले वाली बातचीत जारी रखता है, `/model` मॉडल बदलता है, और `/` कमांड मेनू खोलता है।

मुख्य कमांड, कीबोर्ड शॉर्टकट और पुनर्प्राप्ति चरणों के लिए [DeepCode टर्मिनल का उपयोग करना](./deepcode-terminal) पढ़ें।

## अनुमति अनुरोधों का उत्तर देना

जब DeepCode को एक निर्देशिका, एक नेटवर्क गंतव्य, एक उपकरण या अन्य संसाधन की आवश्यकता होती है, तो Deepsand सैंडबॉक्स को रोक देता है और अनुरोध दिखाता है।

- **अनुदान पहुँच** अनुरोध की अनुमति देता है और सत्र फिर से शुरू करता है।
- **अस्वीकार करना** ने इससे इंकार कर दिया और मॉडल को बताया कि निर्णय अंतिम है।
- एक निर्देशिका अनुदान नए माउंट संलग्न के साथ कंटेनर को फिर से बनाता है।

संवेदनशील फ़ाइलों वाली निर्देशिका तक पहुंच प्रदान करने से पहले [सैंडबॉक्स कैसे काम करता है](./security) पढ़ें।

## चीजें कहां मिलेंगी

| क्षेत्र | यह क्या दिखाता है |
| --- | --- |
| टर्मिनल | सैंडबॉक्स के अंदर लाइव DeepCode सत्र। |
| अनुमतियाँ | साझा निर्देशिकाएँ, नेटवर्क अनुमति सूची और ऑडिट ट्रेल। |
| उपकरण | उपकरण प्रोजेक्ट छवि में बेक किए गए। चयन बदलने से छवि फिर से बन जाती है. |
| रहस्य | प्रारंभ में एन्क्रिप्टेड मानों को पर्यावरण चर के रूप में इंजेक्ट किया जाता है। |
| गतिविधि | सटीक `docker run` तर्क, बिल्ड लॉग और अवरुद्ध निकास प्रयास। |
