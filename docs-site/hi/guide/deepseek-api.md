# डीपसीक API कुंजी प्राप्त करें

Deepsand को सहायक को पावर देने के लिए एक मॉडल प्रदाता की आवश्यकता है। डिफ़ॉल्ट कॉन्फ़िगरेशन डीपसीक का उपयोग करता है। यह पृष्ठ एक खाता बनाने, क्रेडिट जोड़ने, एक API कुंजी बनाने और इसे Deepsand में सहेजने के बारे में बताता है।

यदि आपके पास पहले से ही किसी अन्य प्रदाता से API कुंजी है, तो [आपके पास पहले से मौजूद कुंजी का उपयोग करें](#use-a-key-you-already-have) पर जाएं।

## शुरू करने से पहले

आपको चाहिये होगा:

- एक ईमेल पता या एक समर्थित साइन-इन खाता।
- API क्रेडिट के लिए एक भुगतान विधि।
- कुंजी बनाने और उसे Deepsand में चिपकाने में कुछ मिनट लगेंगे।

DeepSeek API को DeepSeek चैट वेबसाइट और मोबाइल ऐप से अलग से बिल किया जाता है। API प्लेटफ़ॉर्म पर क्रेडिट जोड़ने से सहायक को अनुरोध करने की अनुमति मिलती है।

## 1. एक डीपसीक अकाउंट बनाएं

1. [डीपसीक API प्लेटफॉर्म](https://platform.deepseek.com/) खोलें.
2. **साइन अप करें** या **लॉग इन करें** चुनें।
3. अपने ईमेल पते से एक खाता बनाएं, या समर्थित साइन-इन विकल्पों में से किसी एक का उपयोग करें।
4. यदि प्लेटफ़ॉर्म आपसे कहे तो अपना ईमेल पता या फ़ोन नंबर सत्यापित करें।

## 2. क्रेडिट जोड़ें

1. API प्लेटफॉर्म पर साइन इन करें।
2. डैशबोर्ड में बिलिंग या टॉप-अप अनुभाग खोलें।
3. वह क्रेडिट राशि जोड़ें जिसका आप उपयोग करना चाहते हैं।
4. भुगतान पूरा करें.

API उपयोग इस शेष राशि से काट लिया जाता है। प्लेटफ़ॉर्म वर्तमान संतुलन, उपयोग और मूल्य निर्धारण दिखाता है। जब आप Deepsand आज़मा रहे हों तो छोटी राशि से शुरुआत करें; आप बाद में और जोड़ सकते हैं.

## 3. एक API कुंजी बनाएं

1. प्लेटफ़ॉर्म का **API कुंजियाँ** अनुभाग खोलें।
2. **नई API कुंजी बनाएं** या समतुल्य बटन का चयन करें।
3. कुंजी को ऐसा नाम दें जिसे आप पहचान सकें, जैसे **Deepsand**।
4. कुंजी बनाएं और उसे तुरंत कॉपी करें.

कुंजी आमतौर पर केवल एक बार दिखाई जाती है. इसे एक पासवर्ड की तरह समझें: जिसके पास भी यह है वह आपके खाते से क्रेडिट खर्च कर सकता है।

## 4. कुंजी को Deepsand में सहेजें

1. Deepsand खोलें.
2. **सेटिंग्स** खोलें.
3. डिफ़ॉल्ट क्रेडेंशियल के अंतर्गत **API कुंजी** फ़ील्ड ढूंढें।
4. कुंजी चिपकाएँ.
5. **कुंजी सहेजें** चुनें.

Deepsand कुंजी को आपके ऑपरेटिंग सिस्टम के कीस्टोर में संग्रहीत करता है, इसकी सेटिंग फ़ाइल में नहीं। सहेजने के बाद विंडो केवल अंतिम चार अक्षर दिखाती है, इसलिए आप कुंजी को दोबारा उजागर किए बिना इसकी पुष्टि कर सकते हैं।

ऐप-वाइड कुंजी का उपयोग तब किया जाता है जब न तो होस्ट DeepCode कॉन्फ़िगरेशन और न ही कोई प्रोजेक्ट अपनी कुंजी प्रदान करता है। प्रोजेक्ट-स्तरीय कुंजी को अभी भी प्राथमिकता दी जाती है।

## आपके पास पहले से मौजूद कुंजी का उपयोग करें

यदि आपके पास पहले से ही API कुंजी है, तो आपको डीपसीक खाता बनाने की आवश्यकता नहीं है।

- प्रत्येक प्रोजेक्ट के लिए इसका उपयोग करने के लिए, **सेटिंग्स** खोलें, **API कुंजी** फ़ील्ड में कुंजी दर्ज करें और इसे सहेजें।
- किसी भिन्न समापन बिंदु या मॉडल का उपयोग करने के लिए, आधार URL और मॉडल को **सेटिंग्स** या प्रोजेक्ट के स्वयं के क्रेडेंशियल में भी सेट करें।
- केवल एक प्रोजेक्ट के लिए कुंजी रखने के लिए, उस प्रोजेक्ट की सेटिंग खोलें और इसके बजाय उसे वहां दर्ज करें।

प्रदाता को एक API उजागर करना होगा जिसे DeepCode CLI कॉल कर सके। यदि आप गैर-डीपसीक प्रदाता का उपयोग कर रहे हैं, तो डीपसीक डिफ़ॉल्ट के बजाय उसका आधार यूआरएल और मॉडल नाम दर्ज करें।

## अगर कुछ काम नहीं करता

- **कुंजी अस्वीकार कर दी गई है:** प्लेटफ़ॉर्म पर एक नई कुंजी बनाएं और संग्रहीत कुंजी को बदलें।
- **शेष ख़ाली है:** API खाते में क्रेडिट जोड़ें। चैट सदस्यता स्वचालित रूप से API उपयोग को निधि नहीं देती है।
- **सहायक प्रदाता तक नहीं पहुंच सकता:** प्रोजेक्ट के नेटवर्क मोड और अनुमति सूची की जाँच करें। मॉडल समापन बिंदु पहुंच योग्य होना चाहिए.
- **आप कुंजी हटाना चाहते हैं:** **सेटिंग्स** खोलें और **कुंजी निकालें** चुनें।
