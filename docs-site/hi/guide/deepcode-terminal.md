# DeepCode टर्मिनल का उपयोग करना

Deepsand सैंडबॉक्स के अंदर [DeepCode CLI](https://github.com/lessweb/deepcode-cli) चलाता है। **टर्मिनल** टैब एक लाइव DeepCode सत्र है: सामान्य भाषा में एक अनुरोध टाइप करें, या सत्र को नियंत्रित करने के लिए DeepCode के स्लैश कमांड में से एक का उपयोग करें।

आप अपनी मशीन पर DeepCode इंस्टॉल नहीं करते हैं। Deepsand प्रोजेक्ट के कंटेनर में CLI शुरू करता है, जहां यह `/workspace` और आपके द्वारा साझा की गई निर्देशिकाएं देख सकता है।

[DeepCode प्रोजेक्ट होम पेज](https://deepcode.vegamo.cn/) या [DeepCode भंडार](https://github.com/lessweb/deepcode-cli) पर और जानें।

## एक सत्र प्रारंभ करें

1. साइडबार में एक प्रोजेक्ट चुनें.
2. **दौड़ना** दबाएँ.
3. सैंडबॉक्स के प्रारंभ होने की प्रतीक्षा करें. यदि छवि गायब है, तो Deepsand इसे पहले बनाता है और **गतिविधि** में बिल्ड आउटपुट दिखाता है।
4. CLI तैयार होने पर DeepCode टर्मिनल प्रकट होता है।

सैंडबॉक्स को रोकने से कंटेनर समाप्त हो जाता है। किसी के मौजूद होने पर प्रोजेक्ट को फिर से शुरू करना पिछली DeepCode बातचीत को फिर से शुरू करता है।

## DeepCode को कुछ करने के लिए कहें

एक सामान्य अनुरोध टाइप करें और **प्रवेश करना** दबाएँ। उदाहरण के लिए:

```text
Find the failing test in this project and explain what is wrong.
```

DeepCode कार्यक्षेत्र में फ़ाइलों को पढ़ और संपादित कर सकता है, कमांड चला सकता है और प्रोजेक्ट के लिए चयनित टूल का उपयोग कर सकता है। आप नियंत्रण में रहते हैं: जब उसे कार्यक्षेत्र के बाहर किसी चीज़ की आवश्यकता होती है, तो Deepsand सैंडबॉक्स को रोक देता है और पहले आपसे पूछता है।

## मुख्य स्लैश आदेश

स्लैश कमांड `/` से शुरू होते हैं। `/` टाइप करने पर कमांड मेनू अपने आप खुल जाता है।

| आदेश | यह क्या करता है |
| --- | --- |
| `/new` | नए सिरे से बातचीत शुरू करें |
| `/resume` | जारी रखने के लिए पिछली बातचीत चुनें |
| `/fork` | वर्तमान वार्तालाप को फोर्क करें |
| `/continue` | सक्रिय बातचीत जारी रखें, या फिर से शुरू करने के लिए किसी एक को चुनें |
| `/model` | मॉडल, सोच मोड और तर्क प्रयास को स्विच करें |
| `/raw` | डिस्प्ले मोड को टॉगल करें: सामान्य, लाइट या रॉ स्क्रॉलबैक |
| `/init` | प्रोजेक्ट निर्देशों के साथ एक `AGENTS.md` फ़ाइल बनाएं |
| `/skills` | DeepCode | के लिए उपलब्ध कौशलों की सूची बनाएं
| `/mcp` | MCP सर्वर स्थिति और उपलब्ध उपकरण दिखाएँ |
| `/undo` | कोड, वार्तालाप या दोनों को पहले वाले बिंदु पर पुनर्स्थापित करें |
| `/exit` | DeepCode छोड़ें |

किसी प्रोजेक्ट में पहले से ही `AGENTS.md` हो सकता है; `/init` का उपयोग करने से पहले जांच लें ताकि आप पहले से मौजूद निर्देशों को न बदलें।

## कुंजीपटल अल्प मार्ग

| कुंजी | कार्रवाई |
| --- | --- |
| `Enter` | शीघ्र भेजें |
| `Shift+Enter` | एक नई पंक्ति सम्मिलित करें |
| `Ctrl+J` | एक नई पंक्ति सम्मिलित करें |
| `Esc` | वर्तमान मॉडल मोड़ को बाधित करें |
| `Ctrl+V` | जब चयनित मॉडल छवियों का समर्थन करता है तो एक छवि चिपकाएँ |
| `Ctrl+D` दो बार | DeepCode छोड़ें |

`Esc` के साथ एक मोड़ को बाधित करने के बाद, आप एक और अनुरोध टाइप कर सकते हैं। सैंडबॉक्स पुनः प्रारंभ नहीं हुआ है.

## सत्र, मॉडल और पूर्ववत करें

- `/new` एक साफ़ बातचीत के साथ शुरू होता है। प्रोजेक्ट फ़ाइलें हटाई नहीं जातीं.
- `/resume` और `/continue` पहले की बातचीत को वापस लाते हैं।
- `/model` सत्र के लिए मॉडल, सोच मोड और तर्क प्रयास को बदलता है। प्रोजेक्ट हेडर में एक मॉडल चयनकर्ता और एक सोच स्लाइडर भी है; **संतुलित** मध्य पड़ाव है और अधिकांश कार्यों के लिए अनुशंसित सेटिंग है।
- `/undo` कोड, वार्तालाप या दोनों को पहले वाले बिंदु पर पुनर्स्थापित करता है। यह उस बदलाव से पीछे हटने का सबसे तेज़ तरीका है जो आप नहीं चाहते थे।

वार्तालाप इतिहास प्रोजेक्ट के Deepsand स्टेट वॉल्यूम में रहता है, आपके रिपॉजिटरी में नहीं।

## अनुमतियाँ और सैंडबॉक्स

टर्मिनल कंटेनर के अंदर है, इसलिए यह `/workspace` पर प्रोजेक्ट और आपके द्वारा स्पष्ट रूप से साझा की गई निर्देशिकाओं को देखता है, और आपके कंप्यूटर पर और कुछ नहीं देखता है।

जब DeepCode किसी अन्य निर्देशिका, नेटवर्क गंतव्य, टूल या अन्य संसाधन के लिए पूछता है, तो Deepsand सैंडबॉक्स को फ्रीज कर देता है और एक अनुमति संवाद दिखाता है।

- **अनुदान पहुँच** अनुरोध लागू करता है और सत्र फिर से शुरू करता है।
- **अस्वीकार करना** ने इससे इंकार कर दिया और DeepCode को बताया कि निर्णय अंतिम है।
- किसी निर्देशिका को स्वीकृत करने से नए माउंट के साथ कंटेनर फिर से बन जाता है।

संवेदनशील फ़ाइलों वाली निर्देशिका साझा करने से पहले [सैंडबॉक्स कैसे काम करता है](./security) पढ़ें।

## यदि टर्मिनल प्रारंभ नहीं होता है

- **छवि गायब है:** Deepsand इसे पहले बनाता है। निर्माण प्रगति के लिए **गतिविधि** देखें।
- **Docker Desktop नहीं चल रहा है या अटका हुआ है:** इसे शुरू करें और इंजन शुरू होने तक प्रतीक्षा करें। यदि Docker Desktop चल रहा है लेकिन उसका इंजन जवाब नहीं दे रहा है, तो Docker Desktop को पुनरारंभ करें। जब Deepsand इसे दिखाए तो इन-ऐप **Docker Desktop पुनः प्रारंभ करें...** नियंत्रण का उपयोग करें। अन्यथा, Windows पर अधिसूचना क्षेत्र में Docker व्हेल पर राइट-क्लिक करें और **पुनः आरंभ करें** चुनें; macOS पर Docker मेनू बार आइकन का उपयोग करें; Linux पर Docker Desktop का **समस्याओं का निवारण** मेनू खोलें। Docker Desktop को पुनः प्रारंभ करने से मशीन का प्रत्येक कंटेनर समाप्त हो जाता है। [Docker अक्सर पूछे जाने वाले प्रश्न](./faq#what-if-docker-desktop-is-not-running-or-has-stopped-responding) देखें।
- **API कुंजी अनुपलब्ध या अस्वीकृत है:** **सेटिंग्स** खोलें और एक वैध कुंजी सहेजें।
- **DeepCode बाहर निकला:** फिर से **दौड़ना** दबाएँ। पिछला सत्र `/resume` के साथ फिर से शुरू किया जा सकता है।
