# O que é Deepsand?

Deepsand é um aplicativo de desktop que permite que um assistente de codificação de IA ajude em um projeto dentro de seu próprio espaço de trabalho separado.

Pense nisso como uma bancada em outra sala. Você traz o projeto para o qual deseja ajuda. O auxiliar pode usar aquela bancada e os materiais que você entregar, mas não pode vagar pelo resto da casa.

## Para que é útil

- Corrigindo um bug em um site ou programa pequeno.
- Adicionando um recurso a um projeto existente.
- Explicando o código que você herdou ou não reconhece.
- Escrever testes, documentação ou um primeiro rascunho.
- Explorar um repositório desconhecido sem dar a um assistente acesso a todo o resto da sua máquina.

Você não precisa saber como funciona o Docker e não precisa ser um desenvolvedor profissional para começar. Se você puder escolher uma pasta e pressionar um botão, poderá usar o fluxo básico.

## Por que não usar apenas uma janela de bate-papo?

Uma janela de bate-papo pode sugerir código, mas não pode executar seu projeto, ler os arquivos ao seu redor ou verificar se sua sugestão realmente funciona.

Deepsand dá ao assistente um projeto real e ferramentas reais. Ele pode executar comandos, editar arquivos e testar o resultado, enquanto o espaço de trabalho mantém esse trabalho longe do resto do computador.

## O que significa "um espaço de trabalho separado"

O assistente vê a pasta do projeto que você escolhe e as pastas que você compartilha deliberadamente. Ele não vê automaticamente seus documentos, fotos, downloads, outros projetos, senhas ou o restante do disco.

Quando precisa de algo fora do espaço de trabalho, tem que pedir. Deepsand pausa o assistente e mostra a solicitação. Nada é compartilhado até que você aprove.

## Para quem é

- **Pessoas que são novas em codificação:** obtém ajuda com um projeto pequeno sem primeiro aprender uma ferramenta de contêiner.
- **Desenvolvedores experientes:** fornece a um agente de IA um ambiente limitado, inspeciona o comando Docker exato e controla o acesso à rede e às ferramentas.
- **Quem quiser um segundo par de mãos:** mantém o assistente focado em um projeto em vez de expor uma máquina inteira.

## O que você mantém no controle

- Qual pasta cada projeto usa.
- Quais pastas extras, se houver, o assistente pode acessar.
- Quais sites ele pode contatar.
- Quais ferramentas estão instaladas no espaço de trabalho.
- Qual modelo e credenciais são usados.
- Quando o espaço de trabalho inicia e para.
