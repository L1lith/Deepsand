# Baixar Deepsand

Deepsand está disponível para Windows, macOS e Linux. A página detecta seu sistema, mas você pode escolher outra plataforma se estiver baixando para uma máquina diferente.

<DownloadPicker />

## Antes de instalar

- Deepsand usa Docker para executar cada projeto em sua própria sandbox. Instale Docker Desktop em Windows ou macOS ou Docker Engine em Linux.
- Você precisará de uma chave modelo API. [Obtenha uma chave DeepSeek API](./guide/deepseek-api) ou use uma chave de provedor existente.
- A primeira inicialização pode criar a imagem do sandbox, o que pode levar alguns minutos.

## Depois de instalar

1. Inicie Deepsand.
2. Abra **Configurações** e salve sua chave modelo API.
3. Crie um projeto e escolha seu diretório de trabalho.
4. Pressione **Correr** para iniciar a sandbox.

Leia [Começando](./guide/getting-started) para obter o passo a passo completo da primeira execução.
